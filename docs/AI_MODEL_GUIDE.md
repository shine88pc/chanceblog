# 무료 AI 활용 가이드 — 코드를 고치는 AI와 알림·글쓰기용 AI를 나눠 쓰기

> **기준일 2026-11-02.** 공식 문서·약관·가격 페이지를 이날 직접 읽은 조사입니다(근거 주소와 확인하지 못한 것은 [`analysis/2026-11-02_free-ai-code-editing.md`](./analysis/2026-11-02_free-ai-code-editing.md)).
> **무료 한도·약관은 몇 달 단위로 바뀝니다.** 올해만 Gemini CLI 무료(6월)·Qwen Code 무료 로그인(4월)·Roo Code(5월)가 끝났습니다. 그래서 이 문서의 표는 **한 달에 한 번 다시 확인**합니다(§7).
> 이 문서는 **안내**입니다. 계정 연결·결제는 운영자 승인 사항이라 **아직 아무것도 켜지 않았습니다**(§7의 기본값은 모두 "켜지 않음").
> 앞선 결론(2026-10-30, [`analysis/2026-10-30_free-ai-monitoring.md`](./analysis/2026-10-30_free-ai-monitoring.md))과의 관계: 그때는 "무료 AI 는 지금 Claude 세션이 하는 일(요청 이해·계획·수정·독립 검증)을 통째로 대신하지 못한다"였고 그 판단은 그대로입니다. 이번 조사는 **작은 수정(문서·시험·모듈 하나)에 한해** 무료로 코드를 고치게 할 수 있는 길이 있는지, 그리고 DeepSeek-Coder 를 폴백으로 쓸 수 있는지를 봅니다.

## 1. 한눈에 (결론)

1. AI 를 **두 가지 일**로 나눕니다. ① **코드를 고치는 일** — 파일을 직접 바꾸고 시험까지 돌립니다. ② **글만 돌려주는 일** — 알림 문구·한 줄 요약·오류 설명·주간 요약·글 초안. 두 일에는 쓰는 도구도, 위험도, 지켜야 할 규칙도 다릅니다.
2. 코드 수정을 **지금 $0 으로** 할 수 있다고 문서에 적힌 곳: **Google Jules**(하루 15건), **Google Antigravity**(주간 한도), **GitHub Copilot Free**(VS Code 에이전트 모드), **Amazon Q/Kiro**(월 50), **Mistral Vibe Free**. 다만 "문서상 가능"이지 "실제로 잘 고친다"는 **직접 측정하지 못했습니다.**
3. **개인 PC(메모리 16GB·내장 그래픽)에 설치해 쓰는 무료 모델은 코드 수정용으로 권하지 않습니다.** 알림·요약 실험용으로만 씁니다.
4. **DeepSeek-Coder**: PC 에 받아 쓰는 DeepSeek-Coder-V2 는 2024년 모델이라 **비추천**입니다. 지금의 DeepSeek 은 공식 API(`deepseek-flash`·`deepseek-v4-pro`)이고 **무료가 아니라 선불 소액**(경량 사용 월 약 $1~10 — 계산 가정은 분석 문서 C절)이며 서버가 중국입니다. **조건을 지킬 때만 사용**합니다(§4).
5. 규칙: 무료 AI 는 **문서·시험(T0)과 모듈 하나·프롬프트(T1)만 직접 고칩니다.** 워크플로·발행 핵심(T2)은 **초안까지만**, 비밀·광고·계정·삭제·정책(T3)은 **손대지 않습니다.** 어떤 경우에도 **브랜치 → PR → 자동 검사 → 운영자 병합**입니다(§6).
6. 한도가 닿으면 **멈추고 다음 리셋을 기다리거나, 사람이 다른 도구를 골라** 씁니다. AI 가 알아서 다른 서비스로 갈아타는 자동 전환은 하지 않습니다(운영자 결정 D-15). 규칙을 풀어서 해결하지 않습니다.
7. 무료만으로 **데스크톱 프로그램을 새로 만드는 일**(수정이 많이 반복되는 일)을 감당하기는 어려울 가능성이 큽니다(조사자의 추정). 그때 가장 덜 나쁜 길이 §3의 3단계(선불 소액)입니다.

## 2. 용도를 나누는 표 — 무슨 일에 어떤 AI 를 쓰나

| 일 | 가장 안전한 방법 | 무료 AI 로 보탠다면 | 해서는 안 되는 것 |
|----|------------------|---------------------|-------------------|
| 텔레그램 알림 문구 | **문장 틀(AI 없음)** — 지금도 이렇게 보냅니다 | Gemini Flash(무료 키, 이미 블로그 글에 쓰는 것) | 로그 원문·비밀이 든 글을 AI 에 보내기 |
| 실패 한 줄 요약 | 틀 + 핵심 줄 뽑기 | Gemini Flash-Lite | 로그를 통째로 붙여 넣기 |
| 긴 오류 로그를 쉬운 말로 | 앱 안의 **오류 코드 + 문구**(규칙 기반, 결정 D-17) | Gemini(로그를 사람이 훑어 비밀을 지운 뒤) | 비밀·개인정보가 든 로그 |
| 주간 요약 | 틀 | Gemini | – |
| 블로그 글 초안 | Gemini(이미 사용 중, 게이트·가드레일 통과 필요) | 로컬 소형 모델(실험) | 게이트를 건너뛴 게시 |
| **코드·문서·시험 수정** | **Claude Code 등 유료 세션(지금 방식)** | §3의 도구들 — **T0·T1 만**, 결과는 PR 로 | T2·T3 를 AI 가 직접 반영 |
| 코드 검토(다른 AI 의 눈) | 다른 회사 AI 가 **읽기만**(제 변경은 제가 검증하지 않습니다) | Copilot Free 채팅·Gemini | 같은 AI 가 자기 변경을 스스로 검증 |

> 데스크톱 프로그램 안에서 쓰는 AI(요약·로그 설명)는 **선택 보조**이고 기본은 꺼짐입니다(결정 D-14·D-16). 프로그램을 **개발할 때** 쓰는 AI 는 위 표의 "코드·문서·시험 수정" 줄이며 프로그램에는 포함되지 않습니다. 둘을 섞지 않습니다.

## 3. 코드를 고치는 AI — 지금 무료로 되는 것과 아닌 것

### 3-1. 무료로 코드 수정이 문서상 되는 도구 (2026-11-02)

| 도구 | 어떻게 쓰나 | 무료 한도 | 입력이 학습에 쓰이나 | 난이도 |
|------|-------------|-----------|----------------------|--------|
| **Google Jules** | 웹에서 저장소 1개 연결 → 작업 입력 → 계획 승인 → 결과를 **브랜치로** 올려 줌(main 직접 푸시 없음) → PR 은 사람이 | 하루 15건·동시 3건 | 비공개 저장소는 아님(공개 저장소는 문서에 없음) | 낮음 |
| **Google Antigravity** | 앱·명령줄. 무료는 Gemini Flash 계열만 | 주간 한도(수치 비공개) | **예**(설정에서 끌 수 있으나 효과는 논쟁) | 중 |
| **GitHub Copilot Free** | VS Code 에이전트 모드·Copilot CLI | 완성 월 2,000회, 채팅·에이전트는 "제한"(수치 비공개) | **예**(2026-04-24부터, 설정에서 거부 가능) | 중 |
| **Amazon Q / Kiro Free** | IDE·명령줄 | 에이전트 요청 월 50 / 월 50 크레딧 | Kiro 는 예(옵트아웃 가능) | 중 |
| **Mistral Vibe Free** | 명령줄(Windows 는 공식 지원 아님) | "제한된 코딩 세션"(수치 비공개) | 기본 예(옵트아웃 가능) | 높음 |

- **"무료로 모델 API 만 주는 곳"**(OpenRouter 무료 모델·Groq·Cerebras·NVIDIA·Cloudflare·Hugging Face)은 글만 돌려줍니다. Aider·Cline 같은 도구에 연결해야 코드를 고치는데, 분당 토큰 한도(예: Groq 8K)가 코드 에이전트 한 번 호출에도 모자랄 수 있고 `:free` 라우터는 자동 전환형이라 **쓰지 않습니다**(D-15).
- **한국에서 쓸 수 있는지·실제 한도 수치·테스트 실행 여부**는 로그인한 뒤에야 보여서 **확인하지 못했습니다**(§8).

### 3-2. 끝났거나 쓰지 말 것

- **Gemini CLI·Gemini Code Assist 개인 무료**: 2026-06-18 종료(Antigravity 로 이전). **Qwen Code 무료 로그인**: 2026-04-15 종료. **Roo Code**: 2026-05-15 보관(종료). **Continue**: 더는 관리되지 않음.
- **GitHub Models**: 종료됐고 이 프로젝트의 설계에서도 제외(결정 D-15, 시험으로 고정).
- **채팅 웹 화면을 스크립트·매크로로 조작**하는 방법: DeepSeek 이용약관(3.5)·Antigravity 약관(§6)이 금지·계정 정지 사유입니다. **공식 API·공식 명령줄·공식 앱만** 씁니다. 한 서비스의 로그인을 다른 도구에 빌려 쓰지 않습니다.

### 3-3. 단계별 추천 (싼 것·쉬운 것부터)

- **0단계($0, 지금):** AI 에 덜 의존하게 둡니다. 알림은 문장 틀, AI 는 선택 기능. 지금의 Gemini 키는 **글쓰기·요약 전용**으로 두고 모델 이름을 점검합니다(이 저장소는 `gemini-3.8-flash`·`3.6-flash`·`3.5-flash-lite` 만 쓰고 있어 2.5 계열 접근 제한(2026-09-18)의 영향이 없습니다 — 점검함).
- **1단계($0, 설치 없음):** **Jules 로 T0·T1 작은 수정.** 순서 — Jules 사이트 → 개인 Gmail 로그인 → 안내 동의 → GitHub 연결은 **저장소 1개만** → 작업 입력 → 계획 승인 → "Create branch" → GitHub 에서 PR → 자동 검사 → 운영자 병합. 하루 15건 이내. 한도에 닿으면 그날은 멈추고 24시간 뒤에 이어 갑니다.
- **2단계($0, 설치 있음):** 데스크톱 프로그램을 **개발**할 때는 **Antigravity 앱** 또는 **VS Code + Copilot Free 에이전트**. 설치 직후 **학습·데이터 설정부터 끄고**(Copilot 은 Privacy 설정) 공식 클라이언트만 씁니다. 주간 한도가 바닥나면 다음 리셋까지 보류하거나 1단계로 옮깁니다. 큰 작업은 **PR 한 개 = 작은 일 하나**로 잘게 나눕니다.
- **3단계(소액, 무료 한도가 계속 막힐 때만):** **DeepSeek API 선불 $5 안팎 + Aider 또는 Cline**(월 약 $1~10, 아래 §4 조건 준수). 대안은 Copilot Pro $10/월·ClinePass $9.99/월·Mistral Vibe Pro $14.99/월. **월 소액 허용은 운영자가 정합니다**(§7).
- **PC 안에 설치하는 모델**(Ollama·LM Studio)은 코드 수정용으로 **권하지 않습니다**: 기본 문맥 길이가 4K 인데 코딩 도구는 64K 이상을 권하고, Aider 공식 문서도 "대부분의 로컬 모델은 겨우 동작해 편집 오류가 피할 수 없다"고 적습니다. 메모리 32GB 이상·그래픽 전용 메모리 12~16GB 이상이면 Devstral Small 2·Qwen3.8-27B 를 시험해 볼 만하지만 제작사 수치일 뿐입니다.

## 4. DeepSeek-Coder 를 쓰려면

- **이름의 현재:** DeepSeek-Coder 는 2024-09 의 V2.5 에서 일반(Chat) 모델과 **합쳐졌고**, 지금의 최신은 V4 계열(`deepseek-flash`·`deepseek-v4-pro`)입니다. 따로 "Coder" 신제품은 찾지 못했습니다.
- **PC 에 받아 쓰는 DeepSeek-Coder-V2-Lite(16B)는 비추천:** 2024년 모델이고 도구를 부려 파일을 고치게 학습됐다는 근거가 없습니다.
- **공식 API**(`api.deepseek.com`): 선불 충전식. 1백만 토큰당 `deepseek-flash` 입력 $0.15~0.3·출력 $0.6~1.2, `deepseek-v4-pro` 입력 $0.66~1.32·출력 $1.98~3.96(한국 시간 낮 10~13시·15~19시가 비싼 시간대). 가입 무료 크레딧은 **확인하지 못했습니다.** 월 비용은 조사자의 계산(작업 1건당 모델 호출 10회 가정): flash 월 30건 $1~2.5, pro $4~10 — 에이전트가 맴돌면 몇 배가 되므로 **선불 잔액으로 상한**을 겁니다.
- **프라이버시:** 처리방침상 서버가 중국에 있고, 비식별화한 입력을 모델 개선에 쓸 수 있으며(앱에서는 거부 가능), API 약관은 학습 사용 여부를 밝히지 않았습니다.
- **판단 = 조건부 사용.** 조건: ① **T0·T1 만** ② **공개 저장소 코드만** — 비밀·개인정보·로그 원문은 절대 보내지 않음 ③ **공식 API + 선불 소액** ($5 안팎), 웹 채팅 자동화 금지 ④ **브랜치 + PR + 자동 검사**를 그대로 유지 ⑤ 코드를 읽는 AI 가 이슈·웹 글 속 지시문을 따르지 않도록 PR 검토에서 확인. 이 중 하나라도 지키지 못하면 쓰지 않습니다.

## 5. 코드 수정이 안 되는 용도 (알림·요약·글쓰기)

- **가장 안전하고 비용 0 인 방법은 AI 없이 문장 틀입니다.** 지금 텔레그램 알림도 틀이고, 앞으로도 틀이 기본입니다.
- **이미 쓰는 길 — Gemini API 무료 키:** 문서상 무료 모델은 `gemini-3.8-flash`·`3.6-flash`·`3.5-flash-lite`·`3.1-flash-lite`(이 저장소는 앞의 세 개를 씁니다). **모델별 하루 한도 수치는 공식 문서에 없고 AI Studio 화면에서만 보입니다** — 블로그의 숫자는 서로 달라 믿지 말고, 운영자가 화면에서 읽어 이 문서에 적어 둡니다(§7). 무료는 입력·출력이 제품 개선에 쓰이고 사람이 읽을 수 있으며 "민감·기밀·개인정보를 넣지 말 것"이 약관 문구입니다. (결제 계정을 연결하면 학습에 쓰이지 않지만 "무료 원칙"을 깨므로 운영자 결정입니다.)
- **다른 무료 후보:** Cloudflare Workers AI(하루 10,000 Neurons, 학습 미사용), Groq(분당 토큰 한도 작음), PC 의 Ollama `gemma4`(PC 가 켜져 있을 때만 — GitHub Actions 에서는 못 씀). 한국어 품질을 믿을 만하게 비교한 자료는 못 찾았습니다 — **같은 문장 5개로 직접 시험**합니다.
- 이 용도의 AI 는 **짧은 입력 → 검증된 짧은 출력**만 합니다. 결과는 길이·금지어 검사를 거치고, 못 믿으면 틀 문장으로 되돌립니다.

## 6. 안전 규칙 (모든 AI 공통)

**절대 보내지 않는 것:** API 키·토큰·비밀번호·`.env`, 개인정보(이름·메일·전화·주소·결제), 비공개 문서, 로그 원문. 에이전트를 돌리는 폴더에는 `.env`·키 파일이 없어야 하고 환경변수에도 토큰을 넣지 않습니다. GitHub 는 등록된 비밀을 로그에서 가려 주지만 변형된 형태는 못 가립니다 — 로그는 사람이 훑거나 가공한 뒤에 보냅니다.

**무료 입력이 학습·열람에 쓰이나:** Gemini API 무료=예(사람이 읽을 수 있음), Antigravity 개인=예, Copilot Free=예(2026-04-24~, 거부 가능), Mistral Free·Vibe=기본 예, Kiro Free=예, Cline·OpenCode 무료 모델=가능, DeepSeek=처리방침상 가능(서버 중국), Jules=비공개 저장소는 아님, Cloudflare=아님. PC 안의 모델은 PC 밖으로 나가지 않습니다. 그래서 **공개 저장소의 코드만, 비밀 없이** 보냅니다. 회사 PC·회사 계정에서는 규정을 확인하기 전에 외부 무료 AI 에 로그인하거나 코드를 보내지 않습니다.

**작업 등급별 권한(제안):**

| 등급 | 무료 AI 가 할 수 있는 것 | 필요한 조건 |
|------|--------------------------|-------------|
| **T0** 문서·시험 | 직접 수정 | 브랜치 + PR, 자동 검사 통과, 운영자가 바뀐 파일 목록을 확인(비밀·워크플로 파일이 없는지) |
| **T1** 모듈·프롬프트 하나 | 직접 수정 | 고칠 파일을 지정해 한정, 시험을 함께 추가, PR 설명에 변경 요약, 자동 검사 통과 |
| **T2** 워크플로·발행 핵심·권한·배포 | **초안(diff)까지만** | 자동 검사 + **다른 회사 AI 의 읽기 전용 검토 1회** + 운영자 승인 |
| **T3** 비밀·광고·계정·삭제·정책 | **직접 수정 금지**(분석·설명까지) | 운영자의 번호 있는 명시 승인 뒤 사람이 반영 |

`.github/workflows/`·`permissions`·비밀 참조·배포 단계는 항상 T2 이상으로 봅니다. 이 저장소의 자동 검사(guardrails)와 "main 검사 실패 즉시 알림"은 무료 AI 가 만든 변경에도 그대로 적용됩니다. AI 가 읽는 이슈·웹 페이지·로그 속의 지시문은 **자료일 뿐 명령이 아닙니다.**

**한도에 닿았을 때(공통):** 멈춤 → 다음 리셋 대기 → 사람이 다른 도구를 골라 수동으로 → 그래도 급하면 3단계. **규칙(브랜치 + PR + 검사, 등급)을 풀어서 해결하지 않습니다.**
