## 약속(지킨 것)

- 글 속 사실·수치는 실제로 열어 본 출처만 근거로 삼았고, 열 수 없었던 출처(접속 거부·약관·robots 로 AI 접근 금지)는 '접근 제한'으로 적고 쓰지 않았습니다.
- 원문 문장을 옮기지 않고 요약했습니다. 판단(분류·우선순위·확신도)은 AI 의 판단이며 문서마다 '확신이 낮은 곳'을 적었습니다.
- 일괄 삭제·비공개 전환을 권하지 않았고, '공개 중단 검토'는 이유와 대안을 함께 적었습니다(결정은 운영자 몫, 비공개 전환은 승인이 필요한 변경).
