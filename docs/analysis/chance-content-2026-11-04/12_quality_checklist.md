## 이 체크리스트를 쓰는 법
- **뼈대는 운영자의 범용 가이드 §11 의 13항목**입니다(§A). 운영자 가이드에 없는 것은 두 갈래로 구별해 표시했습니다: **[범용 §n]** = 같은 가이드의 다른 절(§5 사실성, §7 이미지, §8 링크, §10 AI 보조)에서 가져온 확인 / **[추가]** = Chance 저장소의 규칙·실제로 확인된 실패 사례에서 우리가 더한 항목(§D). 분야별 확인(§C)은 주제별 가이드에서 가져왔습니다.
- **같은 목차를 강제하지 않습니다**(운영자 지시): 이 체크리스트의 어떤 항목도 소제목 수·표 유무·결론 절·문단 순서를 요구하거나 확인하지 않습니다. '도입부', '한계', '다음 행동' 같은 말은 **글에 그런 내용이 독자에게 전달되는지**를 묻는 질문이지 칸을 만들라는 뜻이 아닙니다. 글의 구성은 독자의 질문에 맞춰 작성자가 정합니다.
- **누가**: **사람** = 사람이(또는 출처를 직접 여는 AI 가) 판단 / **자동** = 코드가 이미 하거나 개선안이 승인되면 할 것 / **반자동** = 코드가 신호를 주고 사람이 판정. '지금 코드'는 `origin/main`(8dba231) 기준입니다. 자동 검사는 독창성·정확성을 보장하지 못합니다(범용 §10).
- **번호 표기**: 표의 'S1·S4·S11…'(검사 번호)와 'G1·G5'(근거 대조·상태어 검사)는 개선안 §5 와 §3 에서 정의한 자동 검사의 이름이고, 이야기를 가리킬 때는 '이야기 S20'처럼 앞말을 붙였습니다(진단 담당 의 이야기 번호 S01~S20 과 다른 번호).
- **판정**: 범용 §12 의 세 단계 — **통과 / 수정 후 통과 / 발행 보류**(§E). 필수 6항목(§D 끝)이 하나라도 '확인 못 함'이거나 통과가 아니면 발행하지 않습니다. **'필수' 표시는 운영자 가이드의 것이 아니라 이 체크리스트가 정한 최소 묶음**입니다(운영자 §11 의 13항목은 모두 같은 무게로 두었고, 범용 §10 이 든 보류 사유 5가지에 맞춘 것이 §D 끝의 대응표). 보류 사유는 항목 번호로 기록합니다.
- **분량 안내(핵심 17 + 확장)**: 글마다 반드시 보는 핵심 목록은 운영자 13항목(§A) + 필수 추가 4(B1·D3·B4·D7) = **17항목**입니다(지시서가 정한 12~20항목 범위). 나머지 B2·B3·B5~B9·D1·D2·D4~D6·D8·D9 는 자동 검사가 이미 잡거나 월 1회 표본 점검 때 보는 '확장 항목'입니다(핵심 17 + 확장 14 = 31).
- **소요**: 한 편(한·영 한 쌍) 약 10분 + 출처를 여는 시간. 지금은 월 1회 5편 표본 점검과 승인 흐름의 PR 에서 씁니다.

## F. 이미지 점검 순서(5분) — 운영자 기준 그대로
운영자 기준(#118): **주제가 비슷하다는 이유만으로 쓰지 말고, 실제 설명과 일치하는지·제작 주체·상업 블로그에서 쓸 수 있는 조건·캡션·alt 를 실제 내용 기준으로 확인한다. 확인되지 않은 이미지 사용 권한은 추측하지 않는다.**
1. 사진을 연다 → 무엇이 보이는지 한 문장으로 적는다(이것이 alt 의 재료).
2. 글·캡션이 말하는 대상과 같은가? 같지 않으면 '이해를 돕기 위한 사진'이라고 캡션에 밝히거나 사진을 바꾼다(범용 §7: 설명 기능이 없는 이미지는 쓰지 않는다).
3. 제작 주체(작가)와 출처 링크를 누른다 → 열리고 사진 페이지와 이름이 같은가?
4. 사용 조건(라이선스) 페이지를 연다 → 광고가 붙는 상업 사이트 사용이 허용되는가? 확인일을 적는다. 인물·상표·로고·건물이 있으면 이 조건만으로 충분한지 운영자에게 묻는다(법률 판단은 이 문서가 하지 않는다).
5. 같은 사진이 사이트의 다른 글에 쓰였는지 찾는다. 외부 기관 이미지(예: NASA)는 제작 주체·사용 지침 페이지를 직접 열어 크레딧 문구를 그대로 표기한다(자동 이미지 경로는 `images.unsplash.com` 만 받으므로 PR 로 수동 반영).
6. 하나라도 '확인 못 함'이면 그 사진은 쓰지 않는다(다음 후보). 그래도 없으면 사진 없이 발행할 수 있는지(범용 §7)를 운영자에게 묻는다(홈 카드·레이아웃 영향 때문에 ★).

**이미 있는 장치(U3 포함)가 막는 것 / 못 막는 것**
| 막는 것 | 못 막는 것 |
|---|---|
| 작가 출처를 모르는 사진 사용, 사진·사용 알림 주소의 호스트·경로 이상, 이미 쓴 사진 재사용(이력·글 안), 접근 불가(HEAD) 사진, 작가·Unsplash 출처 줄 자동 삽입(utm), 키가 리다이렉트로 새는 일 | 사진이 글의 대상인지, 사람·상표·로고·건물, 작가 이름의 진위, 라이선스 문구·확인일 기록, alt·캡션의 질, 생성 이후 사진이 내려가는 일(핫링크), 홈 카드·모달 이미지의 출처 표시(광고 표면) |

## H. 자동 검사로 옮길 수 있는 것과 없는 것 (개선안과의 대응)
- **옮길 수 있는 것(결정적, 보류·수정 후 통과)**: 환산 의심(S4), 한·영 숫자 불일치(S5), 본문 안 근거 링크(S1)와 진짜 분량(S3, 출처 자르기 보정 뒤), 같은 원문 주소(`DUP_URL`), 근거 입력 부족(`THIN_INPUT`), 근거 텍스트에 없는 숫자(G1), 이미지 기록 누락, 분야 규칙의 결정 조건(투자 권유·진단·치료 조언 표현).
- **신호만(사람이 먼저 볼 순서를 정하는 용도, 판정을 바꾸지 않음)**: 숫자 부족, 일반론 표지 문장 비율, 가정형 비율, 귀속 없는 인과 단정, 틀에 박힌 표현, 제목 유사도(강화).
- **자동 후보가 아닌 것(사람만)**: 독창성·정확성의 최종 판정, 도입부·결론·한계·분석 개수 같은 **구성 요소**(운영자: 같은 목차를 강제하지 않는다 — 표준 글 담당 템플릿 초판의 '사실 표 3~5행·분석 소제목 2개·한계 항목 3개' 검사는 v0.2 에서 이미 빠졌고, v0.2 §9-2 에 남은 도입부 위치·표나 목록 표지·한계 절 유무 확인도 이 때문에 자동 후보에서 제외), 이미지가 설명과 맞는지, 링크가 주장과 맞는지.
- 근거: 시뮬레이션에서 신호를 판정에 쓰면 후반 14쌍 중 9~12쌍이 걸려 게시가 사실상 멈추고(개선안 §5), 가장 잘 쓴 설명서형 글도 가정형 신호에 걸립니다.
