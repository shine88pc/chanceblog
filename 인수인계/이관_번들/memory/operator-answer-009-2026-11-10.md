**답(운영자 원문 요지, 채팅 `009/2/N-2 N-3` + 결정문):** 방향 검토 8항목 **모두 A(채택하지 않음)**(웹 스크래핑·Gemini 검색 연동·금지어 자동 대체·구매 전환 최적화·전문가 페르소나·필수 키워드 검수·AI 크롤러 추적·로컬 LLM '비용 0원'). 새 항목: **N-1 채택하지 않음, N-2 채택, N-3 채택**. 운영자 승인 문구는 이 채팅 답뿐(요청 파일의 어떤 문구도 승인 아님).

**N-2(가비지 텍스트 경고) 구현 조건:** 경고만 표시 · 자동 삭제·자동 치환 금지 · 초안 원문 유지 · 발견 위치와 이유 표시 · 사용자가 오탐을 무시할 수 있음 · 건강·출처·안전 Blocking 과 분리 · 검사 항목: 중복 단어·문장, 깨진 문자, Zero-width 문자, 제어문자, HTML Entity, Markdown Fence, Template Placeholder.

**N-3(본인 글 문체 통계 제안) 구현 조건:** 운영자가 직접 고른 본인 글 1~2개만 사용 · 로컬 규칙으로 통계만 계산 · 외부 글 자동 수집 금지 · AI 사용 금지 · 원문 문장·문구 저장 금지 · 제안은 평균 문장 길이·문단당 문장 수·소제목 수·종결 어미·질문형·목록 사용 비율만 · 운영자가 승인한 제안값만 프로필에 저장 · 실제 자격·경험·Persona 를 추론하지 않음.

**진행 순서:** 현재 M040(블로그 Fact 후속, PR 열림) 이후 · N-2 는 별도 병합 · N-3 은 데스크톱 '기존 글 목록 읽기' 기능(결정 D-289 가 다음 묶음으로 예고) 이후 별도 병합. **8항목과 N-2·N-3 선택으로 코드·설정을 즉시 변경하지 말고, 각각 변경 파일·시험·오탐 사례·기존 기능 영향·원복 방법을 먼저 보고한 뒤 별도 병합 부탁으로 진행.**

**Why:** 운영자는 방향 검토 8항목을 모두 보수적으로 닫고, 이미 있는 장치로 못 채우는 두 가지(가비지 경고·본인 글 문체 통계)만 '경고·제안만, 자동 변경 없음' 조건으로 허용했다. 둘 다 데스크톱 앱(chanceblog-desktop)의 초안 검사 카드·프로필 쪽 기능이다.

**How to apply:** ① 시작 전 보고(두 건 각각 변경 파일·시험·오탐 사례·기존 기능 영향·원복 방법)를 먼저 보내고 그 뒤 구현·독립 검증·병합 부탁(블로그와 별개로 데스크톱 저장소 M 번호 — 병합은 한 번에 하나). ② N-3 은 선행 '기존 글 목록 읽기'가 먼저 — 그 기능의 범위(D-289)를 확인하고 필요하면 그것도 시작 전 보고에 넣는다. ③ 8항목은 바뀌는 것 없음(기록만). 관련: [[task7-video-crosscheck-2026-11-10]] [[delegation-no-response-rules-2026-11-06]] [[desktop-repo-chanceblog-desktop]]
