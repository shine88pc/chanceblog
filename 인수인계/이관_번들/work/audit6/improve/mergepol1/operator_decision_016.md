# 운영자 확인 016 답 (2026-11-15 아침, 채팅 본인 입력 — 원문 그대로)

016/3/조건부 승인형 병합으로 진행합니다.
제가 원하는 방식은 AI가 독자적으로 판단해서 자동 병합하는 방식이 아닙니다.
AI가 변경 내용을 쉬운 말로 설명하고, 제가 해당 병합 번호를 명시해 승인하면 AI가 그 PR을 병합하는 방식입니다.
병합 전에는 다음 내용을 개발자가 아닌 사람도 이해할 수 있게 설명해 주세요.

1. 무엇을 바꾸는지
2. 왜 필요한지
3. 프로그램을 사용할 때 무엇이 달라지는지
4. 기존 기능에 미치는 영향과 위험
5. 검사와 독립 검증 결과
6. 문제가 생겼을 때 되돌리는 방법

전문용어만 나열하지 말고 실제 사용자가 체감할 변화 중심으로 설명해 주세요.
예:
병합 요청 M075
무엇을 바꾸나요? 앱을 닫아도 작성 중인 초안을 다시 열 수 있도록 저장 기능을 추가합니다.
왜 필요한가요? 현재는 앱을 닫으면 초안이 사라집니다.
사용할 때 무엇이 달라지나요? 저장 버튼과 저장된 초안 목록이 추가됩니다.
위험은 무엇인가요? 저장 실패나 손상 가능성을 막기 위해 원자적 저장과 복구 시험을 수행했습니다.
검사 결과 전체 검사와 독립 검증을 통과했고 기존 복사 기능에는 변화가 없습니다.
되돌리기 문제가 발생하면 M075 병합만 되돌리면 이전 상태로 복구됩니다.
승인 방식은 반드시 병합 번호와 함께 사용해 주세요.
승인 예: M075 승인
아래 표현만으로는 병합 승인으로 판단하지 마세요.

* 확인했습니다
* 진행하세요
* 좋아 보입니다
* 기본값대로
* 다음 단계 진행

AI는 제가 승인한 병합 번호와 현재 열려 있는 PR 번호가 일치할 때만 병합할 수 있습니다.
승인은 해당 PR 한 건에만 유효하며, 다른 PR이나 이후 변경에 재사용할 수 없습니다.
승인 후에도 병합 전에 다음 조건을 다시 확인해 주세요.

* 승인된 병합 번호와 PR 일치
* 승인 이후 Commit 추가 없음
* 검사 전체 통과
* 독립 검증 통과
* 충돌 없음
* 변경 범위가 승인 설명과 일치
* 비밀정보 노출 없음
* 원복 방법 확인

승인 이후 새 Commit이 추가되거나 변경 범위가 달라지면 기존 승인은 무효입니다. 새 설명과 새 승인을 받아야 합니다.
AI가 병합할 수 있는 범위:

* 일반 프로그램 코드
* 일반 UI
* 시험
* 문서
* 로컬 저장·조회
* 오류 수정
* 접근성·성능 개선

다음 항목은 제가 승인해도 AI가 직접 병합하지 말고 운영자 직접 병합 대상으로 유지해 주세요.

* GitHub Actions Workflow
* 광고·AdSense·ads.txt
* 공개 게시물과 고정 페이지
* PIPELINE_PAUSE
* 발행 모드와 발행 재개
* Provider 활성화
* API Key·Secret·Credential
* 의존성 추가
* 데이터 삭제·Migration
* 자동 게시 활성화
* 외부 비용 발생 기능
* Main Branch 보호 설정

병합 방식도 제한합니다.
AI가 운영자 PC의 Git 자격 증명을 이용해 main에 직접 Push하는 방식은 사용하지 마세요.
반드시 다음 흐름을 사용해 주세요.
AI가 PR 작성 → 검사와 독립 검증 → 쉬운 병합 설명 발송 → 운영자가 병합 번호를 명시해 승인 → AI가 승인된 PR 병합 → main 사후 검사 → 병합 완료 알림
main 직접 Push는 금지합니다.
병합 후 main 검사에서 문제가 나오면 추가 변경을 자동 병합하지 말고, 해당 병합을 되돌리기 위한 요청과 쉬운 원인 설명을 먼저 보내 주세요.
병합 완료 알림에는 다음을 포함해 주세요.

* 병합 번호
* PR 번호
* 병합된 Commit
* 실제 반영된 변화
* main 검사 결과
* 이상 유무
* 원복 Commit 또는 원복 방법

이 정책을 먼저 문서화하고 시험해 주세요.
실제 AI 병합 기능을 켜는 변경은 별도 병합 요청으로 보내고, 그 변경은 제가 직접 병합하겠습니다.
첫 운영은 일반 코드 또는 문서 PR 3건으로 시험해 주세요.
3건 모두 다음 조건을 만족하면 승인형 AI 병합을 계속 사용합니다.

* 승인받은 PR만 병합
* 승인 후 변경 없음
* main 검사 전체 통과
* 원복 발생 0건
* 다른 PR 오병합 0건
* 운영자 전용 경로 변경 0건

문제가 한 건이라도 발생하면 AI 병합을 즉시 중지하고 기존 운영자 직접 병합 방식으로 돌아가 주세요.
