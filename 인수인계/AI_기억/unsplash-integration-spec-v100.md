**요지(내 말):**
- **목적·이름:** 이미지를 '생성'하지 않고 주제에 맞는 사진을 Unsplash 에서 **검색·추천·선택**. UI 글자는 `주제 이미지 추천`·`Unsplash 이미지 검색`·`대표 이미지 선택` 만, `이미지 생성`·`AI 이미지 생성` 금지.
- **흐름:** 주제 후보 → 핵심 키워드·글 유형 → 영어 검색어 자동 구성(1차 결과가 부족할 때만 보조 검색어) → 검색 → **기본 추천 1장 자동 제안** → 그대로 쓰거나 다른 사진 선택 → 이미지 없이 진행 가능 → 선택 이미지·출처를 초안에 연결 → 사용자가 실제 블로그 편집기에서 사진을 직접 추가. 이미지는 선택 사항이고 **API 한도·네트워크 오류·결과 없음에도 초안 작성·복사는 계속**.
- **공식 규칙:** 화면 표시는 응답 `photo.urls`(목록 thumb/small, 미리보기 regular) 핫링크 / **사용자가 `이 이미지 사용`을 누르면 `download_location` 호출**(성공 여부 기록, 같은 사진 반복 호출 방지) / 출처 `Photo by [작가] on Unsplash` + 작가 프로필·사진 페이지·Unsplash 링크, 모두 `utm_source=chanceblog_desktop&utm_medium=referral` / `출처 복사` 버튼.
- **키:** Access/Secret 키는 저장소·소스·`.env.example` 실제 값·설치 파일·Portable ZIP·로그·오류 보고서·설정 내보내기·백업 ZIP 어디에도 없음. 저장은 Windows 자격 증명 관리자(1순위)·DPAPI 암호화(2순위), 설정 DB 에는 별칭·연결 상태·마지막 확인 시각만. 입력은 마스킹, 저장한 키를 다시 보여 주지 않음(보이려면 재인증), 연결 해제 시 보안 저장소에서도 삭제하고 **캐시를 남길지 사용자에게 물음**.
- **설정 화면:** 설정 → 연결 관리 → 이미지 서비스 → Unsplash — 연결 상태·Access Key 등록·(Secret 은 실제로 필요할 때만)·연결 테스트(**최소 호출**)·마지막 성공 시각·남은 요청 수·한도 초기화 시각·캐시 상태·연결 해제. 상태 문구 5종: 연결됨 / 연결 확인 필요 / 요청 한도 도달 / 인증 정보 오류 / 연결 안 됨.
- **검색어:** 짧은 영어(핵심 대상 + 장소·상황 + 시각 요소), 기본 흐름에서는 검색어를 보이지 않고 `다른 이미지 보기`·`검색어 수정` 때만. 입력 재료 = 핵심·보조 키워드·추천 주제·글 유형·카테고리·블로그 프로필·사용자 추가 입력·제외할 이미지 주제.
- **추천 기준:** 주제 직접 관련·밝고 명확·작은 썸네일에서도 식별·글자·워터마크 없음·광고처럼 연출되지 않음·인물 식별 중심 아님·블로그 A/B 분위기와 일치·최근 사용과 중복 안 됨·가로형 우선, 좋아요 수만으로 고르지 않음. 의료·금융·법률·세금·안전 글은 결과를 보장하는 느낌의 사진 금지, 직접 경험이 없는 후기는 방문·구매·사용을 증명하는 듯한 사진 금지.
- **적용 우선순위:** ① 사용자 로컬 이미지 ② 그 주제에 이전에 골라 둔 이미지 ③ Unsplash 기본 추천 ④ 사용자가 고른 다른 Unsplash ⑤ 카테고리 Placeholder ⑥ 카테고리 아이콘.
- **화면:** 홈 추천 목록 왼쪽 64×64 또는 72×72(1:1·모서리 10~12·cover·Skeleton·실패 시 Placeholder·깨진 아이콘 금지·지연 로딩·스크롤 중 요청 취소) / 이미지 선택 창(검색어·결과 Grid 3~4열 간격 12~16·미리보기 4:3 또는 1:1·선택=파란 테두리+체크·출처·버튼 `[이 이미지 사용] [다른 검색어로 검색] [로컬 이미지 추가] [이미지 없이 진행]`) / 초안 결과 오른쪽 패널 `대표 이미지 제안`(16:9 미리보기·작가명·출처·검색 키워드·사용 상태, 버튼 `[이 이미지 사용] [다른 이미지] [출처 복사] [이미지 없이 진행]`) — **본문에는 이미지 이진·외부 주소를 강제로 넣지 않고** 대표 이미지 제안·작가/출처·Alt Text·추천 삽입 위치만 제공.
- **블로그 A/B 차별화:** 같은 주제를 두 블로그에서 쓰면 기본값으로 같은 이미지를 반복하지 않음(A 생활형·밝음, B 정보형·도구/문서/기술). 이미지 분위기·선호 색감·인물 포함·실내외·사진/일러스트·동일 이미지 재사용 허용 옵션은 처음엔 고급 설정에 숨김.
- **메타데이터(이미지마다):** 이미지 ID·공급자·공급자 사진 ID·원본 주소·작가 이름·작가 프로필·Unsplash 페이지·`download_location`·사용 조건 문구·검색어·Alt Text·크기·색·방향·블로그 선택 여부·후보 연결·다운로드 알림 시각·생성/마지막 사용 시각·로컬 썸네일 경로·상태. 사용자 화면에는 내부 ID·영문 상태 노출 금지. 내부 상태: NONE·SEARCHING·SUGGESTED·SELECTED·TRACKED·MISSING·ERROR.
- **캐시:** `UserData/` 아래 `image-cache`·`image-metadata`·`selected-images`·`thumbnails`. 검색 결과 메타데이터 7일·**썸네일 30일**·선택 이미지 정보는 사용자가 지울 때까지·검색어별 결과 7일. 한도 넘으면 오래된 미선택부터 삭제, 선택 정보 자동 삭제 금지, 중복 저장 금지, 캐시를 지워도 출처 메타데이터 유지, 홈은 원본이 아니라 썸네일.
- **한도·안전장치:** 같은 검색어 중복 호출 금지·화면 이동 시 자동 재검색 금지·캐시 우선·명시적 새로고침일 때만 재검색·남은 요청 수·초기화 시각 저장/표시·429 는 `Retry-After`/공식 제한 정보 준수·5xx·Timeout 은 **짧게 기다렸다 최대 1회 재시도** 뒤 캐시/Placeholder·무한 재시도 금지·이미지 문제로 초안 생성을 막지 않음. **여러 키: Unsplash 한도 우회용 자동 순환 금지 — 키가 여러 개여도 용도는 개발/운영 앱 구분·사용자가 명시적으로 고른 앱 전환·폐기된 키 교체뿐, 429·한도 소진에도 다른 키로 자동 전환하지 않음**(→ 'k' 에 전달함).
- **오류 문구 4종(인증 / 요청 한도 / 결과 없음 / 네트워크):** 쉬운 한국어로 이어서 쓸 수 있는 길(설정 열기·저장된 이미지·다른 검색어·이미지 없이 진행)을 안내, 스택 트레이스·응답 원문은 `상세 정보`·로그에만, 로그에서도 키 마스킹.
- **비동기:** 검색·미리보기 로딩·썸네일 생성·캐시 저장/정리·다운로드 알림·로컬 이미지 변환·메타데이터 저장은 화면 스레드 밖, 요청 취소·동일 요청 중복 제거·이미지 실패가 목록 전체 오류로 번지지 않게 격리.
- **구조:** `services/image_provider/`(인터페이스·unsplash 제공자·제공자 오류·한도 상태) + `services/image_cache/`(썸네일·메타데이터·정리) + `ui/components/`(주제 썸네일·이미지 카드·이미지 선택 창·출처 표시·Placeholder). 공통 제공자 인터페이스: `search(query, page, count, orientation)`·`get_photo(photo_id)`·`track_download(download_location)`·`get_rate_limit_state()`·`health_check()`, Unsplash 전용 필드는 제공자 안에서 공통 ImageAsset 으로 변환.
- **시험:** 단위(검색어·응답 변환·출처 문자열·UTM·한도 상태 파싱·중복 제거·선택 시 다운로드 알림·키 마스킹·캐시 만료) / 통합(정상·결과 없음·401·403·429·5xx·Timeout·Offline·이미지 선택·이미지 없이 진행·로컬 이미지) / UI(Skeleton·Placeholder 대체·선택 상태·출처 표시·Tooltip·Windows 125%·크기 변경). 실제 API 반복 호출보다 **Mock 응답이 기본**.
- **산출 문서:** `docs/UNSPLASH_INTEGRATION.md`·`IMAGE_PROVIDER.md`·`IMAGE_ATTRIBUTION_POLICY.md`·`IMAGE_CACHE.md`·`API_KEY_SECURITY.md`·`TROUBLESHOOTING.md`·`CHANGELOG.md`, README 에는 4줄만(선택 기능·키 등록 위치·출처 표시 원칙·한도 소진에도 초안 가능). **릴리스·설치:** 키는 Release Asset 에 없음·키 없이 설치/실행/기본 Placeholder/로컬 이미지 가능·업데이트 뒤 자격 증명 유지·스키마 변경 시 이미지 메타데이터 마이그레이션·마이그레이션 전 DB 백업·이미지 기능이 베타면 릴리스 노트에 표시.
- **구현 순서 5단계:** ① 기존 블로그 연동 분석·재사용/재작성 구분·ImageProvider 인터페이스·보안 저장소 연결 ② 검색·응답 변환·썸네일·출처·한도 상태 ③ 기본 추천 자동 선택·선택 창·다운로드 추적·이미지 없이 진행·로컬 이미지 ④ 메타데이터 저장·캐시·지연 로딩·오프라인/Placeholder·초안 결과 연결 ⑤ 오류 상태·화면 스레드 분리 확인·Mock 시험·설치/업데이트 시험·문서. **구현 전 13항목 사전 보고**(§24: 블로그 연동 위치·엔드포인트와 응답 필드·핫링크·다운로드 알림·출처 표시·UTM·키 저장 방식과 노출 위험·재사용 코드·새 파일·한도/오류 처리·시험 계획·기존 기능 영향·운영자 확인 사항) — **기존 구현이 공식 규칙을 못 지키면 그대로 복사하지 말고 수정안을 먼저**. 끝나면 정상·한도 초과·오프라인·결과 없음·이미지 없이 진행 화면을 캡처해 보고.
