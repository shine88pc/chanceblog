**운영자 지시(2026-11-03 19:24, 채팅):** "창 띄우지 말고 조용히 진행해줘." 이 PC 는 운영자가 쓰는 회사 PC 이고, GUI 시제품 작업 중 창이 화면에 떠서 방해가 된 것으로 보인다.

**Why:** 작업 방해(화면에 창이 깜빡임)를 피하고 싶다. 결과는 사진·표·보고로 받는다.

**How to apply (모든 에이전트·내 작업에 상시):**
- **창을 화면에 띄우지 않는다**: pywebview 창·PyInstaller 로 만든 exe 실행·Qt 창·브라우저/탐색기/메모장 열기·콘솔 창 포함. 자식 프로세스는 `creationflags=0x08000000`(CREATE_NO_WINDOW)·`startupinfo` SW_HIDE.
- **Qt**: `QT_QPA_PLATFORM=offscreen` + `widget.grab().save()`(한글은 `QT_QPA_FONTDIR` 필요 — 없으면 네모).
- **웹/pywebview 화면 사진**: 헤드리스 Edge — `msedge.exe --headless=new --disable-gpu --hide-scrollbars --window-size=W,H --force-device-scale-factor=S --user-data-dir=<임시> --screenshot=<png> file:///…`(pywebview 는 WebView2 = Edge 엔진이라 같은 모양). 상호작용 상태는 주소 인자(`?state=drawer`)로 바로 그림.
- **pywebview 실행 측정**: `create_window(hidden=True)`; 안 되면 기존 측정값 재사용 또는 '측정 안 함'. 숨김은 렌더 타이머가 느려질 수 있음(보고에 명시).
- **화면에 띄워야만 확인되는 것**(실제 IME·DPI 렌더·`PrintWindow` 캡처·스크린 리더)은 하지 않고 '운영자 요청으로 안 함 — 정식 단계에서 운영자 확인 또는 숨김 시험'으로 보고.
- 알림음·토스트 알림 금지(기존 규칙: 앱 푸시 알림 없음), 사용자 클립보드는 시험 뒤 원래 내용으로 되돌림.
- 데스크톱 앱의 **정식 GUI 시험**도 offscreen/헤드리스/숨김이 기본(UI 시험 설계에 반영).

**추가 지시(2026-11-03 19:27, 채팅):** "창이 띄워 확인해야 되는 것들은 21시 이후에 진행해줘." → **창을 띄워야만 되는 확인은 21:00 이후에 모아서 짧게**(합계 15분 이내, 창은 한 번에 하나·각 10초 이내·끝나면 즉시 종료). 21:00 전에는 보이는 창 금지(offscreen·헤드리스·숨김만). 21시 이후 묶음의 내용: 실제 보이는 pywebview/Qt 창 실행 측정, 창 단위 `PrintWindow` 캡처(그 창 하나만 — 전체 화면 캡처 금지, 다른 창이 찍히지 않았는지 사진을 열어 확인), 번들 exe 실행 시간·메모리, 실제 클립보드 복사(시험 전 내용을 저장했다가 복원), 실제 Tab·Esc·Enter 포커스. **시스템 설정 변경(Windows 화면 배율 125% 등)은 21시 이후에도 하지 않는다**(흉내 사진 + '운영자 PC 에서 직접 확인'). 실제 IME 조합·화면 읽기 프로그램은 자동화 불가라 '운영자 확인 필요'. 시간 기준은 시스템 시각(`Get-Date`)이고 PC 는 23:00 에 재부팅되므로 21:00~22:30 안에 끝낸다. 이 규칙은 앞으로의 정식 GUI 시험에도 적용(낮에는 창 없는 시험, 창 확인은 저녁 묶음).

**정정(2026-11-03 20:22, 채팅) — 위 '21시 이후' 제한은 풀렸다:** "21시부터 창 띄워 확인해달라고 했던 요청을 정정하고 **지금부터는 창 띄워 확인하는 작업도 진행해도 돼**." → 창이 꼭 필요한 검증(실제 렌더링·포커스·클립보드·실행 시간·창 단위 PrintWindow)은 **언제든 해도 된다**. 단 습관은 유지: 같은 결과를 헤드리스·offscreen 으로 얻을 수 있는 반복 작업은 창 없이, 창은 한 번에 하나·짧게·끝나면 즉시 종료·마지막에 남은 창 0 확인, 전체 화면 캡처 금지(창 단위만), 시스템 설정 변경 금지(화면 배율 등), 시험 전 클립보드 복원, 실제 IME·화면 읽기 프로그램은 '운영자 확인 필요'. (18:50 시점의 '창 띄우지 말고 조용히 진행'은 '불필요하게 띄우지 않기' 수준으로 완화됨 — 새 지시가 오면 그것이 우선.)
