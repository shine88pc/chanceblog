확인 025(블로그를 어느 사이트든 더 많이 연결하도록 한도(다섯 칸·세 종류)를 풀기, 이슈 #207 의 '어느 사이트든' 후속, 요청 파일 R-394)에 운영자가 이슈 #226(2026-11-17 15:46 KST, 새 양식 대상번호 25→025, 선택 ④)로 **보류**를 골랐다 — 요청 글의 뜻: '지금은 정하지 않습니다(1 그대로와 같이 두되 다시 묻지 않고 기다린다)'. 승인(approve=2)이 아니다.

**Why:** 설계서(audit6/improve/blog_slots/design.txt)의 추천(블로그 목록 id 방식 5단계, 단계 1-4 약 40-62시간·약한 추정, 켜는 날 이후 옛 Package 로 돌아가면 옛 앱이 '업데이트하세요'로 멈춤, 티스토리 제외 D-01 정책 충돌 가능)이 크고, 운영자가 지금은 정하지 않기로 했다.
**How to apply:** 블로그 슬롯 한도·저장 형식 판 3·엔진 채널 변경 작업을 시작하거나 다시 묻지 않는다. 운영자가 먼저 꺼낼 때(예: 블로그를 여섯 개 이상 연결해야 하는 일이 생길 때)만 설계서에서 이어 간다. 다른 일(후속 정리 묶음 등)에서 이 한도를 건드리지 않는다. 관련: [[photo-analysis-local-only-directive]] (같은 날 확인 026 은 승인됨).
