## 2. 제한 재개 흐름과 PR 시험

흐름(이 순서로만): PIPELINE_PAUSE 유지 → 최소 품질 Gate 적용 → 그림자 모드 검증 → `publish_flow: pr` 검증 → 하루 최대 1편 PR 생성 → 사람 검토·승인 후 공개.

PR 시험: 실제 PR 3개를 연속 검토합니다. 3개 모두 승인 가능한 품질이면 제한 재개를 유지하고, 중간 이상 결함이 1건이라도 나오면 신규 생성을 중지하고 그림자 모드로 돌아갑니다.

**결함 등급 정의(제안 — 다르게 정하시면 알려 주세요)**

| 등급 | 예 |
|---|---|
| 필수 | 원문에 없는 사실·수치·인용·직함, 사실과 다른 서술, 건강 위험(C) 표현 누락, 출처 오귀속, 제3자 문장 대량 복제 |
| 높음 | 원문 핵심 사실 누락으로 독자를 오도, 번역 복제 통과, 회사 발표·행사 안내의 단순 요약, 필수 고지·출처 표기 누락, 근거 없는 인과·전망 단정 |

승인 가능한 품질 = 필수·높음·중간 결함 0건(낮음만 허용). 이 정의는 엄격해서 첫 PR 3개가 한 번에 통과하지 못할 수 있습니다(위험은 7번).

## 7. 가정·위험·확정 요청

**기본값으로 정한 가정(위임 규칙에 따라 결정하고 기록, 다르면 알려 주세요)**
1. 제한 재개 단계는 국문만 만듭니다(하루 1편 = 국문 1편, 영문 없음). 영문은 독립 각색 기준이 서고 통과한 글만 나중에 따로 공개.
2. '그림자 모드 3회·초안 10개'는 별도 실행 3번(같은 날 가능), 초안은 국문 10편 이상으로 셉니다.

**위험**
- **병합 지연**: 병합 부탁이 6–7건이라 일정의 가장 큰 변수입니다. 늦어지면 날짜를 다시 보고합니다.

- **엄격한 PR 시험**: 중간 이상 결함 1건이면 중지라 첫 3개가 한 번에 통과하지 못할 수 있습니다. 생성기가 기준을 못 맞추면 '제가 근거를 열어 초안을 쓰고 사람이 승인하는 수동 흐름'으로 바꾸는 안을 그때 제안하겠습니다.
