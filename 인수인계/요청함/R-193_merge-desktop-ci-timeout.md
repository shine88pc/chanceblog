## 이번 묶음이 하는 일
1. **자동 검사 한 칸의 제한 시간을 30분에서 40분으로** 올립니다. 시험이 늘면서 가장 느린 칸(Windows 3.10)이 방금 병합하신 M013 가지에서 **28분 34초**(시험 실행만 27분 27초) 걸려 한도 30분에 **1분 26초**만 남았습니다. 같은 코드도 GitHub 의 컴퓨터(러너)에 따라 속도가 ±20% 달라서 어느 때든 시간 초과로 칸이 빨갛게 끝날 수 있고, 그러면 '검사가 이미 초록일 때만 병합 부탁'이 막혀 같은 시간을 다시 기다려야 합니다.
2. 바뀌는 곳은 **숫자 하나(30→40)와 주석**뿐입니다. 검사가 도는 조건·권한·단계는 그대로이고, 한도를 확인하는 시험은 '40 이상'으로 조였습니다. 자동 PR 워크플로 파일에도 **머리 주석 두 문장**(시간 서술)만 새 값에 맞춰 고쳤고 실제 동작 부분은 바이트까지 같습니다.
3. 시험을 줄이거나 나누는 일은 **이번에 하지 않았습니다**(후속 — Windows 칸에서 오래 걸리는 시험을 가려내 줄이는 작업). 이 저장소는 공개라 GitHub 의 표준 러너 사용 시간은 무료여서 한도를 올려도 비용은 늘지 않습니다.
