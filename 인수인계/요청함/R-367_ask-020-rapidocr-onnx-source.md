# 확인 요청 020 — 이슈 #212: RapidOCR 비교용 모델을 어디서 받을까요 (결정은 한 가지)

> 이 글은 **질문**입니다. 이슈 양식 '[답변] AI 확인 요청에 답하기'에 **대상번호 020**·고른 보기(1·2·3)를 적어 올려 주세요(이 세션 채팅에 `020/2` 처럼 쓰셔도 번호 있는 목록 항목이라 그대로 유효합니다). **답이 없으면 1(하지 않음)** 입니다.

## 한눈에
- 확인 019 에서 승인하신 RapidOCR 모델 2파일은 `modelscope.cn` 에 있는데, 이 PC 의 **사내 웹 게이트웨이가 그 사이트 전체를 막아**(HTTP 502) 받지 못했습니다. 우회하지 않았습니다.
- 대신 **이미 승인하신 호스트 `huggingface.co`** 에 PaddlePaddle 공식 조직이 올려 둔 같은 PP-OCRv5 한국어 계열의 ONNX 저장소 두 곳이 있어, 그 파일 2개를 받아도 되는지 여쭙니다. 새 호스트도 새 패키지도 없습니다.

## 선택지
1. **하지 않음(기본)** — RapidOCR 비교는 보류하고 PaddleOCR 만 시험합니다.
2. **허락** — 아래 파일 2개(합 18,245,305 바이트)만 받습니다.
3. **다른 길** — 운영자께서 직접 ModelScope 원본 두 파일을 사내 게이트웨이 밖에서 받아 이 PC 폴더에 두시거나(파일 이름과 sha256 은 제가 드립니다), 변환 도구 경로(아래)로 가는 것 중 하나를 메모에 적어 주세요.

## 알려 드릴 해석의 한계 (숨기지 않습니다)
- 이 파일들은 ModelScope 의 RapidOCR 기본 파일과 **같은 파일이 아닙니다**(sha256 이 다름). 같은 PaddleOCR 계열을 Paddle 공식이 ONNX 로 내보낸 **별도 파일**이라 가중치가 같은지는 모릅니다. 그래서 비교 결과는 'RapidOCR 의 ONNX 실행 환경 대 PaddleOCR 의 실행 환경(같은 모델 계열)'으로만 말하고 'RapidOCR 기본 모델의 성능'이라고는 말하지 않겠습니다.
- 모델 카드가 사실상 비어 있어(인식 쪽 28바이트) 변환 방법과 원본과의 관계 설명이 없습니다. 라이선스는 태그로만 확인했습니다.
- RapidOCR 은 글자 목록(사전)이 필요합니다. 이미 받은 Paddle 한국어 모델의 `inference.yml`(96,039 바이트)에서 로컬로 만들 수 있다고 보며 **새로 내려받지 않습니다**. 안 되면 멈추고 보고합니다.
- RapidOCR 의 방향 분류와 시각화(`vis()`)는 쓰지 않습니다(쓰면 모델·글꼴을 더 내려받으려 합니다).
