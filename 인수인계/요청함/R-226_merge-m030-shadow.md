1. **그림자 모드 = 게시 결과에 영향을 주지 않고 글의 품질 신호만 재는 도구**입니다(확인 요청 006 항목 10 에서 정하신 '그림자 모드부터'). 글 폴더(`_posts`)의 글을 읽어 최소 분량·원문 링크·머리말·숫자 충실·번역 복제 의심·건강 위험 낱말·행사 문장 같은 **신호**를 내고, 보고서(JSON·마크다운)를 지정한 한 곳에만 씁니다. 신호를 점수 하나로 합치거나 합격·불합격을 정하지 않습니다.
2. **게시와 연결하지 않습니다.** 글을 만들거나 올리거나 초안으로 보내는 어떤 흐름(`generator.py`·`pipeline/run.py`·워크플로·레지스트리)도 이 도구를 불러오지 않는다는 것을 시험이 코드 구조와 글자 검색으로 못박습니다(뒤에 병합할 수동 그림자 워크플로 한 파일의 별도 프로세스 호출 한 줄만 예외로 적어 둠). 네트워크·시각·난수를 쓰지 않아 같은 입력에는 같은 출력이고, 입력 폴더·글 폴더·하드 링크·정션에는 절대 쓰지 않습니다(그런 `--out` 은 종료 코드 2 로 거절).
