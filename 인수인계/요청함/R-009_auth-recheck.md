# R-009 · 인증 점검 결과와 다음 확인 (R-002 후속)

## 결과
- 21:29 에 돌리신 `[Blogger 영문]` 인증 점검(실행 #40688268165): 시크릿 4종은 모두 인식됐고, 구글이 refresh token 을 **다시 거부**했습니다(`auth_expired`). 글·게시·저장소 변경은 없었습니다(쓰기 없는 점검).
- 값에 눈에 안 보이는 글자가 섞였다면 "지우고 썼다"는 안내가 떴을 텐데 없었으므로, 붙여 넣기 문제보다는 **토큰과 클라이언트가 맞지 않거나 토큰 자체가 무효인 쪽**일 가능성이 큽니다(추정).

## 먼저 확인할 것 (위에서부터)
1. **앱 게시 뒤에 새로 받은 토큰인가요?** 게시(In production) 전에 받은 토큰은 쓰지 마세요(`.github/editorial/BLOGGER_API_SETUP.md` §1-4). 게시 상태는 구글 클라우드 → Google Auth Platform → **대상(Audience)** 화면에서 **프로덕션**으로 보여야 합니다(R-005 에서 "했어요"라고 하셨어도 화면에서 한 번 더 확인해 주세요).
2. **세 개를 한 벌로 덮어쓰셨나요?** `BLOGGER_CLIENT_ID`·`BLOGGER_CLIENT_SECRET`·`BLOGGER_REFRESH_TOKEN` 은 토큰을 받을 때 쓴 **같은 클라이언트**의 값이어야 합니다. 새 프로젝트·새 클라이언트를 만드셨다면 옛 프로젝트의 ID·시크릿이 남아 있으면 짝이 안 맞습니다. 저장소 Settings → Secrets and variables → Actions 의 **Secrets 탭**에서 세 개의 갱신 시각이 모두 방금인지 봐 주세요.
3. 토큰을 **한 번만** 붙여 넣고 끝에 Enter 를 누르지 않았는지(가끔 끝에 줄바꿈이 같이 들어갑니다 — 이제 코드가 지우고 쓰지만 확인해 주세요).

## 로그 한 줄로 원인 가르기
