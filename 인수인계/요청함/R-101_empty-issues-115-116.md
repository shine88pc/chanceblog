# [R-101] 빈 요청 두 건(이슈 #115·#116) — 내용이 비어 있어 처리하지 못했습니다

> **요청이 있으셨다면 다시 알려 주세요.** 실수로 올리신 것이면 하실 일은 없습니다.

## 무엇이 보였나
- 11:28 의 이슈 #115 와 11:40 의 이슈 #116, 두 건 모두 **'해 주었으면 하는 일' 칸이 비어 있었습니다.** 나머지 칸(끝났다고 볼 기준은 비움·긴급도 보통·진행 범위 '논의·준비까지만')만 들어 있었습니다.
- 자동 접수 확인 글은 내용이 있든 없든 똑같이 달려서, 접수 확인이 왔어도 **제게는 읽을 내용이 없었고 아무 일도 시작하지 않았습니다.**
- 가능한 원인: 길거나 서식이 있는 글을 붙여 넣을 때 칸에 안 들어간 경우(11:26 의 지시서 #114 는 들어왔지만 매번 그렇게 되는 것은 아닐 수 있습니다), 또는 실수로 올리신 것입니다.

## 하실 일
1. 요청이 있으셨다면: 같은 양식에 **내용을 적어 다시 올려** 주시거나 **채팅으로** 말씀해 주세요(긴 글은 채팅이 더 확실합니다).
2. 실수로 올리신 것이면: 아무것도 안 하셔도 됩니다. 저는 빈 이슈를 닫지 않고 그대로 둡니다.

## 참고
- 먼저 올려 주신 작업 지시서(이슈 #114)는 R-100 에 적은 대로 진단표·허블 표준 글·내부 링크 후보·개선안을 준비 중이고, 사이트·광고·설정은 바꾸지 않았습니다.
