1. **'설정' 메뉴가 실제 화면이 됩니다.** 서비스를 묶음별(`발행·연결` 등)로 접고 펴며, 용도마다 카드 하나에 **이름·연결 상태·키 항목(가린 이름과 끝 4자만)·사용 설정 종류·한도 줄**(`오늘 12 / 100회 · 이번 달 340 / 27,000회`)과 쉬운 설명이 보입니다.
2. **읽기만 합니다.** 키를 넣거나 지우는 기능은 없습니다 — 화면에 **'화면에서 키를 넣는 기능은 아직 없어요.'** 라고 적혀 있습니다(키 입력 화면은 다음 묶음 P4f, 보안 독립 검증을 거쳐 따로 요청드립니다). 키 원문은 읽지 않고 **있는지만** 묻습니다.
3. **정직한 상태 말하기:** 호출 코드가 아직 없는 서비스는 '연결됨'으로 보이지 않고 `준비 중`·`연결 확인 필요`·`연결 안 됨` 으로만 말합니다. 검색광고 카드는 키 항목이 있거나 실제로 연결돼 있을 때만 보입니다.
4. **예시 표시:** 프로그램을 `--sample` 로 열면 가짜 데이터로 화면을 보여 주고 `예시` 라고 표시합니다(실제 값이 아님).
5. **홈 화면·나머지 메뉴는 그대로입니다**(홈 사진 10장 중 9장이 픽셀까지 같고 나머지 1장은 진단 정보의 초 단위 숫자만 다릅니다).
