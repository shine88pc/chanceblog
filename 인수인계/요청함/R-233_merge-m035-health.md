## 이번 묶음이 하는 일
앱의 **건강 판정기**(`topics/concepts.py`·`safety.py`)는 후보 만들기·초안 만들기·복사 전 관문이 함께 쓰는 '위험한 건강 문장(건강 C) 자동 중지' 규칙입니다. 독립 검증이 놓친 위험 문장을 찾아냈고, 이번 묶음이 그것을 보강합니다. **안전한 쪽으로만 바뀌게** 만들었습니다 — 기존에 중지로 읽던 글이 낮아지지 않습니다.
1. **늘 단정 + 해결류**: `요통 100% 해결`·`기침을 틀림없이 잡아주는 가이드` 같은 문장이 중지됩니다(소프트웨어 문장 `서버 오류 100% 해결` 은 그대로).
2. **즉각·기간 표현 확대**: `5분 만에`·`하룻밤`·`한방에`·`금세`·`일주일 만에`·`먹자마자` 등을 증상·질환·영양제 곁 효과 서술일 때만 읽고, 쇼핑 문장(`영양제 하루 만에 품절되는 이유`)은 그대로 둡니다.
3. **처방약 복용 중단 단정**: `수면제 끊고 좋아지는 방법` 같은 문장을 중지합니다(`의약품 구독 끊고 비용 줄이는 방법` 같은 비용 이야기 과탐은 없앰).
4. **낱말 경계**: 두 글자 증상(감기·설사·요통·기침·이명)을 낱말 처음에서만 읽어 `체감기온`·`시설사용료`·`설 사진`·`손목감기` 같은 일상 문장을 건드리지 않고, 진짜 증상 합성어(`열감기`·`심한요통`)는 증상별 수식어 표로 읽습니다. 새 증상 7개(복통·인후통·치통·관절통·콧물·무좀·습진)를 더했습니다.
5. 병적 입력(긴 반복·공백)에서 느려지던 것을 1초 안으로 고쳤습니다.

## 눈에 보이는 변화
- 앱을 쓸 때: 건강 효과를 단정하는 후보·초안이 **더 자주 '중지'**로 나옵니다(사람이 문장을 고쳐 쓰면 풀림, 우회 단추는 없음). 일상 문장·표시만/근거 확인 단계는 기준과 거의 같고, 일상 손글 340문장에서 새 과탐은 0 입니다. 후보 만들기 800개 중 일상 600개는 결과가 한 글자도 안 바뀝니다.

## 단계 보고
1. **변경 파일**: 11개(+2,257/−82). 판정기 `topics/concepts.py` 약 +500줄, `safety.py` 소폭, 시험 `test_topics_health_coverage.py`(새 파일 1,736줄)와 기존 시험 값 보정, 문서(결정 D-290–D-311·CHANGELOG·ARCHITECTURE·TOPIC_ENGINE_PLAN).
2. **시험**: 건강 판정 시험 모듈이 54개에서 152개로, 전체 42개 모듈 1,974개가 파이썬 3.12·3.10 모두 통과. 변이 점검(코드를 일부러 틀리게 해서 시험이 빨개지는지) 204곳 중 203 적발(1곳은 동작이 같은 동등 변이).
3. **독립 검증 3회**(구현자와 다른 AI, 읽기 전용, 자기가 만든 문장 약 38만 7천 번 판정): 1차 조건부 통과(높음 1: 늘 단정 + 해결류 미탐) → 2차 조건부 통과(높음 1: 한 낱말 마스크가 기준이 중지로 읽던 글 53건을 낮춤) → 모두 반영 → 3차 **통과**(**기준보다 낮아진 글 0**, 새 지적은 모두 낮음 D11–D13). 측정: 운영자 C 의도 생성 14,453문장의 중지율 46.9% → 97.6%.
4. **기존 기능 영향**: 서비스·화면·저장·보안·발행 코드 0 변경. 합성 확인: 뒤에 올릴 초안 작성 화면(P4e)과 합쳐도 충돌은 변경 기록·결정 문서 끝줄 둘뿐이고 문서·구조·건강 판정 시험이 통과합니다.
5. **데이터 이관**: 없음. **원복 방법**: 이 PR 을 되돌리는(Revert) 커밋 하나를 병합하면 됩니다.

## 정해 둔 것·한계 (운영자 확인 항목 — 위임 규칙의 안전 기본값으로 정해 두었고 다른 답을 주시면 바꿉니다)
1. 증상별 앞 수식어 표 159개·`이명` 뒤 말 27개는 **초기값**입니다. 표에 없는 수식어(`꽃샘감기`)와 수식어 둘이 붙은 합성어(`환절기목감기`)는 읽지 않아 표시만 단계로 남습니다.
2. 약 이름 + 복용 중단 + `줄이는`만 있는 글 90건은 근거 확인 필요로 남고, 일반 낱말(의약품·처방약·치료제) 곁은 결과어가 있어도 중지가 아닙니다. 반대로 비용 이야기(`인슐린 구독 중단하고 비용 개선하는 방법`)도 중지가 되는 새 과탐이 있습니다.
3. 증상 + 즉각 + `풀어보는` 은 효과로 읽습니다(`두통 퀴즈 한 번에 풀어보는 앱` 은 기준보다 올라가 중지).
4. `제거·퇴치·차단·정복` 이 즉각 표현 곁에서 효과로 읽히지 않는 것은 **기준과 같은 한계**입니다(읽게 할지 정해 주시면 반영).
5. 기준부터 있던 한 낱말 마스크 24개(`소화기`·`자세히` 등)는 글을 갈라 '표시만'으로 낮춥니다(기준과 같음).
- 낱말 규칙으로는 '건강 위험 문장 누락 0' 을 **보증할 수 없습니다**. 그래서 앱은 이 판정을 '자동 중지'에 쓰되 사람이 글을 읽고 복사·게시하는 흐름은 그대로입니다.
