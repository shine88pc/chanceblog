# 보완·재개 계획서(Phase 3) — 본문 (폰에는 싣지 않고 요청 열기로 읽습니다)

승인 전에는 아무것도 바꾸지 않는 **계획서**입니다. 11-04 실행안(`docs/analysis/chance-content-2026-11-04/15_execution_plan.md`)과 생성기 개선안(같은 폴더 `11_generator_improvement_plan.md`)의 갱신판이라, 겹치는 부분은 그 문서를 가리키고 바뀐 것만 적습니다. 용어: 이야기 = 국문·영문 한 쌍(S01~S26, 번호는 R-211 참조), 배치 = 한 번의 채팅 승인으로 바꾸는 글 묶음(5~10편).

## 1. 한눈에

1. **지금**: 새 글 자동 게시는 정지(운영자가 설정한 PIPELINE_PAUSE, 08:09 실행부터 확인). 기존 글과 사이트 배포는 그대로입니다. 정지는 워크플로만 막으므로 글을 고치는 병합 PR 은 정지와 상관없이 진행할 수 있습니다.
2. **감사 결론**: Chance 공개 50편 중 지금 그대로 둘 수 있는 글은 거의 없습니다(A 6·B 34·C 2·D 8). 문제는 글 몇 편이 아니라 '보도자료 한 건을 요약하고 원문에 없는 일반론으로 채운 글이 같은 틀로 반복되고 한·영이 번역 복제'인 구조입니다.
3. **순서**: ① 응급 정정(사실 오류, 10편) → ② 비공개·통합 결정(5개 이야기) → ③ 재작성(공식 자료로 대조 가능한 것부터) → ④ 영문 이식과 유지 글 보완 → ⑤ 이미지·분류명·내부 링크 정리. 배치마다 변경 목록·전후 비교·URL 영향을 보고하고 **채팅 승인 뒤에만** 적용합니다.
4. **재개**: 정지 해제는 마지막입니다. 먼저 승인 흐름(`publish_flow: pr`) 전제 확인 → 전환 병합(T3) → 알림 중복 방지 같은 AI 후속 → 생성 기준 보강 → 하루 상한 낮춤 → 해제 → 첫 초안 PR 을 사람이 읽고 병합 또는 닫기 순서입니다(§7).
5. **결정이 필요한 것**은 확인 요청 006 한 건에 12항목으로 묶었습니다. 답이 없으면 아무것도 바꾸지 않고 정지·읽기 전용을 유지합니다.
6. **승인 전에 하지 않는 것**: 공개 글 수정·통합·비공개 전환, 고정 페이지 문구, 광고 코드·표시, `ads.txt`, 커스텀 도메인, 재검토 요청, 생성기 변경.

## 3. 감사로 달라진 점 (11-04 이후 새 사실)

1. **AdSense 판정**(운영자 확인): '가치가 별로 없는 콘텐츠' 정책 위반. 11-04 점검표가 예상한 대로 글의 질과 운영 방식이 핵심이고, 광고 코드·ads.txt 는 원인으로 확인되지 않았습니다. 우선순위는 콘텐츠 > 구조 > 광고 코드입니다.
2. **정지 전까지 약한 글이 더 쌓였습니다**: 11-04 이후 이야기 6개(12편)가 같은 방식으로 생성됐고 사망 원인 누락(S25)·수치 귀속 오류(S23) 같은 문제가 있었습니다. 11-04 생성기 개선(트랙 G)은 아직 시작 전입니다.
3. **한·영이 어긋난 쌍 3개**(S06·S08·S15): 국문만 개선본으로 바꿨고 영문은 옛 글입니다. 11-04 후속 ①('영어 짝 글을 고칠지 따로 여쭙기')이 아직 물어지지 않았습니다 → 확인 요청 006 에 포함.
4. **번역 복제 22쌍**: 구글의 웹 검색 스팸 정책은 가치를 더하지 않은 대량 생성과, 번역·말바꿈으로 남의 자료를 재게시하는 것을 문제 삼습니다(대량 콘텐츠 남용·스크레이핑 항목). 이 사이트가 그 정의에 해당한다고 단정할 수는 없지만 닿을 수 있는 구조입니다.
5. **출처 이용 조건**: Pew 는 생성기가 RSS 요약만 쓰고 11-04 표본은 페이지를 읽어 기준이 다릅니다. 한국 출처 4편(식약처·NST)은 이용 조건 표시가 불명확합니다.
6. **Blogger 영문(검토 중)**: 안전 의심 4편·소개/문의/개인정보 페이지 없음·모든 글에 출처 0.
7. **루트 랜딩**: 본문 약 610자·광고 로더 스크립트·자체 소개/개인정보 없음·사이트맵에 없음(원인 확정은 아님).

## 7. 재개 계획 — 정지 해제만으로 끝내지 않기 (사람 승인 흐름 먼저)

**사실**: 정지 중에는 Chance 자동 글·Blogger 영문·한글 초안 생성·이슈 수정·이미지 교체·수동 실행이 모두 건너뜁니다(워치독은 침묵, 확인 필요 모음에 '자동 발행이 멈춰 있습니다' 표시). 사이트 배포·저장소 검사·PR 검사는 그대로 돕니다. 해제는 변수 삭제입니다.

| 단계 | 내용 | 주체·등급 |
|---|---|---|
| R0 지금 | 정지 유지. W0~W6 은 병합 PR 로 진행 | — |
| R1 전제 확인 | ① 저장소 Settings → Actions → General 의 'Allow GitHub Actions to create and approve pull requests' 켜짐 ② 휴대폰 PR 알림 ③ main 에 '병합 전 PR 필수·상태 검사 필수' 보호 규칙이 없음(봇이 main 에 이력 커밋을 올림) ④ AdSense 연동 사이트 확인(같은 계정으로 이미 확인) | 운영자 화면 확인 + 저 |
| R2 AI 후속 | 초안 PR 알림 중복 방지(항목 번호 통일), 건강 경고 DRAFT_WAITING 이 STALE 을 가리지 않게, 열린 초안 상한, 확인 필요 모음 즉시 실행과 '발행 대기' 텔레그램 알림 연결, 라벨 색·설명 통일, 승인 흐름에서는 새 글 알림이 가지 않게 | 저(T2, 독립 검증) |
| R3 생성 기준 보강 | 11-04 트랙 G: 입력 보강(피드 본문 사용) → 그림자 모드 검사 → 보류 승격(원화 환산·본문 링크·진짜 분량·한영 숫자 불일치부터 하나씩) → 분야별 지침. 취지는 '새 글이 감사에서 나온 문제(원문 핵심 누락·원문에 없는 일반론)를 다시 만들지 않게' | 저(T2/T3) |
| R4 전환 | `pipeline/blogs.json` 의 chance `publish_flow` 를 `pr` 로 바꾸는 병합 PR(시험 상수 함께). **병합 뒤에도 정지는 유지**해 전환이 실제 실행에 닿지 않게 함 | 운영자 채팅 승인(T3) |
| R5 해제 전 조정 | 하루 상한을 낮춤(예: 하루 1쌍), 열린 초안·브랜치 정리 | 운영자 승인(T3) |
| R6 해제 | 운영자가 변수 삭제 → 첫 실행 확인: 요약 `DRAFT_CREATED`·`DRAFT_OPENED`, PR 라벨 `초안`·`채널:Chance`, 변경 파일은 `_posts` 글 2개뿐, main 에는 이력 커밋 하나, 사이트 배포 없음 → 운영자가 원문과 수치를 대조한 뒤 병합 또는 닫기 → 병합 뒤 사이트 반영 확인 | 운영자 |

- **해제의 영향 범위**: 변수 삭제는 Blogger 영문·한글 초안 생성도 함께 재개합니다. 영문은 초안이 생겨도 운영자가 게시하지 않으면 공개되지 않습니다. Blogger 만 따로 멈추려면 레지스트리 `mode: off`(Blogger 는 이 값을 읽습니다, T3).
- **해제 게이트(추천)**: R2 완료 + R3 의 첫 보류 승격(핵심 오류 방지) 완료 + W0·W1 완료 전에는 해제하지 않습니다. 목표 시점은 약 1~2주 뒤입니다(11-04 점검표는 오래 멈추면 운영 중단으로 보일 수 있다고 지적 — 승인된 글로 1주 안에 재개를 권했습니다).
- 승인 흐름을 켜도 '사람이 눌렀다'가 곧 '가치 있다'는 뜻은 아닙니다. 병합 전 원문 대조·고유 가치 확인을 초안 PR 체크리스트에 두는 기존 구현을 그대로 씁니다.
- 첫 7일은 STALE·DRAFT_WAITING 알림 동작, 초안 PR 의 감사 기준 통과율, 승인 소요 시간을 관찰합니다.

## 8. Blogger 영문(검토 중)과 한글

- **영문**: 검토 결과가 나오기 전에는 읽기 전용입니다. 안전 4편의 처리와 소개·문의·개인정보 페이지 추가는 확인 요청 006 에서 묻습니다. 재작성·출처 보강(B 12편)은 검토 결과 뒤에 계획합니다.
- **한글**: 이번 조치 범위 밖(AdSense 미연결, 운영자가 직접 게시). 영문과 같은 문제(출처 없음·같은 틀)가 있을 가능성이 높아, AdSense 를 연결하기 전에 같은 기준으로 점검하는 것을 권합니다(별도 요청).

## 9. 위험과 한계

- 구글은 통과 기준을 공개하지 않습니다. 글을 고쳐도 재검토 통과는 보장되지 않고, 재검토 요청은 운영자만 합니다(게이트 G1~G8 통과 + 마지막 구조 변경 뒤 14일 관찰 + 한 번만).
- 색인·노출 신호는 Search Console 에서만 볼 수 있습니다(§10).
- 글 수를 줄이면 색인된 주소·검색 유입에 영향이 있습니다. 비공개 글은 404 가 됩니다(리다이렉트 플러그인 없음). 통합 때 주소 처리 방식은 배치 보고서에 적습니다.
- 같은 계정·같은 날 신청한 두 사이트의 상호 영향, 검토 중 수정이 심사에 미치는 영향은 확인하지 못했습니다(미확인).
- 원문 대조의 한계: Pew·OpenAI·SAM.gov 등 열지 못한 원문, 요약 도구 기반 대조.
- 정지가 길어지면 운영 중단으로 보일 수 있어 재개 목표 시점을 정하는 편이 좋습니다(§7).
- 작업량은 11-04 추정(AI 약 65시간, 운영자 승인 약 12건)과 같은 규모입니다.
