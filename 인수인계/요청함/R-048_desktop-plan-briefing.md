# [R-048] 데스크톱 프로그램 구현 계획 브리핑

> 채팅에서 요청하신 브리핑을 그대로 보냅니다(2026-11-02 18:40 기준). **하실 일은 없습니다.**

## 한 줄 요약
프로그램의 부품(글 만들기·변환·원고 보관·네이버 꾸러미·올리기·배포 확인)은 새 저장소 main 에 병합됐고, 지금은 이 부품들을 하나의 흐름으로 묶는 중입니다. **화면과 설치 파일은 아직 없습니다.**

## 1. 무엇을 만드나
- 개인 PC(Windows 10/11)에서 글을 쓰고 → 검사하고 → 미리 보고 → 승인하면 GitHub Pages·Blogger·네이버용으로 내보내는 프로그램입니다. AI 없이도 핵심 기능이 모두 동작하고, 무료 AI 는 켜야만 쓰는 보조입니다(기본 꺼짐).
- 블로그 자동 발행은 `chanceblog` 저장소에 그대로 둡니다. 프로그램은 새 저장소 `chanceblog-desktop` 에서 따로 만들고, chanceblog 사본을 연결해 글 파일을 만들어 올립니다. 배포는 기존 자동 흐름이 합니다.
- 안전 규칙: 올리기는 승인한 뒤에만 하고, 비밀과 게시 전 원고는 저장소에 두지 않으며, 의심스러우면 내보내지 않고, 오류는 정해진 코드와 안내 문구로 설명합니다.

## 2. 현황 — 운영자 우선순위 12개 기준
| 우선순위 | 상태 |
|---|---|
| ① 프로그램 구조 | 부품 단위 완료 |
| ② 개인 PC 이관 | 문서는 완료, 실제 이관은 PC 준비 후 |
| ③ Pages 발행 | 코드 완료(화면 없음) |
| ④ Blogger 초안 | 대기(구글 OAuth 발급 필요) |
| ⑤ 네이버 A/B 프로필 | 틀 완료(블로그 B 정보 대기) |
| ⑥ 네이버 복사 꾸러미 | 완료 |
| ⑦ 반자동(확인 뒤 올리기) | **진행 중** |
| ⑧ 발행 상태 관리 | 모델·보관함 완료, 흐름 연결은 진행 중 |
| ⑨ 버전·변경 이력 | 파일은 있고 화면 표시는 대기 |
| ⑩ 설치 파일 | 대기 |
| ⑪ 업데이트·백업·복구·로그·오류 | 오류 안내·백업/복구·로그 가리기는 완료, 업데이트는 대기 |
| ⑫ 다른 AI 이어받기 문서 | 완료(계속 갱신) |

- 오늘 병합된 R-047 에는 글 만들기, 마크다운 변환, 원고 보관함, 네이버 A/B 꾸러미, 안전 고치기, Pages 발행, 배포 확인이 들어 있습니다. Chance 와 글자까지 똑같은 글 파일을 만들도록 시험으로 고정했습니다.
- 확인 수준: 시험 680개 통과, 일부러 코드를 망가뜨려 본 점검 700곳 넘게 모두 적발, 자동 검사 4칸 초록.

## 3. 지금 만드는 중 — 서비스 계층 + 명령줄 도구
- 부품을 "원고 가져오기 → 미리보기 → 승인 → (확인 뒤) 올리기 → 배포 확인 → 상태 기록" 한 흐름으로 묶습니다. 점검 기능(`doctor`)도 넣습니다.
- 기본은 연습 실행이라 아무것도 올리지 않고, 확인 옵션을 줘야 올립니다.
- 명령줄은 운영자님이 쓰는 것이 아니라 화면을 만들기 전에 흐름을 시험하는 도구입니다.
- 에이전트가 40분 넘게 작업 중이고 중간 저장본이 올라와 있습니다(병합 대상 아님). 끝나면 다른 에이전트가 새 사본에서 독립 검증한 뒤(블로그에 실제로 올리는 코드라 필수) 병합 부탁을 새 번호로 드립니다.

- **개인 PC 로 옮기는 시점**: Git·Python 설치, GitHub 로그인, Windows 보안의 '스마트 앱 컨트롤' 상태 확인이 필요합니다. 그 전까지는 지금 PC 에서 개발과 시험이 가능합니다.

- **네이버 블로그 B 정보**: 주소·주제·대상 독자·말투·하루 편수를 받을 때까지는 틀만 만들어 둡니다.
