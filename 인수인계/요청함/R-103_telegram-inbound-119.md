# [R-103] 텔레그램으로 보낸 글을 제가 받게 하기 — 가능한 방식과 권장

> **지금 하실 일은 없습니다.** 11:49 에 올리신 이슈 #119 의 질문('텔레그램 메세지로 내가 보내도 내용 전달이 가능하도록 할 수 있어?')에 대한 답입니다. 진행 범위가 '논의·준비까지만' 이라 **아무것도 만들거나 켜지 않았습니다.** 고르시면 그때 준비하고, 답이 없으면 지금처럼 이슈 양식을 씁니다.
> 답하는 방법: 텔레그램의 **[답하기]** → 요청 번호 `r-103`(지금은 하이픈 포함) → 답변 **승인** → **선택** 칸에 `A=1` 처럼 적기. 채팅으로 말씀해 주셔도 됩니다.

## 한눈에
- **가능합니다.** 지금은 제가 텔레그램으로 알려 드리기만 하고(저장소 자동 실행이 봇으로 보냄), 운영자님이 보내시는 글은 받는 길이 없습니다. 보내시는 글을 받으려면 **누군가가 텔레그램에 온 글을 읽어서 저장소로 옮기는 장치**가 새로 필요합니다.
- 어느 방식이든 **운영자님 본인의 텔레그램 계정에서 온 글만** 받고(다른 사람이 봇에게 보낸 글은 버립니다), 받은 글은 **이슈로 올라갑니다.** 저장소가 공개라 **그 글도 공개**입니다 — 텔레그램 일반 대화는 종단간 암호화도 아니니 **비밀번호·키·개인정보는 보내지 마세요.**
- 봇 열쇠(토큰)는 이미 저장소 비밀 보관소에 있고 저는 값을 볼 수 없습니다. 새 방식도 코드·글에는 쓰지 않습니다.

## 방식 비교
| | ① 예약 읽기(권장 시작점) | ② 바로 전달(중계 서버) | ③ 지금처럼(기본) |
|---|---|---|---|
| 어떻게 | 저장소 자동 실행이 정해진 때마다 봇에 온 새 글을 읽어 '텔레그램에서 온 요청' 이슈로 만듭니다 | 텔레그램이 글이 올 때마다 무료 중계 서버(Cloudflare 등)에 알리고, 중계 서버가 저장소 자동 실행을 깨워 이슈를 만듭니다 | 이슈 양식([요청]·[답변])을 씁니다 |
| 걸리는 시간 | **수십 분~수 시간** — 저장소 예약 실행은 늦게 돕니다(오늘 Chance 정기 실행도 약 2~3시간 간격) | 거의 바로(1분 안쪽) | 바로(제가 수 분 안에 봅니다) |
| 새로 필요한 것 | 없음(저장소 자동 실행 파일 1개 + 기존 비밀 2개 이용) | **무료 계정 만들기와 열쇠 1개 새로 보관**(이 저장소 자동 실행 깨우기 권한만 있는 토큰을 제3자 서버에 둡니다), 운영자님이 약 15단계를 직접 | 없음 |
| 승인 등급 | T3(비밀·새 자동 실행) — 승인 뒤 병합 | T3(새 계정·제3자 보관) — 승인 뒤 운영자님이 직접 설정 | — |
| 장점 | 계정 만들 일이 없고 되돌리기 쉽습니다(파일 1개 삭제) | 대화처럼 빠릅니다 | 이미 되고 있습니다 |
| 단점 | 급한 일에는 느림(승인·메모처럼 '답이 없으면 기본값' 인 것에는 충분) | 직접 해야 할 단계가 많고 계정·토큰 관리 부담, 중계 서버가 멈추면 전달 안 됨 | 휴대폰에서 양식 입력이 번거로울 수 있고, 최근 빈 이슈 두 건처럼 내용이 안 올라간 일이 있었음 |

- 제가 권하는 순서: **먼저 ① 로 시작**하고, 느려서 불편하면 그때 ② 를 안내서와 함께 준비합니다. ① 이 쓸 만한지 며칠 써 보고 정하는 것이 안전합니다. 저장소 자동 실행을 24시간 계속 켜 두는 방식(1분마다 읽기)은 GitHub 이용 조건과 맞지 않을 수 있어 **권하지 않습니다.**
- ① 이든 ② 든 **받은 글의 처리**는 지금과 같습니다 — 이슈로 올라온 글을 제가 읽고, 번호 요청이면 답으로 처리하고, 그 밖의 글은 새 요청으로 접수 확인을 보냅니다. 승인이 필요한 일(광고·사이트·자동 발행 설정·비밀)은 텔레그램 글만으로 진행하지 않고 번호 요청으로 한 번 더 확인합니다.

## 결정해 주세요 (기본값 있음)
- **A 텔레그램으로 받기**: `0` 하지 않음·지금처럼 이슈 양식(기본) / `1` **① 예약 읽기를 준비**(동작 방식 초안·자동 실행 파일 초안·시험 계획을 문서로 보내고, 승인하시면 병합 부탁) / `2` ② 바로 전달 **안내서**를 먼저 준비(계정 만들기 단계표)
- 참고 질문(필수 아님, 편하실 때): 텔레그램으로 주로 무엇을 보내시려는지(요청·답변·긴 글), 지연이 수십 분~수 시간이어도 괜찮은지, 보낸 글이 공개 이슈로 올라가도 괜찮은지.
