2. **항목별 승인**: 승인 전 → **사용 중**(승인)·승인 전 → 쉬는 중·사용 중 ↔ 쉬는 중으로 바꿉니다(되돌릴 수 없는 전환은 서비스가 거절). **여러 개를 한꺼번에 바꾸기는 확인창이 먼저**(개수·처음 몇 개 이름·되돌릴 수 있음을 사실대로, 처음 포커스는 취소)이고 **전부 바뀌거나 하나도 안 바뀝니다**(한 번의 원자적 쓰기).
3. **고치기·새로 등록**: 우선 표시·제외 키워드·우선 키워드·허용 채널·제안 이유처럼 서비스가 이미 검사하는 칸만 고칩니다(칸 옆에 쉬운 문장). 새 Seed 는 **승인 전으로만** 등록됩니다(한 번 더 승인해야 쓰입니다).
4. **제안 파일 불러오기**: 파일 위치를 고르면 미리 보기(읽기뿐) → 확인창 → **모두 승인 전으로** 등록합니다(이미 있는 Seed 는 건너뜀). 명령줄 `topics seeds import` 의 화면판입니다.
5. **180일 '쉬게 할까요?' 제안**은 배지와 문장으로만 보이고 **자동으로 적용되지 않습니다**(누를 때만). **삭제 기능은 만들지 않았습니다**(쉬게 둘 뿐).
6. **쓰기는 서비스 한 곳**(`service/seed_manage.py`): 낡은 판 거절·잠금·**직전 사본(`.bak`)을 먼저**·임시 파일 교체·**다시 읽어 확인**하고 다르면 쓰기 전 상태로 복원하며, 승인 전 Seed 안전망(`_guard`)이 쓰기 직전에 '새 Seed 는 모두 승인 전·바뀐 상태는 사용자가 부른 것뿐' 을 강제합니다. 키·토큰 모양 글은 거절하고 새 오류 코드는 없습니다.
