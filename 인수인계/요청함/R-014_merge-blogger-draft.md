# R-014 · 한글·영문 Blogger 켜기 PR 병합 부탁

## 한 줄
R-011(한글)·R-015(영문)에서 승인(A)해 주신 대로 **두 Blogger 블로그를 초안함 업로드(`draft`)로 켜는 변경**을 한 PR 로 준비했습니다. 병합해 주세요. 병합해도 글은 Blogger **초안함**에만 올라가고 **공개는 사용자님이 직접** 합니다.

## 하실 일 (2분)
1. 저장소 첫 화면(https://github.com/shine88pc/chanceblog) 맨 위의 노란 **"ai/claude/blogger-draft-on had recent pushes" — Compare & pull request** 배너를 누릅니다. 배너가 안 보이면 이 주소를 엽니다: https://github.com/shine88pc/chanceblog/compare/main...ai/claude/blogger-draft-on?quick_pull=1
2. **제목은 그대로 두고** 초록 **Create pull request**. 제목 앞쪽의 `Ad-Surface-Approved: …` 는 광고 표면 파일(`_config.yml`)을 승인받아 바꿨다는 **승인 기록**이라 지우면 안 됩니다.
3. 화면 맨 아래 검사가 모두 초록(All checks have passed)이 될 때까지 2~3분 기다린 뒤 **Squash and merge → Confirm squash and merge**. **Delete branch 는 누르지 않습니다.**

병합하셨는지는 제가 직접 확인합니다.

## 바뀌는 것 (승인 A 범위만)
- `pipeline/blogs.json`: 한글 Blogger(kcyoon)와 영문 Blogger(macat0722)의 `mode` 를 `off` → **`draft`**. (`auto`·광고·프로필·프롬프트·주제·톤·금지·고지문은 **수정 없이 그대로**입니다.)
- `_config.yml`: `exclude` 에 **`blogger_ko_history.json` 한 줄**(한글 이력 파일이 사이트에 공개되지 않게. 영문 이력 파일은 이미 제외돼 있습니다).
- 빈 이력 파일 `blogger_ko_history.json`(내용 `[]`) 1개: 사이트 점검 시험이 "제외 목록의 파일이 실제로 있는지"를 확인하기 때문이며, 첫 실행 때 봇이 채웁니다.
- 옛 값(`off`)을 못박았던 시험과 문서를 새 상태에 맞게 고쳤습니다.

## 병합하면
- 매일 **영문 11:00(KST)**·**한글 12:30(KST)** 에 글 1편씩을 만들어 각 블로그의 Blogger 초안함에만 올립니다(광고는 계속 끔). 오늘 11시 전에 병합하시면 오늘부터 시작합니다.
- 병합부터 첫 글이 올라올 때까지 **빨간 알림이 올 수 있습니다**: 영문은 마지막 활동이 10월 25일 기록이라 "영문 Blogger 멈춤(마지막 활동 이후 N시간 경과)"이 **치명(빨강)** 으로 뜨고, 이슈가 열리고, `확인 필요 모음`에 해야 할 일 한 건이 생겨 텔레그램이 갈 수 있습니다. 한글은 "발행/초안 기록이 전혀 없습니다"(경고)입니다. **둘 다 첫 글이 올라온 뒤 다음 점검(12:30·00:30 KST) 때 저절로 닫히는 정상 알림이니 무시하셔도 됩니다.** 첫 글이 올라왔는데도 남거나 글이 안 올라오면 제가 원인을 읽고 알려 드립니다.
- **정정(Gemini 한도)**: R-011·R-015 에 "한도 관리 장치가 막아 준다"고 적었는데 틀렸습니다. 지금은 호출을 세어 기록만 하고(측정 전용) 한도를 자동으로 지켜 주는 장치는 아직 없습니다. 대신 블로그마다 하루 1편·재시도 제한이 있어 글 한 편은 보통 1~3회(최악 약 11회) 호출이고, 영문 11:00·한글 12:30 은 Chance 슬롯(09·18시)과 겹치지 않아 분당 한도는 문제없어 보입니다. 하루 한도는 같은 키를 함께 쓰므로 첫 주에는 실행 요약의 "Gemini 호출: N회" 줄을 제가 계속 확인합니다.
- **바로 첫 글을 보고 싶으시면(선택)**: Actions → `[Blogger 영문] 글 자동 작성`(또는 `[Blogger 한글] 글 자동 작성`) → Run workflow → **"연습 실행" 체크를 풀고** 나머지는 그대로(글을 어디까지는 반드시 **draft** — `publish` 를 고르면 즉시 공개되니 건드리지 마세요) → 초록 Run workflow. 몇 분 안에 Blogger 초안함에 글이 생기고, 결과는 제가 읽습니다. 안 하셔도 정해진 시각에 저절로 돕니다.
- 첫 초안은 **초안함에서 직접 읽어 보시고** 공개할지 정해 주세요. 공개 전에는 블로그에 보이지 않습니다. 실제 모델 글은 두 블로그 모두 처음이라, 길이·형식 검사에서 탈락해 글이 안 올라오는 날도 있을 수 있습니다(그때는 제가 원인을 읽고 알려 드립니다).
