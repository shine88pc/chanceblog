# 감사 리포트(Phase 2) — 본문 (폰에는 싣지 않고 요청 열기로 읽습니다)

읽기 전용입니다. 글·설정·광고·페이지를 바꾼 것은 없습니다. 이 리포트는 11-04 진단 묶음(`docs/analysis/chance-content-2026-11-04/`)의 **갱신·재검증판**입니다 — 그 묶음에 이미 있는 판단은 번호(S01–S20)로 이어 쓰고, 이번에 새로 확인한 차이만 강조합니다. '이야기'는 국문·영문 한 쌍(또는 단독 1편)이고 '글'은 파일 1편입니다. 분류: A 유지·보강 / B 재작성 / C 통합 / D 비공개. P1–P3 은 손볼 우선순위(1이 먼저)입니다.

가장 큰 문제 세 가지(11-04 진단과 같은 결론):
1. **원문 핵심이 빠지고 원문에 없는 일반론이 채워짐**: 원문을 열어 대조한 글 중 18편(9개 이야기)에서 '원문에 없는 추가 내용'이 확인됐고, 일부는 사실과 다릅니다(아래 §2).
2. **한·영이 같은 구조의 번역 복제**: 50편 중 44편(22쌍)이 소제목·문단·불릿·링크 수까지 같습니다. 국문만 개선본으로 바뀐 세 쌍(S06·S08·S15)은 한·영 내용이 어긋났습니다.
3. **독자가 얻는 새 정보가 적음**: 고유 가치(0–3점) 분포는 0점 2편·1점 42편·2점 4편·3점 2편입니다. 출처는 글마다 보도자료 1건이고 표·계산·여러 자료 대조가 있는 글은 개선본 몇 편뿐입니다.

11-04 진단과의 대조: 그 진단표에 있던 38편 중 30편이 같은 분류입니다. 다른 8편 중 4편은 11-04 이후 국문이 개선본으로 바뀐 글(S08·S15 국문)이거나 Pew 원문을 정책상 열 수 없어 근거 확인이 안 되는 글(S09 한·영)이고, 나머지 4편은 S03 한·영(통합 제안)과 S02·S06 영문(경계에 있던 글)입니다. 11-04 이후 생성된 새 이야기 6개(S21–S26, 12편)는 같은 문제를 그대로 가졌습니다 — 정지 전까지 약한 글이 계속 쌓이고 있었다는 뜻입니다.

## 6. 사이트 구조 발견 (요청서 §6 — 발견사항이며 원인 확정이 아님)

- **루트 랜딩(별도 저장소)**: 정적 페이지 1장, 가시 텍스트 약 610자(소개 문장 + 편집 원칙 카드 3개). '최근 글'은 JS 가 블로그의 글 목록을 불러와 6개 표시(JS 가 없으면 "불러오는 중"). AdSense 로더 스크립트 1개가 있고 광고 단위는 없음. 루트에는 자체 소개·개인정보·문의 페이지가 없고(링크만 블로그로 연결) 루트 주소는 사이트맵에도 없음. 루트 `robots.txt` 는 모두 허용 + 블로그 사이트맵 안내.
