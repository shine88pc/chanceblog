# 개인 PC 시험 — 휴대폰 원격으로 하는 순서 (0–8단계, 약 1시간)

> 이 글은 **부탁**입니다. 텔레그램에서 `012/1/내용` 처럼 번호/선택/내용으로 답해 주세요. **한 단계가 끝날 때마다 짧게 답해도 됩니다**(예: `012/1/0단계 통과`, `012/1/1-2 SmartScreen 창 떴음`). 답이 없으면 기본값(2번, 나중에)으로 두고 아무것도 바꾸지 않습니다.

## 먼저 읽고 시작해 주세요
1. 이 시험은 **개인 PC 의 표준 사용자 계정**에서 합니다(회사 PC 는 관리자 권한이라 안 됩니다).
2. **진짜 키·비밀번호·토큰은 어디에도 넣지 않습니다.** 키 칸에는 5단계의 **가짜 글자**만 넣습니다. 이 앱은 지금 어떤 서비스에도 접속하지 않습니다.
3. 각 단계의 **'이렇게 보이면 통과'** 와 다르면 **실패**입니다. 멈추지 말고 **화면에 보인 글자만** 적어 두고 다음 칸으로 가세요(아래 4번은 예외).
4. **멈추고 바로 알릴 일**: ① 앱을 열거나 쓰는 중에 **관리자 권한(예/아니요 또는 암호를 묻는 창)** 이 뜸 ② 앱이 키·비밀번호·계정을 달라고 함 ③ 앱이 브라우저를 열었는데 네이버 글쓰기 주소가 아닌 곳임 ④ 화면에 키처럼 보이는 긴 글자가 그대로 보임.
5. 설정을 바꾸라는 창이나 무언가를 설치하라는 창이 뜨면 **누르지 말고 창 이름만** 적어 주세요.
6. 휴대폰 원격이라 입력이 불편하면 아래 **상자 안의 글자는 길게 눌러 복사 → 원격 화면에 붙여 넣기**를 쓰세요(붙여 넣기가 안 되는 원격 앱이면 짧은 글자라 직접 입력해도 됩니다).

## 0단계 (5분) — 압축 파일이 온전한지
받은 세 파일(압축 파일 `ChanceBlogDesktop-0.1.0-preview.1-win64.zip`·확장자 없는 `SHA256SUMS`·`PACKAGE_INFO.md`)을 **한 폴더**에 둡니다.

**0-1. 표준 사용자 계정인지**
- Windows `설정` → `계정` → `내 정보`에서 내 이름 아래에 **`관리자`라는 글자가 없어야** 합니다. 있으면 관리자 계정이니 표준 사용자 계정으로 다시 시작하세요(계정 만들기는 6단계 준비 참고).
- 통과: 표준 사용자(관리자 아님).

**0-2. 악성코드 검사**
- 압축 파일을 길게 누르거나 마우스 오른쪽 단추로 → `Microsoft Defender로 검사`(쓰는 보안 프로그램의 검사).
- 통과: '위협이 없습니다'. 위협이 나오면 **압축을 풀지 말고** 이름만 알려 주세요. 쓴 보안 프로그램 이름도 적어 두세요.

**0-3. SHA-256 확인**
- 압축 파일이 있는 폴더를 파일 탐색기로 열고 **주소 표시줄을 한 번 눌러 `powershell` 을 쓴 뒤 Enter** → 그 폴더에서 PowerShell 창이 열립니다(관리자로 열지 않습니다).
- 아래 한 줄을 붙여 넣고 Enter:

```text
Get-FileHash .\ChanceBlogDesktop-0.1.0-preview.1-win64.zip -Algorithm SHA256
```

- `SHA256SUMS` 를 메모장으로 열어 **첫 줄 앞의 64글자**와 위 결과의 `Hash` 칸을 비교합니다(대문자·소문자는 같은 값).
- 통과: 64글자가 **한 글자도 다르지 않고** 같습니다. 다르면 풀지 말고 알려 주세요.

## 1단계 (10분) — 표준 계정에서 풀고 실행
**1-1. 압축 풀기**
- 내 계정 폴더(`C:\Users\내이름`) **바로 아래**에 `ChanceBlogTest` 폴더를 새로 만듭니다.
- 압축 파일 → `모두 압축 풀기` → 위치를 `C:\Users\내이름\ChanceBlogTest` 로 정하고 `압축 풀기`.
- 하지 말 것: `AppData` 안·`Program Files` 안·OneDrive 동기화 폴더(문서·바탕 화면)에는 풀지 않습니다.
- 통과: `ChanceBlogTest\ChanceBlogDesktop-0.1.0-preview.1` 안에 `ChanceBlogDesktop.exe`·`_internal`·`vendor`·`LICENSES` 폴더와 `VERSION`·`PACKAGE_INFO.md` 파일이 있습니다. 풀린 경로를 적어 두세요.

**1-2. 실행 — 관리자 권한 창이 뜨면 안 됩니다**
- `ChanceBlogDesktop.exe` 를 두 번 누릅니다.
- **파란 'Windows의 PC 보호' 창(SmartScreen)** 이 뜨면 `추가 정보` → `실행`. 서명 없는 Package 라 나올 수 있고 **떴다는 사실을 꼭 적어 두세요.**
- **방패 그림의 '이 앱이 디바이스를 변경하도록 허용하시겠어요?'** 가 뜨면 **실패**입니다 — `아니요` 를 누르고 멈춰서 알려 주세요.
- '스마트 앱 컨트롤이 앱을 차단했습니다' 가 뜨면 **이 PC 에서는 실행할 수 없는 것**입니다 — 설정을 바꾸지 말고 이 사실만 알려 주세요.
- 통과: `ChanceBlog Desktop` 창이 열리고 왼쪽에 `홈`·`주제 후보`·`초안 작성`·`Seed 관리`·`블로그 관리`·`설정` 메뉴가 보입니다. 관리자 권한 창은 한 번도 안 떴습니다.

**1-3. 버전·미서명 표시**
- 왼쪽 `설정` → 화면 맨 아래쪽 `정보` 줄을 눌러 펼칩니다.
- 통과: `버전 v0.1.0-preview.1 · 커밋` 다음에 **7글자**가 보이고(제가 확인한 앱 main 은 `83722d6` 이니 그렇게 보이는 것이 정상입니다 — 다르면 보인 7글자를 알려 주세요), 그 아래 **`개인 PC 제한 시험용, 미서명 Package`** 한 줄이 보입니다. 그 줄 끝에 `시험 빌드` 글이 이어져 있으면 멈추고 알려 주세요.

## 2단계 (10분) — 프로필·Seed·후보·초안 (시험용 값만)
- **블로그 등록**: 왼쪽 `블로그 관리` → 위쪽 카드들 중 **`네이버 A`**(`블로그를 등록해 보세요`·`비어 있음` 카드) → 입력 창에서 `표시 이름` 에 `시험 블로그 A`, `블로그 ID 또는 주소` 에 `testblog-a`(공백 없이) → `저장`. 통과: '저장했어요.' 와 `네이버 A` 카드가 `등록됨` 으로 바뀜.
- **Seed 등록**: `Seed 관리` → `새 Seed 등록` → `Seed 낱말` 에 `시험용 키워드`, `대분류`·`중분류` 에 `시험`, `중요도` 는 `일반`, `대상 유형` 은 아무거나(예: `제품`), `소속` 은 `네이버 A` → `승인 전으로 등록`. 이어서 목록의 그 Seed 를 눌러 열고 `승인하기`. 통과: '승인했어요. 이제 후보 생성에 쓰여요.'
- **후보 만들기**: `주제 후보` → `후보 만들기` → 확인 창에서 `만들기`. 통과: 목록에 후보가 하나 이상 생김('아직 후보를 만들 수 없어요' 가 나오면 그 이유 글을 적어 주세요).
- **초안 만들기**: 후보 하나를 눌러 상세에서 `이 주제로 만들기`. 통과: `초안 작성` 화면에 제목과 본문이 생김(AI 가 아니라 규칙으로 만든 글).
- **글자 하나 고치기**: 제목 맨 끝에 `!` 를 더합니다.
- **저장**: `저장` 단추(또는 Ctrl+S). 통과: '저장됨' 같은 표시. **저장 단추가 화면에 없으면 '실패(기능 없음)'** 으로 적어 주세요.
- (선택) `제목 복사` 후 메모장에 붙여 넣기 / `네이버 글쓰기 열기`(앱은 주소만 열고 로그인·입력·발행은 하지 않습니다).

## 3단계 (5분) — 저장하고 껐다 켜기
- 앱 창을 닫습니다(오른쪽 위 X). '저장하지 않은 내용이 있어요' 창이 뜨면 `계속 고치기` → 저장 → 다시 닫기.
- 같은 폴더의 `ChanceBlogDesktop.exe` 를 다시 엽니다.
- 통과: ① `블로그 관리` 의 `네이버 A` 카드에 `시험 블로그 A` 가 `등록됨` ② `Seed 관리` 에 시험용 키워드(승인된 상태) ③ `주제 후보` 에 후보 ④ 저장한 초안을 열면 **제목 끝의 `!` 까지 그대로**.
- 데이터 폴더 위치: 키보드 `Windows` + `R` → `%LOCALAPPDATA%` 입력 → Enter → 열린 폴더 안의 `ChanceblogDesktop` 폴더 경로를 적어 두세요(원격에서 키 조합이 안 되면 파일 탐색기 주소 표시줄에 `%LOCALAPPDATA%` 를 써도 됩니다).

## 4단계 (5분) — 백업과 복원
- `설정` → `백업·복원` → `지금 백업`. 통과: '백업을 만들었어요', 목록에 새 줄, 그 줄에 **`Credential 제외됨`** 표시, 상태 '완료'.
- `블로그 관리` 에서 `네이버 A` 카드의 `표시 이름` 을 `시험 블로그 AA` 로 한 글자 더하고 `저장`.
- 다시 `설정` → `백업·복원` → 방금 백업 줄의 `복원` → 확인 창에서 **무엇이 바뀌는지 읽고** `복원하기`. 통과: '복원을 마쳤어요', `블로그 관리` 이름이 **`시험 블로그 A`** 로 돌아옴.
- 백업은 같은 PC 의 사본이라 PC 가 고장 나면 같이 사라진다는 안내(USB 에 직접 복사해 두라는 글)가 보이는지만 확인.
- 백업·복원 기능이 화면에 없으면 **'실패(기능 없음)'** 으로 적어 주세요.

## 5단계 (5분) — 키 등록 (가짜 글자로)
- `설정` → `AI 보조` 줄을 펼칩니다 → **`AI 보조(선택)` 카드의 `키 등록`**. (설정 위쪽에 이미 펼쳐진 `NAVER API HUB 검색어 트렌드` 카드의 `키 등록` 은 **아닙니다**.)
- `별칭` 칸에 `시험`, `API 키` 칸에 아래 **가짜 글자**를 붙여 넣습니다(점으로만 보입니다). '너무 짧습니다'가 나오면 같은 글자를 두 번 이어 붙입니다.

```text
TEST-KEY-NOT-REAL
```

- `다음` → 확인 화면을 읽고(약관 확인 칸이 있으면 체크) `저장`.
- 통과: `저장된 키` 줄에 별칭(`시험`)과 등록 상태·시각만 보이고, **키의 앞·끝 글자나 `****` 같은 일부 글자가 어디에도 보이지 않습니다**(`REAL` 이나 `TEST` 가 보이면 실패).
- **키는 아직 지우지 마세요**(6-4 에서 지웁니다).

## 6단계 (20분) — 다른 일반 Windows 계정에서 첫 계정의 데이터·키에 못 닿는지
**준비**: 표준 사용자 계정이 **하나 더** 필요합니다(관리자 계정이면 안 됩니다). 없으면 `설정` → `계정` → `다른 사용자` → `계정 추가` 로 만듭니다 — `이 사람의 로그인 정보가 없습니다` → `Microsoft 계정이 없는 사용자 추가` 로 이름·비밀번호만 넣는 **로컬 계정**으로. **계정을 만들 때 Windows 가 관리자 계정의 이름과 암호를 묻는 창을 띄웁니다 — 앱 때문이 아니라 Windows 설정이 띄우는 것이고, 암호는 그 창에만 넣고 어디에도 적지 않습니다.** 관리자 암호를 모르면 계정을 만들지 말고 6-1·6-2·6-3 을 `실패(권한 없음)` 으로 적은 뒤 6-4 만 하세요.
- 첫 계정에서 압축 파일을 `C:\Users\Public\Documents` 에 복사해 둡니다(모든 계정이 보는 폴더).
- 두 번째 계정으로 로그인합니다(첫 계정은 로그아웃하거나 사용자 전환).

**6-1. 첫 계정 데이터 폴더 열기 시도**
- 파일 탐색기 주소 표시줄에 `C:\Users\첫계정이름\AppData\Local\ChanceblogDesktop` 을 쓰고 Enter.
- 통과: **'액세스 거부'**(또는 권한이 없다는 글)가 나오고 폴더 안이 열리지 않습니다. **`계속` 단추가 보여도 누르지 마세요**(권한이 바뀝니다). 폴더가 열려 버리면 실패입니다.

**6-2. 첫 계정의 키에 접근 못 하는지**
- 시작 → `cmd` → 검은 창에 아래를 쓰고 Enter:

```text
cmdkey /list
```

- 통과: 목록의 `대상:` 줄 중 **`ChanceBlogDesktop:` 이 들어 있는 줄이 하나도 없습니다.**

**6-3. 자기 계정의 빈 데이터로 시작하는지**
- 두 번째 계정에서 `C:\Users\Public\Documents` 의 압축 파일을 **두 번째 계정 폴더**(`C:\Users\둘째계정이름\ChanceBlogTest`)에 풀고 `ChanceBlogDesktop.exe` 를 실행합니다(SmartScreen 이 뜨면 같은 순서).
- 통과: 첫 계정에서 만든 `시험 블로그 A`·Seed·후보·초안·백업이 **하나도 보이지 않는** 빈 상태이고, `설정` 의 키도 모두 키 없음입니다. 이 계정에서도 관리자 권한 창은 안 떠야 합니다.

**6-4. 첫 계정으로 돌아와 키 지우기**
- 둘째 계정의 앱을 닫고 첫 계정으로 로그인 → 앱 `설정` → `AI 보조` → `AI 보조(선택)` 카드의 `삭제` → 확인.
- 통과: `저장된 키` 줄이 처음처럼 `연결 안 됨 — 키 없이도 쓸 수 있어요` 로 돌아옵니다.

## 7단계 — 결과 보고 (표를 복사해 채워 답장)
아래 표를 복사해 `통과`·`실패` 중 하나와 적어 둘 말을 채워 `012/1/` 뒤에 붙여 답해 주세요(필수 칸에는 '해당 없음'이 없습니다. 6-1에서 6-3 까지는 관리자 암호가 없어 계정을 못 만들었을 때만 `실패(권한 없음)`).

## 8단계 — 시험이 끝난 뒤 지우기 (이 앱은 설치 프로그램이 아니라 아래 곳만 지우면 깨끗합니다)

- **데이터 폴더**: `%LOCALAPPDATA%` 안의 `ChanceblogDesktop` 폴더를 지웁니다(두 계정 모두 — 시험 데이터와 백업이 들어 있습니다). **이 앱을 시험이 아니라 진짜로 쓰는 중이면(진짜 블로그·Seed·초안이 있으면) 지우지 마세요.**

## 막혔을 때 — 자주 막히는 곳
1. **압축이 안 풀리거나 풀다 멈춤**: 경로가 길거나 `AppData`·OneDrive 폴더 안입니다 → 1-1 의 위치에 다시 풀기.
2. **SmartScreen 창에 `실행` 단추가 없음**: `추가 정보` 라는 작은 글씨를 먼저 눌러야 `실행` 이 나옵니다. `추가 정보` 도 없이 막히면 스마트 앱 컨트롤 차단이니 설정을 바꾸지 말고 알려 주세요.
3. **`Get-FileHash` 가 '인식할 수 없다'고 함**: 줄을 직접 치지 말고 위 한 줄을 그대로 복사해 붙여 넣으세요. 압축 파일이 있는 폴더에서 PowerShell 을 연 것인지 확인하세요.
4. **두 번째 계정이 사실 관리자 계정이라 폴더가 열려 버림**: 그 계정은 시험에 쓸 수 없습니다 — 표준 사용자 계정을 새로 만들어 6단계를 다시 하세요.
5. **단추 이름이 다르거나 기능이 없음**: 이름이 다르면 같은 뜻의 단추를 고릅니다. 저장·백업·복원이 정말 없으면 '실패(기능 없음)' 으로 적고 알려 주세요.
6. **원격 화면에서 키보드 조합(Windows+R 등)이 안 먹음**: 시작 메뉴 검색이나 파일 탐색기 주소 표시줄을 쓰세요.
