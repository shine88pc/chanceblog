# 병합 요청 M092 — 오류 카드를 쉬운 말로 바꾸고 없는 메뉴 이름을 바로잡습니다(앱 L4)

> **병합 방식**: 지금은 AI 병합 기능이 **꺼져 있어** 운영자께서 직접 병합해 주세요. (`M092 승인` 이라고 답하셔도 아직 AI 가 병합하지 않습니다.) 이 요청은 앱 저장소 `chanceblog-desktop` 의 것이고, PR 제목 맨 앞이 `[M092]` 인 것 하나만 병합합니다. 검사는 이미 끝나 초록입니다. 급하지 않습니다(보통).

## 1. 무엇을 바꾸는지
① **오류 카드의 명령줄 말투(F028)**: 오류 코드 105개의 사용자 문구·하실 일을 모두 읽고 60행을 바꿨습니다. 명령줄·개발자 말투(`git config --global …`·`--data-dir`·'세부 줄' 같은 글)가 섞여 있던 54행은 사용자 문구와 하실 일을 누구나 읽는 쉬운 해요체로, 이름만 틀린 6행은 이름만 고쳤습니다. 카드는 쉬운 앞부분만 보이고, **옛 명령은 지우지 않고** '명령줄·개발자 안내:' 꼬리로 옮겨 명령줄 출력·점검(doctor)·JSON 은 전체 글을 그대로 씁니다. 안전 문구(지우지 마세요·덮어쓰지 않았어요·되돌릴 수 없어요)는 앞부분에 남겼습니다. ② **없는 메뉴 이름(F041)**: 화면에 없는 메뉴 이름 열한 가지를 실제 이름으로 바로잡았습니다(예: 백업·복구 → 백업·복원 네 곳). 시험이 '문구가 가리키는 이름이 실제 화면에 있다' 를 지킵니다.

## 2. 왜 필요한지
운영자 방침(세부는 추천안으로 진행하고 알리기만 함)으로 진행하는 화면 문구 묶음(L4)입니다. 오류 카드에 명령줄 글이 그대로 나와 일반 사용자가 읽기 어려웠고, 문구가 가리키는 메뉴가 실제 화면에 없는 곳이 있었습니다.

## 3. 사용자가 체감하는 변화
오류가 났을 때 카드의 설명과 '하실 일'이 쉬운 말로 보이고, 안내하는 메뉴 이름이 실제 화면과 같아집니다. 개발자용 명령은 카드에서 빠지고 명령줄 출력에는 그대로 남습니다. 화면의 큰 창·작은 창에서는 문구 길이만 달라지며 잘림은 없습니다(검증자 확인).

## 4. 위험과 기존 기능에 미치는 영향
- **기존 기능**: 저장 형식·백업·서비스 쓰기·네트워크·설정은 안 바뀌었습니다. 코드는 약 20줄(카드용 하실 일 고르기 함수 하나·내보내기·어댑터 한 줄·약관 안내 문체 상수 하나)이고 나머지는 오류 문서 표(정본)와 거기서 다시 만든 카탈로그·시험입니다. 명령줄 출력이 기대하는 명령 시험은 한 글자도 안 바뀌고 통과합니다.
- **알려 둔 한계**: 말투 문제가 없던 45행은 합니다체 그대로입니다(한 카드 안에서 문체가 섞이지 않게 바꾼 54행만 해요체). 서비스가 만드는 이유 글의 말투·콘솔 글(PySide6 가 없을 때 안내)은 범위 밖입니다. 새 표가 못박은 69문장 중 7문장은 화면의 200자 줄임 때문에 일부만 보입니다.
- **기존 시험 변경**: 의도한 문장 갱신으로 기존 시험 15개 파일 31곳의 기대 문장을 바꿨습니다(단언을 약하게 한 곳은 없고 강화만).

## 5. 시험·독립 검증 결과
- 새 시험 37개(순수 34·Qt 3): 고치기 전 코드에서 빨강이고 구현자 변이 40개가 모두 잡혔습니다.
- 독립 검증(구현자와 다른 AI 둘이 안전·화면·시험 두 관점으로): **안전 쪽 통과(필수 0·권고 2·참고 7)**, 시험 쪽은 첫 판정의 필수 2건(NAVER_PROFILE_MISSING 안내가 없는 화면을 가리킴·Qt 시험이 옛 문장을 못박음 — 앱 검사에는 PySide6 가 없어 못 잡던 것)을 모두 고치고 **델타 재확인 pass(필수 0)**. 권고는 반영했습니다.
