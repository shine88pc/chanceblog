2. **지어내지 않습니다** — 입력하지 않은 개인 경험·후기·협찬·가격·사용 기간·수치·날짜·효능·'써 보니' 같은 1인칭 체험·의료/법률/금융 조언·최상급 단정은 **여러 겹**(문단 틀 자체가 사실·수치·평가가 없게 쓰여 있음 → 문장마다 주장 검사 → 마지막 관문 → 키워드의 단정 낱말은 확인 권장 맨 위에 경고)으로 막습니다. 모르는 사실은 '확인 권장' 줄로 돌려 보내고 본문은 확인 없이도 참인 일반적인 확인 순서·기준만 씁니다. **사용자가 입력한 경험·의견은 그대로 먼저** 씁니다.
3. **엔진이 '자동 초안 중지' 로 표시한 후보**(건강 단정 등 안전 판정)는 **본문을 만들지 않고 거절**합니다. 건강·금융·법률 주제에는 전문가 확인 문단이 붙습니다. 키·토큰 모양 글은 입력 칸 어디에 들어와도 거절합니다.
