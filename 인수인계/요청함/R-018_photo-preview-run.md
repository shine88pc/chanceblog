# R-018 · 사진이 붙은 초안을 지금 확인하는 방법 (선택)

## 먼저 결과
- 대표 사진 기능(PR #74)이 병합됐고, main 의 검사·사이트 배포도 모두 초록입니다. **내일(10/30) 11:00 영문·12:30 한글 정기 실행부터** 초안 맨 위에 사진이 붙습니다.
- 오늘 올라간 첫 글 2편은 사진이 없습니다. 내일까지 기다리지 않고 **사진이 붙은 초안을 지금 보고 싶으시면** 아래처럼 한 번씩 수동 실행해 주세요. **안 하셔도 괜찮습니다**(내일부터 저절로 붙습니다).

## 하실 일 (영문·한글 각각 1분, 선택)
1. 저장소 **Actions** → **`[Blogger 영문] 글 자동 작성`** → 오른쪽 **Run workflow**.
   - **직접 정할 주제**: 아래 글자를 복사해 붙여 넣습니다 → `A gentle morning routine for people who hate waking up`
   - **연습 실행(기본 켜짐…)**: **체크를 풉니다**.
   - **글을 어디까지**: **`draft` 그대로**(`publish` 는 즉시 공개되니 건드리지 마세요).
   - **인증 점검만 실행**: 체크하지 않습니다.
2. 초록 **Run workflow**. 몇 분 뒤 초록이면 끝입니다.
3. **`[Blogger 한글] 글 자동 작성`** 도 같은 방법으로, **직접 정할 주제**에는 → `PC 바탕화면과 다운로드 폴더를 10분 안에 정리하는 방법`

주제 칸에 직접 적으면 "하루 1편 상한"을 건너뛰어 오늘 두 번째 초안이 만들어집니다(칸을 비워 두면 오늘은 상한 때문에 아무것도 만들어지지 않습니다 — 오류가 아닙니다).

## 그다음 (자동)
- 글이 올라오면 텔레그램에 "초안함에 올라왔습니다" 알림이 갑니다. 저도 실행 결과를 읽습니다.
- **Blogger 초안함**에서 새 초안을 열어 맨 위를 봐 주세요: ① 사진이 글 주제와 어울리는지 ② 사진 아래 `Photo by … on Unsplash` 줄이 깨지지 않고 보이는지 ③ 글 본문이 평소와 같은지. 사진이 없으면 이유는 제가 실행 화면의 알림으로 읽고 알려 드립니다(키가 없을 때는 알림 없이 사진만 빠집니다).
- 오늘 올라간 사진 없는 첫 글 2편은 Blogger 초안함에서 지우셔도 되고 그대로 두셔도 됩니다.
- 빨간 ✗ 로 끝나면 [답하기] → 요청 번호 **R-018** → 답변 '문제' 를 고르고 메모에 화면에 보이는 문구를 적어 주세요(비밀 값은 쓰지 마세요).
