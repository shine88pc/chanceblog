# 병합 요청 M106 — 글자 읽기 켜기 전 마무리 (앱)

> **병합 방식**: 지금은 AI 병합 기능이 **꺼져 있어** 운영자께서 직접 병합해 주세요. (`M106 승인` 이라고 답하셔도 아직 AI 가 병합하지 않습니다.) 이 요청은 앱 저장소 `chanceblog-desktop` 의 것이고, PR 제목 맨 앞이 `[M106]` 인 것 하나만 병합합니다. 검사는 이미 끝나 초록입니다. 급하지 않습니다(보통).

## 1. 무엇을 바꾸는지
운영자께서 글자 읽기를 켜기 전에 하실 첫 일(GitHub 에서 `Package OCR` 흐름을 한 번 수동 실행)을 앞두고, 독립 점검자와 안전 감사자가 짚은 것을 마무리합니다. **앱 본체·화면·워크플로 파일·잠금 파일은 한 글자도 바뀌지 않았고 글자 읽기는 꺼진 채입니다.**
① **고지문에 모델·글자 사전 절**: 추가 도구 폴더의 `THIRD_PARTY_NOTICES.txt` 에 글자 위치 모델·한국어 인식 모델·글자 사전의 이름·출처(저장소·커밋)·라이선스 표기를 더했습니다. 값은 잠금 파일·사전 출처 기록에서 읽고, 읽지 못하거나 모양이 이상하면(줄바꿈·마크다운·긴 값 등) 빌드가 멈춥니다. 저장소 카드 표기를 그대로 옮기고 새 사실을 지어내지 않습니다. GEOS 파일을 바꿔 끼우면 정보 파일의 그 줄도 고쳐야 한다는 안내 한 줄도 더했습니다.
② **빌드 안내 문서 정정(`docs/PACKAGE_OCR.md`)**: 이미 병합된 흐름인데 '병합되기 전' 처럼 낡게 적힌 말, 합치기 전 실측이던 숫자(이 PC 에서 합친 최종 코드로 진짜 빌드: 점검 문제 0·묶음 파일 144개)를 바로잡고, 운영자 단계(3절)에 휴대폰/PC 구분·`Package OCR` 와 본체 `Package` 이름 혼동·압축 풀기 대상 칸 함정·걸리는 시간(AI 추정 10–20분)을 더했습니다. **액션 SHA 세 개 예비 대조 표**(checkout v4.4.0·setup-python v5.6.0·upload-artifact v4.6.2 — 공식 릴리스와 일치, **AI 예비 대조이며 운영자 대조를 대신하지 않습니다**)와 켜기 전 운영자 질문 후보 다섯(11절)을 정리했습니다. `ocr_addon/README.md`·`NOTICE` 의 낡은 표현도 고쳤습니다.
③ **시험 46개**: 고지문 값이 줄 단위로 맞는지·값 모양 문·문서에 정확한 해시·바이트 수가 없는지 등을 시험이 지킵니다.

## 2. 왜 필요한지
점검자(OCR-W1)가 '첫 수동 실행 전 준비' 에서 증거 빈틈(문서의 실측치가 합치기 전 값)과 문서·고지문 보강 여섯을 짚었고, 감사자(OCR-S1)의 권고와 맞물립니다. 운영자께서 헛걸음하지 않고 첫 실행을 하실 수 있도록 글과 고지문을 먼저 바로잡았습니다.

## 3. 사용자가 체감하는 변화
**없습니다.** 앱 화면·동작은 그대로이고 글자 읽기는 꺼진 채입니다. 병합 뒤 운영자께서 첫 수동 실행을 하실 때 문서(3절)가 더 정확해집니다.

## 4. 위험과 기존 기능에 미치는 영향
- **기존 기능**: 앱 본체·`.github/`·잠금 파일·모델 잠금·앱의 추가 도구 확인 코드·`LOCAL_OCR` 는 바뀌지 않았습니다(추가 도구 빌드 코드 1개와 시험·문서뿐). 이 PC 에서 합친 코드로 진짜 빌드를 세 번(+같은 입력 반복) 돌려 점검 문제 0·고지문이 같은 입력에서 바이트까지 같음을 확인했습니다(러너가 아님).
- **알려 둔 한계**: ① GitHub 러너에서의 첫 실행은 여전히 **한 번도 안 돌려 봤습니다**(운영자 몫 — 3절 순서대로 한 번 실행해 결과를 알려 주세요) ② 고지문 [1] 표의 numpy 라이선스 파일 개수가 실제보다 많이 적힙니다(표 20 대 실제 18 — **시작점부터 있던 문제**, 같은 내용의 파일 두 쌍이 겹친 것이라 라이선스 글 손실은 없음, 후속에서 고침) ③ 시험 보강 권고 둘(값 모양 시험의 끝 줄바꿈 변종·문서 약속을 지키는 시험 범위)은 후속에서 처리합니다.
- **운영자께 여쭐 것(급하지 않음, 이번 병합과 별개)**: 글자 읽기를 켜기 전에 ① 빌드 흐름 첫 수동 실행과 액션 SHA 눈 대조 ② 운영자 PC 화면 확인 ③ GEOS(LGPL) 약관 확인이 남아 있습니다 — 문서 11절의 질문 후보 다섯은 켜기 요청을 올릴 때 **추천안과 함께** 여쭙겠습니다.
