# 확인 요청 — 'AI 입력' 칸을 규칙 기반 경로에서 판정에서 뺄지

> 이 요청은 **한 가지만** 묻습니다. 이미 정하신 엄격 기준(표준 라이선스 문구나 로봇 허용 같은 '암묵적 허용'은 근거로 인정하지 않음)은 **바꾸지 않습니다.** 바뀌는 것은 'AI 를 쓰지 않는 경로에서 AI 입력 칸을 볼 것인가' 하나입니다. 답이 없으면 지금 그대로(엄격 유지)입니다.

## 왜 지금 묻나 (일정 위험 1순위)
- 제한 재개(11-16–19, 사람 승인 흐름)에서 새 글은 **'구조화 Fact + 우리 계산'**(공개 통계의 숫자·날짜를 우리가 계산해 쓰는 글)으로만 만들기로 했습니다. 그런데 허용 목록 56곳을 **7칸이 모두 명시 허용**이라는 엄격 기준으로 걸러 보면 **지금 자동으로 쓸 수 있는 제공처가 0곳**입니다. 이대로 재개하면 새 글 후보에 쓸 외부 자료가 없어(자체 데이터만 가능) 재개해도 새 글이 거의 나오지 않습니다.
- 막힌 이유를 칸별로 보면, 구조화 API 세 곳은 **'AI 입력' 칸 하나만** '명시 허용'이 아니라 '금지는 없지만 허용도 명시하지 않음(암묵)'입니다. 나머지 여섯 칸(상업 이용·자동 접근·가공·저장·출처 표시·라이선스)은 이미 명시 허용이거나 표준 공개 라이선스·법령 근거가 있습니다.

| 제공처(구조화 API 경로) | 막는 칸 | 나머지 칸 |
|---|---|---|
| 캐나다 통계청(통계 API) | AI 입력(암묵 허용) | 모두 명시·표준 공개 라이선스 근거 |
| 영국 정부 콘텐츠 API(정부 안내 문서 데이터라 통계 글에는 쓰임이 제한적) | AI 입력(암묵 허용) | 모두 명시·표준 공개 라이선스 근거 |
| 미국 NOAA 우주날씨(JSON) | AI 입력(암묵 허용) | 모두 명시·법령 근거 |

(웹페이지·RSS 경로는 이 요청과 무관하게 '자동화 제외'입니다. 위 표는 구조화 API 경로만입니다.)

## 선택지
1. **엄격 유지(기본값)** — 'AI 입력' 칸도 명시 허용이어야 합니다. 자동 사용 가능한 외부 제공처는 **0곳**이라 재개해도 새 글의 외부 자료가 없습니다. 위험 없음.
2. **★ AI 를 쓰지 않는 규칙 기반 경로에서만 'AI 입력' 칸을 판정에서 뺍니다** — 위 세 곳이 **켤 수 있는 후보**가 됩니다(이 선택이 곧바로 무엇을 켜지는 않습니다: 제공처마다 칸 확인·호출 한도 확인을 한 뒤 **켜는 변경을 따로 부탁**드립니다). AI 에는 이 자료를 **한 글자도 넘기지 않으며**(AI 입력 금지 규칙 그대로), 글은 규칙 기반 틀로만 조립합니다. 'AI 는 선택, 없어도 규칙 기반 초안' 원칙과 같은 방향입니다. 위험: 그 칸이 '암묵 허용'이라 나중에 제공처가 AI 이용을 막는다고 밝히면 그 제공처만 바로 끕니다(자동 격리 규칙).
3. **그 밖의 방식** — 내용 칸에 적어 주세요(예: 세 곳 중 일부만).

## 추천과 영향
- **추천은 2번**입니다. AI 를 쓰지 않는 길에서 AI 입력 허용은 쓰이지 않는 칸이고, 정하신 '구조화 Fact 와 자체 계산만 초안에 전달' 원칙과 어긋나지 않습니다.
- 2번을 고르면: 구조화 Fact 경로 2단계(생성기 연결·Gate 근거 교체·실제 어댑터)를 위 세 곳 중 가장 단순한 것(우주날씨 JSON)부터 진행할 수 있어 제한 재개 일정(11-16–19)에 **한 가지 길이 생깁니다.** 단 글 품질은 '초안 보조 수준'(고정 틀 64–77%)이라 사람 승인 전제입니다.
- 1번을 유지하면: 일정은 그대로지만 **새 글 후보가 없는 재개**가 됩니다(데스크톱 수동 초안·기존 글 정비는 계속).

## 답하는 방법
- 텔레그램 안내대로 `대상번호/선택/내용` 으로 답하시면 됩니다(예: `007/2/`). 답이 없으면 1번(엄격 유지)으로 진행합니다. 어느 선택도 곧바로 글·설정·광고를 바꾸지 않습니다.
