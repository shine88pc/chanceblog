## 이번 묶음이 하는 일 (확인 요청 002 의 변경 결정 + 직접 기준 4가지)
말씀하신 원칙 — **단어가 존재한다는 이유만으로 판정하지 말고 단정 표현이 행동 순서를 꾸미는지 효과 결과를 꾸미는지 구분** — 대로 규칙을 정했습니다.
1. **영양제 + 바로·즉시**: 단순 시간·순서 표현은 A(`영양제 바로 알기`), 복용 질문은 B(`영양제를 식후 바로 먹어도 될까`), 즉각적 효능·치료·보장 주장은 C(`이 영양제는 피로를 즉시 없애줍니다`·`영양제로 불면이 바로 치료됩니다`·`수면제 바로 끊어도 될까`).
2. **증상 + 즉각적 효과 결과 = C**(`피로를 즉시 줄이는 방법`·`통증을 완전히 없애는 의자 선택법`), **'바로 확인한다'처럼 행동 순서를 꾸미는 표현은 C 가 아닙니다**(`자세가 불편할 때 책상 높이를 확인하는 기준` A).
3. **질환 + 단정(100%·보장·완치·무조건·즉시)은 효과 동사가 없어도 C**(`당뇨 100% 보장`·`암 완치 보장`), 질환 단독은 B(`당뇨 관련 공식 표시사항 확인하기`).
4. **직접 기준**: 효과 동사는 기본형뿐 아니라 **활용형 Phrase**(줄여 줍니다·줄여줍니다·줄일 수 있습니다 …)를 검사하고 없애·완화·개선·교정·치료·회복·예방·감량 계열도 같게 / `당뇨 환자가 무조건 피해야 할 음식` 은 B / `암` 은 토큰 경계 기준(암 관련 공식 정보 B, 암호·암호화는 건강 판정 없음).
운영자 예시 16개는 **16/16 일치**합니다. **옛 판정에서 '중지'였던 것을 결정 밖으로 푼 것은 없습니다**(독립 검증이 글 42,513개로 확인 — 옛 표시·근거·중지가 일반으로 내려간 글 0건).
