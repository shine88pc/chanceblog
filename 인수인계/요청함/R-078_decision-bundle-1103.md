# [R-078] 결정 모음 — 급하지 않고, 전부 기본값이 있습니다

> **하지 않으셔도 일은 계속 진행됩니다.** 아래 기본값(지금처럼 '하지 않음')으로 두고, 바꾸고 싶은 것만 알려 주세요.
> 답하는 방법: 텔레그램의 **[답하기]** → 요청 번호 `R-078` → 답변 **승인** → **선택** 칸에 `D1=A D2=A D3=B` 처럼 적기(안 적은 항목은 기본값) → 메모는 비워도 됩니다.

## D1. 사이트 홈페이지(`index.html`)의 글 제목 따옴표 처리 — 광고 표면이라 승인이 필요합니다
- **무엇이 문제인가:** 홈페이지 글 카드가 제목·분류·태그를 화면에 넣을 때 따옴표(`"`)를 처리하지 않습니다. 실제 글 50개 중 3개 제목에 곧은 따옴표가 있어 그 카드의 그림 설명·접근성 문구가 깨질 수 있고, 만약 악의적으로 만든 제목이 들어오면 홈페이지에서 스크립트가 실행될 수도 있습니다(지금은 우리 파이프라인이 만든 글만 올라가서 외부에서 넣을 길은 없습니다).
- **A (추천) 고친다:** 제목·분류·태그를 안전한 글자로 바꿔 표시하는 작은 함수를 더합니다. 실제 사이트 빌드를 공개 사이트와 견줘 달라지는 곳이 의도한 곳뿐인지 확인한 뒤 별도 병합 부탁으로 올립니다.
- **B (기본값) 지금처럼 둔다.**

## D2. 화면(GUI) 만들 도구 비교용 개발 설치 — 이 PC 에 새 프로그램 설치가 필요합니다
- 지금까지는 설치 없이 명령줄만 만들었습니다. 운영자님이 쓰실 **화면**은 PySide6(기능 풍부·설치 파일 큼) 또는 pywebview(작고 웹 모양)로 만들 수 있어, 작은 시제품 둘을 만들어 비교하려면 이 PC 에 `pip` 로 두 도구를 설치해야 합니다(파이썬 공식 저장소에서 내려받음, 개발용).
- **A (추천) 허용:** 시제품을 만들어 비교한 결과(화면 사진 포함)를 보여 드리고 고르시게 합니다.
- **B (기본값) 허용 안 함:** 설치 없는 기본 화면 도구(tkinter)로 단순한 화면을 만듭니다(모양은 소박함).

## D3. 네이버 검색 데이터(후보의 검색 수요·추세) 수집용 키 — 계정·약관이 필요한 일입니다
- 후보를 자동으로 더 똑똑하게 고르려면 네이버 공식 API(오픈 API·검색광고 API)의 키가 필요하고, 키는 운영자님 계정으로만 만들 수 있습니다(키 값은 저에게 주지 마시고 나중에 안전한 곳에 직접 넣는 방법을 안내합니다).
- **A 키를 만들겠다:** 만들 때 안내드립니다(약관·호출 한도 확인 포함).
- **B (기본값) 지금은 키 없이:** 후보는 직접 입력·CSV·블로그 프로필의 주제로 만들고, 검색 수요 같은 칸은 '데이터 없음'으로 비워 둡니다(프로그램은 그대로 동작).

## D4. 데스크톱 프로그램 라이선스
- **A MIT(제안):** 누구나 쓰고 고칠 수 있게 공개. **B (기본값) 라이선스 표시 없이 둔다:** 저작권은 그대로 운영자님께 있고 남이 쓸 권리는 따로 없는 상태.

## D5. 두 번째 네이버 블로그(B) 정보
- 주소와 주제를 알려 주시면 B 프로필을 채웁니다. **기본값: 계속 비워 둠**(A 블로그만 쓰는 것으로 진행). 선택 칸에 `D5=알림` 이라고 적으시면 정보를 따로 물어보겠습니다.
