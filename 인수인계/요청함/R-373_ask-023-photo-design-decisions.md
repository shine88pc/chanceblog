# 확인 요청 023 — 사진을 넣어 글쓰기(AI 없음) 설계 18가지

> 이 글은 **질문**입니다. 새 양식 `AI 확인 요청에 답하기(대상번호)` 에 대상번호 **023**, 선택 **①(추천대로)** 로 올리시거나 이 세션 채팅에 `023/1` 로 답하셔야 승인이고, **답이 없으면 전부 보류**(화면·초안 연결을 시작하지 않음)입니다. 일부를 바꾸고 싶으시면 선택 ② 로 바꿀 번호와 내용을 적어 주세요 — 그것은 승인이 아니라 접수라서, 바뀐 내용으로 확인 요청을 한 번 더 드립니다. 승인은 아래 **번호 항목에만** 유효하고, 승인하셔도 코드 병합은 단계마다 병합 부탁으로 한 번 더 여쭙니다. (참고: 지난번처럼 옛 양식에 올리면 자동 접수가 거절합니다.)

## 한눈에
- 운영자님 지시(이슈 #206·#208·#209, 확인 018 답 '1')대로 **사진을 글에 넣는 기능**을 AI·인터넷 없이 만들고 있습니다. 사진은 PC 밖으로 나가지 않고, 앱은 사진 파일을 복사해 저장하지 않으며 **파일 위치·순서·종류·직접 쓰신 설명·확인 표시**만 기억합니다. 사진 자동 분석은 하지 않습니다(글자 읽기 시제품은 확인 019·020 이 따로 대기 중).
- **1단계는 만들었습니다**(사진 정보를 담는 그릇과 규칙 — 새 파일 4개, 시험 101개). 아직 화면·초안과 연결하지 않아 **사용자에게 보이는 변화는 없고**, 지금 독립 검증자 두 명이 보고 있으며 통과하면 병합 부탁을 따로 드립니다.
- 앞으로 **2단계(사진 정리 화면)** 와 **3단계(초안에 사진 자리 넣기·내보내기)** 를 만들려면 아래 18가지를 정해야 합니다. 모두 되돌리기 쉬운 값이고, 백업 형식 변경·새 설정 스위치 같은 큰 일(T3)은 일부러 추천에서 뺐습니다(필요하면 따로 번호 있는 요청).

## 쓰시게 될 모습(요약)
초안 작성 화면에서 `사진 정리 열기` → 사진을 여러 장 고르고 → 사진마다 **종류**(간판·메뉴판 …)·**장소 분위기**·**'이 사진은 무엇인가요?'**(예: 반찬 5개 — 칸이 항상 보임)·**한마디 메모**·**들어갈 곳**을 직접 쓰고 → **'확인했어요'** 를 누른 사진만 초안에 반영됩니다. 초안 본문에는 `{{사진 1}}` 같은 자리 표시가 들어가고, 네이버용은 올릴 사진 순서 목록을 보여 드리며(직접 올림), Pages 용은 이미지 마크다운으로 바뀝니다. 앱이 사진 내용을 보고 말을 지어내지 않습니다 — 맛·재료·분위기 말은 쓰신 글 그대로만 들어갑니다.

## 결정 18가지 (모두 **추천이 먼저**, 괄호는 바꾸면 달라지는 점)
**가. 저장·삭제**
1. **사진 정보를 어디에 저장하나** — 추천: 데이터 폴더의 초안별 파일(`photo-manifests/초안번호.json`, 이미 구현). (대안: 저장한 초안 기록 안에 칸을 더함 — 초안 저장 코드·형식을 건드리는 T3 이고 '초안 저장·Package 우선순위를 건드리지 말라'는 지시와 부딪히며, 윈도 사용자 이름이 든 경로가 DB 와 모든 백업에 들어갑니다.)
2. **전체 백업에 사진 정보를 담을까** — 추천: 이번엔 안 담음(참고 글 보관함과 같음. 담으려면 백업 형식 변경 T3 이 필요). PC 를 바꾸실 때는 그 폴더를 직접 옮깁니다.
3. **저장한 초안을 지울 때 사진 정보도 함께 지울까** — 추천: 함께 지움(지우기 확인창에 한 줄 안내). (안 하면 남은 파일 정리 단추가 따로 필요.) 사진 파일 자체는 어떤 경우에도 지우지 않습니다.
17. **같은 초안을 두 창에서 동시에 저장하면 마지막 저장이 이김** — 추천: 이 한계를 받아들임(앱은 한 번에 하나만 열림).

**나. 사진 정리 화면의 목록·한도**
4. **사진 종류 목록** — 추천: 맛집 기준 9종(간판·건물 외관·메뉴판·인테리어·대표 메뉴·반찬·음식·지도 캡처·기타)을 기본으로 두고 화면 안에서 고칠 수 있음. 종류별 기본 '들어갈 곳': 간판·건물 외관→도입, 메뉴판·대표 메뉴·음식·반찬→내용 소제목, 인테리어→분위기 소제목(들어갈 곳은 사진마다 바꿀 수 있음).
5. **장소 분위기 목록** — 추천: 6종(실내·실외·테라스·주차장·객실·야경) — 맛집과 숙박을 둘 다 덮음. (지금 설계 초안은 실내·실외·객실·야경 4종.) 이것도 화면 안에서 고칠 수 있음.
6. **사진 최대 장수** — 추천: 30장(넘으면 '더하기' 단추가 꺼지고 이유를 말함).
10. **설명 없이도 '확인했어요' 허용** — 추천: 허용('여기에 사진' 만 넣는 경우). (아니면 '이 사진은 무엇인가요?' 칸을 꼭 채워야 확인 가능.)
11. **사진 파일이 옮겨지거나 지워졌을 때** — 추천: '파일 없음' 표시와 `다시 찾기` 단추만(앱이 폴더를 몰래 뒤지지 않음). 쓰신 글과 확인 표시는 남고 내보내기에서만 막힘.
16. **아주 큰 PNG 사진** — 추천: PNG 만 가로×세로가 1억 화소(예: 10,000×10,000)를 넘으면 미리보기를 만들지 않고 '너무 커서 미리보기를 못 만들어요' 로 알림(사진은 그대로 쓸 수 있음). 일반 사진은 영향 없음. (지금은 20MB·긴 변 12,000 화소 경고만 있음.)

**다. 본문 속 사진 자리·순서**
7. **글 속 사진 자리 표시 모양** — 추천: `{{사진 1}}` 그대로(눈에 잘 띔). 대신 3단계에 '글 모양 점검'이 중괄호 두 겹을 막는 규칙의 예외를 이 모양에만 두는 코드가 필요합니다. (대안: `[사진 1]` — 예외 코드는 필요 없지만 일반 대괄호와 헷갈릴 수 있음.)
8. **사진을 지우거나 순서를 바꿀 때 본문의 번호** — 추천: 사진 번호는 그대로 두고 앱이 본문을 몰래 고치지 않으며, 어긋나면 '사진 3 이 본문에 없어요' 처럼 번호로 알리고 내보내기 전에 확인. (대안: 앱이 본문 번호를 자동으로 다시 매김 — 편하지만 본문을 앱이 바꾸므로 비추천.)
15. **대표 이미지(Unsplash 검색·내 사진)와 본문 사진** — 추천: 서로 독립(본문 사진을 대표 이미지로 고르는 기능은 나중).

**라. 거르기·개인정보·스타일**
9. **사진 분석 결과(읽은 글자·관찰한 것) 저장** — 추천: 기본 끔 유지(지금 분석 기능이 없고, 생기더라도 확인 전에는 초안에 가지 않으며 저장도 안 함). 켜는 스위치는 로컬 분석(4단계, 별도 승인)을 다룰 때 함께 여쭙습니다.
12. **개인 정보 숫자 거르기** — 지금: 주민등록번호·카드 번호 모양만 막음. 추천: 그대로(식당 전화번호는 보통 정보라 통과). (전화번호·이메일·계좌 번호까지 거르면 정상 설명도 막힐 수 있음.)
13. **직접 쓰신 메모에서 얼굴·관계·감정 낱말을 거를까** — 추천: 거르지 않음(아시는 사실을 적으시는 것이므로). 거르는 것은 나중에 분석이 짐작한 말뿐입니다.
14. **참고 글(레퍼런스) 스타일 반영 범위** — 추천: 규칙 기반 엔진은 문단·문장 길이와 **사진 간격**(기본 2문단마다 1장)만 따르고 말투는 따라 하지 않음. '현장감 있는 묘사'는 AI 없이는 만들 수 없어 **쓰신 글 그대로** 넣고 앱은 맛·분위기 형용사를 만들지 않음.

**마. 변경 등급**
18. **단계별 등급** — 추천: 1단계 T2(새 파일을 쓰는 서비스 — 독립 검증 필수, 병합 부탁), 2단계 화면 T1, 3단계 초안 연결 T2 — 모두 독립 검증 뒤 병합 부탁으로 운영자께서 직접 병합.

## 승인하시면 (선택 ①)
- 1단계는 독립 검증이 끝나는 대로 병합 부탁을 드립니다(보이는 변화 없음). 이어서 **2단계 화면 → 3단계 초안 연결·내보내기** 순서로 구현·시험·독립 검증을 거쳐 단계마다 병합 부탁을 드립니다. 마지막에 시험지(`docs/PERSONAL_PC_TEST.md`)에 사진 3장으로 처음부터 끝까지 해 보는 항목을 더합니다. 3단계는 개인 PC 의 새 Package 를 만드신 뒤 시험하시게 됩니다.
- 이 승인은 **위 18가지 안에서 화면·초안 연결을 만드는 것까지**입니다. 다음은 따로 번호 있는 확인 요청 없이는 하지 않습니다: 백업 형식 변경·새 설정 스위치·초안 저장 형식 변경(결정 1 대안)·로컬 사진 글자 읽기(OCR)의 모델 내려받기·설치(확인 019·020 — 옛 양식 답이 거절돼 **새 양식이나 채팅 `019/2`·`020/2` 로 다시 답해 주셔야 하는 상태**입니다)·구글 등 클라우드 AI 사용(확인 018 답대로 쓰지 않음).
- 바꾸고 싶은 번호가 있으면 선택 ② 로 올리고 내용에 `7 대괄호`, `6 20장` 처럼 번호와 바꿀 것만 적어 주세요(나머지는 추천 그대로 두고 다시 확인 요청드립니다).

## 지금까지 한 일·한 적 없는 일
- 한 일: 설계서(18가지의 근거)와 1단계 코드·시험·문서를 앱 저장소의 작업 가지에 올렸고(병합 안 함) 저장소 검사와 독립 검증을 진행 중입니다. 기존 앱 코드는 한 줄도 바꾸지 않았고 새 의존성·네트워크·하위 프로세스는 없습니다.
- 한 적 없는 일: 사진 파일을 열거나 복사·업로드한 적 없음, EXIF·썸네일을 저장하지 않음, 클라우드 AI 호출 없음.
