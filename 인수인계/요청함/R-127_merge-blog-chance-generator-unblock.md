## 병합하시면 승인하시는 것
1. **모델에 넘기는 요약을 300자 → 1,800자로 늘립니다(C)** — 조사·개선 계획 문서는 '입력 보강'을 승인이 필요한 변경(T3)으로 분류했으나 구현은 코드 변경으로 했으므로 **여기서 확인을 받습니다.** `NEWS_SOURCES` 의 약관 확인 기록에는 입력 분량 제한이 없어 전 소스에 적용했지만 **사이트 약관 원문을 다시 읽지는 않았습니다.** 원치 않으시면 **병합하지 말고** [답하기]로 알려 주세요 — 상한을 300으로 두고 NASA·EU 디지털 전략 두 소스만 올리는 판을 다시 만들어 드립니다.
2. **호출 수 증가**: 하루 평균 Gemini 호출이 +1~2회 어림입니다(모델에 보내 보는 후보 상한은 그대로 3건 — 막혀서 한 건만 시도하던 실행이 최대 3건까지 시도). 후보 하나에 AI 서버 요청은 모델 폴백으로 최대 3번이고, 모델이 JSON 형식 지정을 거절하면 모델마다 한 번 더 나가 최대 6번까지 갈 수 있습니다(거절이 없으면 후보당 보통 1번). 무료 한도 안입니다.
3. **공개 주석 한 줄**에 후보 제목 앞 40자와 모델 사유 앞 80자가 로그인 없이 읽히는 공개 실행 기록에 보입니다(키·비밀번호는 가립니다).
