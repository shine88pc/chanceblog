# [M010] 병합 부탁 — 병합 부탁 PR 자동 만들기 (검사가 초록이면 PR 만 만들어 줍니다)

> **검사는 이미 끝났고 PR 도 이미 만들어져 있습니다 — Pull requests 탭에서 그 PR 을 열어 병합하시면 됩니다.** 이번 묶음의 PR 은 **새 워크플로가 자기 가지에서 처음 실제로 돌면서 스스로 만든 것**입니다(PR 번호 148, 작성자 `github-actions[bot]`). **이 병합 부탁은 블로그 저장소 `chanceblog` 것입니다**(데스크톱 저장소 `chanceblog-desktop` 이 아닙니다). 방금 병합해 주신 M009(화면 C-Type 2단계 첫 묶음)와는 **다른 묶음**이고, **사이트·글 발행·알림 전송 코드는 바뀌지 않습니다** — 새 워크플로 하나와 그 시험·안내 문서뿐입니다. 워크플로(`.github/`)와 보안 영역에 닿아 보안 등급 T3 라 병합은 운영자 승인으로만 합니다.

## 병합할 제목 (이것 하나만)
> **[M010] 병합 부탁 PR 자동 만들기 — 검사가 초록이면 PR 만 만드는 워크플로(auto-pr.yml, 병합은 하지 않음) [대상: 공통]**

- **제목 맨 앞이 `[M…]` 인 것만 병합하는 것입니다.** 이번 것은 `[M010]` 이고 가지 이름은 `ai/claude/M010-auto-pr-blog-1` 입니다(제목·가지 이름의 `M010` 이 위 알림의 번호와 같습니다). `M` 이 없는 제목·가지는 병합하지 않습니다.
- 병합 화면 맨 위의 저장소 이름이 **`chanceblog`** 이고 변경된 파일이 **14개**인지 봅니다.
- 이 병합에는 사이트(`index.html`·`_config.yml`·글)·`pipeline/`·기존 워크플로·광고 표면 변경이 **없습니다.** 다른 노란 배너(요청 파일을 올리는 `NO-MERGE-…` 가지 등)는 병합하는 것이 아니니 누르지 마세요.

## 이번 묶음이 하는 일 (운영자 확인 003 의 ② 'PR 만들기만 자동화')
1. **새 워크플로 `[공통] 병합 부탁 PR 자동 만들기`**: 제가 `ai/claude/M###-…` 병합 가지를 올리면, 그 가지의 검사가 **초록으로 끝나고 main 위에 커밋이 한 개뿐일 때만** 같은 제목·본문으로 PR 을 **자동으로 만듭니다.** 그래서 앞으로는 노란 배너를 누를 필요 없이 Pull requests 탭에서 `[M###]` PR 을 열어 병합만 하시면 됩니다.
2. **병합은 자동화하지 않았습니다.** 이 워크플로는 PR 만들기 한 가지만 하고, 병합·승인·라벨·코멘트·가지 삭제·설정 변경·다른 워크플로 실행은 하지 않습니다. 권한은 읽기 둘과 PR 쓰기 하나뿐이고, 외부 액션·비밀 값이 없으며, 가지 이름·제목·본문은 안전하게 따옴표 친 값으로만 다룹니다. 검사가 실패하거나 시간이 지나면 PR 을 만들지 않고 경고만 남깁니다(그럴 때는 지금처럼 노란 배너로 만들면 됩니다).
3. **첫 실제 실행 결과(방금 확인)**: 이 가지를 올린 직후 새 워크플로가 처음으로 돌았고 2분 45초 만에 성공했으며 **PR 148 을 스스로 만들었습니다**(제목·본문은 커밋 그대로, 파일 14개·+1,314/−3). 그리고 **저장소 설정 `Allow GitHub Actions to create and approve pull requests` 는 이미 켜져 있었습니다 — 설정을 따로 켜실 일은 없습니다.**

## 눈에 보이는 변화
- 앞으로 병합 부탁의 PR 은 **작성자가 `github-actions[bot]`** 으로 보입니다(운영자가 만든 PR 과 달리). 제목·본문·내용은 같습니다.
- 봇이 만든 PR 은 GitHub 규칙상 **일부 검사가 '승인 대기'** 로 보일 수 있습니다 — 이번 PR 도 `[공통] PR 변경 범위 검사` 줄이 '승인 대기'(작업 없음)로 보입니다. **그 줄은 누르지 않아도 되고, 병합하시면 됩니다**(이 검사는 AI 가지 PR 에서는 하는 일이 없는 것으로 설계돼 있습니다 — 병합 버튼이 막혀 있으면 병합하지 말고 아래 '안 될 때'대로 알려 주세요).
- 이 PC 에서 본 PR 상태: 병합 가능(충돌 없음), 검사 4건 초록(+ 위 승인 대기 1줄).
