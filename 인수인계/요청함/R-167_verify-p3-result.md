# [R-167] P3 독립 검증 결과 (2026-11-06 10:30 기준)

> 5채널 주제 엔진 3단계(P3 — 후보 보관함·서비스·명령줄·백업)를 만든 AI 와 **다른 AI 두 명**이 따로 검증했습니다(관점 A·C = 저장소 안전·백업·복원·비밀, 관점 B·D = 서비스·명령줄·기존 기능 불변·요구 추적). 둘 다 **조건부 병합 가능**입니다. 병합 부탁(번호 있는 요청)은 아래 지적을 고치고 고친 부분을 다시 검증한 뒤 보냅니다.

## 통과한 것 (안전 약속)
- **읽기 전용 명령은 파일을 만들거나 바꾸지 않습니다** — 폴더 없음·손상·낯선 파일·더 새로운 판 등 13가지 상태 × 32개 호출(416건)과 이상 입력 7,000여 건에서 데이터 폴더·블로그 폴더·현재 폴더의 변화 0건.
- **저장은 `--yes` 가 있을 때만**, 도중에 실패해도 일부만 저장되지 않음(후보 0개·발행 이력 장부 0개로 되돌아감), 여러 창이 동시에 저장해도 목표 개수를 넘지 않음.
- 낯선 파일·더 새로운 버전·깨진 파일은 **한 바이트도 바꾸지 않고** 쉬운 한국어로 거절. 판 올리기 중 강제 종료를 흉내 내도 다음 열기에서 정상.
- 기존 기능 불변: 기존 명령 `--help` 45개 해시 같음, 기존 명령 시나리오 출력 같음(차이는 임시 경로 글자와 `topics` 가 선택지에 더해진 것뿐), 화면(`ui/`)·글 보관함(`content/`) 변경 0줄, 인터넷·프로세스 호출 0.
- 키·비밀번호는 어떤 출력·백업·로그에도 없음(환경변수·자격 증명 관리자·설정 파일 값 모두 0건), 시험도 공허하지 않음(키 검사를 일부러 지우면 시험이 빨개짐).
- 시험: 3.12·3.10 모두 통과(검증자 B 는 37개 모듈(3.12·3.10 각각 1,598개 시험)과 해시 시드 0·1·2 도 확인), 독립 참조 구현과 비교한 남은 자리 계산 차이 0, 검증자가 새로 낸 변이 230곳(A 95 + B 135) 중 209곳을 시험이 잡음(나머지 21곳은 시험 보강 항목).
