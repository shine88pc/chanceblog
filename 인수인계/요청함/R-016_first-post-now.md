# R-016 · 첫 글을 지금 확인하는 방법 (이슈 #73 답)

## 먼저 결과
- 병합(PR #72)을 확인했습니다. 검사(가드레일 포함)·사이트 배포가 모두 초록이고, 한글·영문 Blogger 가 둘 다 `mode: draft`(초안함에만 올리고 공개는 직접)입니다. 한글 이력 파일이 사이트에 공개되지 않는 것도 확인했습니다(주소 404).
- 요청하신 것: **① 첫 글은 지금 바로 확인, ② 두 번째 글부터는 기존 시각(영문 11:00·한글 12:30, KST)**. 저는 Actions 의 "Run workflow" 버튼을 누를 수 없어서(계정 권한), 사용자님이 1분이면 할 수 있는 순서를 준비했습니다. 진행 범위 '논의·준비까지만'에 맞춰 다른 변경은 하지 않았습니다.

## 하실 일 (영문·한글 각각 1분)
1. 저장소 **Actions** → 왼쪽 목록에서 **`[Blogger 영문] 글 자동 작성`** 을 고릅니다.
2. 오른쪽 **Run workflow** 를 누르면 입력칸이 나옵니다.
   - **직접 정할 주제**: **비워 둡니다**(채우면 하루 상한을 건너뛰어, 오늘 정기 실행이 같은 날 글을 또 만듭니다).
   - **연습 실행(기본 켜짐…)**: **체크를 풉니다**. 기본이 체크돼 있어 그대로 두면 가짜 글로 연습만 하고 아무것도 올라가지 않습니다.
   - **글을 어디까지**: **`draft` 그대로**(기본값). `publish` 를 고르면 **즉시 공개**되니 절대 건드리지 마세요.
   - **인증 점검만 실행**: 체크하지 않습니다(기본).
3. 초록 **Run workflow**. 몇 분 뒤 실행이 초록이면 끝입니다.
4. 같은 방법으로 **`[Blogger 한글] 글 자동 작성`** 도 한 번 실행합니다.

## 그다음 (자동)
- 글이 올라오면 텔레그램에 **"초안함에 올라왔습니다 — Blogger 대시보드 → 초안에서 확인하고 게시하세요"** 알림이 갑니다. 저도 실행 결과를 읽고 결과를 따로 알려 드립니다.
- **Blogger 초안함에서 읽어 보시고 공개할지 정해 주세요.** 공개 전에는 블로그에 보이지 않습니다. 눈여겨볼 것: 영문은 건강·치료 주장이 없는지, 한글은 지어낸 경험·수치·후기가 없는지, 두 글이 서로 번역·복제가 아닌지.
- **오늘 정기 실행(영문 11:00·한글 12:30)** 은 하루 1편 상한(DAILY_CAP) 때문에 건너뜁니다(실행은 초록, 요약에 "상한 도달"). **내일부터** 평소 시각에 두 번째 글이 올라옵니다. 수동 실행이 탈락·실패해 글이 안 만들어졌다면 그 기록은 상한에 세지 않아 오늘 정기 실행이 한 번 더 시도합니다.
- 빨간 ✗ 로 끝나면 [답하기] → 요청 번호 **R-016** → 답변 '문제' 를 고르고 메모에 화면에 보이는 문구를 적어 주세요(비밀 값은 쓰지 마세요).

## 알아 두실 것
- 실제 모델 글은 두 블로그 모두 처음입니다. 길이·형식 검사에서 탈락해 글이 안 올라올 수도 있고, 그때는 제가 실행 기록에서 사유를 읽고 알려 드립니다.
- 이 수동 실행으로 이력이 갱신되면 12:30 점검(워치독)에서 "영문 Blogger 멈춤(마지막 활동이 10월 25일)" 빨간 알림이 뜰 일이 없습니다. 실행 전에 뜨더라도 첫 글이 올라온 뒤 자동으로 닫힙니다.
- Gemini 무료 한도를 자동으로 지켜 주는 장치는 아직 없다고 R-014 에서 정정해 드렸습니다. 블로그마다 하루 1편이라 한도 안일 것으로 보며, 첫 주에는 실행 요약의 "Gemini 호출: N회"를 제가 확인합니다.
