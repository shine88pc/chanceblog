# 병합 요청 M073 — 앱의 안내·결과 문장 일곱 곳의 글자 색을 더 잘 보이게 바꿉니다

> **병합 방식**: 지금은 AI 병합 기능이 **꺼져 있어** 운영자께서 직접 병합해 주세요. (`M073 승인` 이라고 답하셔도 아직 AI 가 병합하지 않습니다 — 켜지는 변경이 운영자 병합으로 들어온 뒤에만.) 이 요청은 데스크톱 저장소 `chanceblog-desktop` 의 것이고, PR 제목 맨 앞이 `[M073]` 인 것 하나만 병합합니다. 검사는 이미 끝나 초록입니다.

## 1. 무엇을 바꾸는지
앱에서 **후보 상세·후보 카드·초안 작성 화면의 안내·결과 문장 일곱 곳**이 쓰던 흐린 글자 색을, 앱에 이미 있던 '보조 글' 색(더 진한 색)으로 바꿉니다. 앱의 코드는 글자 색을 가리키는 낱말 일곱 곳(소스 7줄)만 바뀝니다. 입력 칸 테두리 색과 색 값 자체는 그대로이고, 값 칸의 '없음' 표시 다섯 곳은 흐린 글 그대로입니다. (확인 015 승인 10번, 결정 D-487)

## 2. 왜 필요한지
그 문장들이 흰 바탕에서 글자와 바탕의 밝기 차이(대비)가 3.2 여서 흐리게 보였습니다. 작은 글자를 편하게 읽으려면 4.5 이상이 좋다고 알려져 있는데, 바꾼 색은 5.4(검증자가 계산식으로 직접 확인)입니다.

## 3. 사용자가 체감하는 변화
문장 일곱 곳의 글자가 조금 더 진해져 잘 읽힙니다. 글자 크기·굵기·화면 배치와 다른 화면은 그대로입니다.

## 4. 위험과 기존 기능에 미치는 영향
- **기존 기능**: 영향이 없습니다. 글자 색 낱말 7곳 말고 서비스·저장·엔진·외부 접속·설정은 바뀌지 않습니다.
- **솔직하게 알려 드릴 점 ① — 실제 화면 시험을 못 돌렸습니다**: 앱을 실제로 띄워 그려진 색을 확인하는 시험 11개는 'PySide6'(화면 도구)가 필요한데, 이 PC 에는 설치돼 있지 않고(설치 허락을 기다리는 중) 앱 저장소의 자동 검사도 그 도구를 설치하지 않아 건너뜁니다. 대신 화면 도구 없이도 색 규칙을 읽어 확인하는 시험 32개로 지켰고 독립 검증자가 대비를 계산식으로 확인했습니다. 다만 실제 화면에 그려진 색을 직접 본 확인은 아직 없으니, 병합하신 뒤 앱에서 후보 상세·초안 작성 화면의 안내 문장이 읽을 만한지 한 번 봐 주시면 가장 확실합니다.
- **② 문서 사진 188장은 새 색으로 다시 찍지 않았습니다**(옛 색 그대로 — 이유와 다시 찍는 방법은 UI_VISUAL_QA 14절). 사진 픽셀을 읽는 시험은 없어 자동 검사에는 영향이 없습니다.
- **③ 승인 8번(AP13, 주 단추를 주제 후보에서 열기)은 코드로 하지 않았습니다.** 설계 문서(UI_DESIGN_SPEC 13절)에 기록으로만 남겼습니다.
- **④ 이미 있던 작은 결함을 발견해 기록만 했습니다**: 후보 상세를 연 채 `이 주제로 만들기` 로 화면을 옮길 때, 돌아갈 자리를 가리키는 값이 지워진 위젯으로 남는 문제입니다(좁은 창의 서랍과 넓은 창의 고정 상세 창 모두). 서랍을 여는 길이 모두 그 값을 새로 쓰고 옛 값을 꺼내 쓰는 곳이 한 곳뿐이라 거의 걸리지 않습니다. 이 병합은 고치지 않았고 설계 문서에 서랍의 경우만 적었습니다(넓은 창의 경우는 검증자가 확인했고 문서에는 아직 안 적음).

## 5. 시험·독립 검증 결과
- 앱 저장소 자동 검사 초록(환경 4개 × 조각 3개): CI — 시험 성공(14분 20초)과 병합 부탁 PR 자동 만들기 성공. 새 시험 파일 43개(화면 도구 없이 도는 것 32개).
- 독립 검증(구현자와 다른 AI): 범위·AP15 관점이 3차와 4차 델타까지 확인해 최종 **통과**(필수 0·권고 0). 앞서 나온 권고 3건(후보 서랍 문장이 후보 서랍에서는 사실이 아니었던 것·글자 크기가 안 움직인다는 시험·스타일시트 적용 단계 시험)은 4차 수정으로 반영했습니다. 직접 확인: 코드 변경은 낱말 7줄뿐, `.github`·`vendor`·의존성·새 외부 접속 0.
- 변이 시험(규칙을 일부러 망가뜨려 시험이 빨개지는지): 구현자의 77개와 49개를 Qt 가 있어야 잡히는 둘만 빼고 모두 시험이 잡았습니다. 검증자가 만든 변이 중 일부는 못 잡는다고 정보로 보고했습니다(후보 서랍 기록의 전제 일부 등).
