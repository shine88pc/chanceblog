# [R-068] 병합 부탁 — 서비스 층 다듬기(검사 속도·잠금 위치·안내)

## 병합할 제목 (이것 하나만)
> **[R-068] 서비스 층 다듬기 — 위험 글 검사 속도·잠금 위치·안내 문구(독립 검증 낮음 항목) [대상: 데스크톱]**

- 맨 앞이 `[R-068]` 인 이 제목 하나만 병합합니다. 다른 번호나 다른 제목은 병합하지 않습니다.
- 이번에도 **데스크톱 프로그램 저장소 `chanceblog-desktop`** 입니다(병합 화면 맨 위 저장소 이름 확인). 오늘 아침 병합하신 두 건(R-060 서비스 층, R-062 후보 모델) 위에 쌓은 보강입니다.
- 첫 화면에 노란 배너가 여러 개 보여도(작업 중인 다른 브랜치) 위 제목 하나만 고릅니다.

## 무엇이 바뀌나 (쉬운 설명)
독립 검증이 '병합은 막지 않지만 고치면 좋다'고 짚은 항목(낮음)을 고친 묶음입니다. **병합해도 블로그에는 아무것도 올라가지 않습니다**(올리는 명령은 여전히 `--yes` 를 붙여야 실제로 올리고, 기본은 연습 실행입니다).
1. **위험한 글 검사가 아주 느려지던 문제** — 글 속 링크 뒤에 공백이 수만 개 이어지면 검사 시간이 급격히 늘던 것(6만 개에서 88초)을 0.1초대로 줄였습니다. 검사 규칙의 의미는 그대로입니다(옛 규칙과 30만 건을 견줘 차이 0 — 위험한 글을 놓치게 된 경우 없음).
2. **올린 직후 글 지우기에서 막히던 안내** — 올린 글은 '먼저 공개 확인(`check-deploy`)'을 하라고 안내하고, 안내가 서로를 가리키며 빙빙 돌던 상황을 없앴습니다.
3. **같은 블로그 저장소에 두 앱이 동시에 올릴 때 부딪히지 않게** — 동시 올리기 잠금을 저장소 안(`.git` 폴더)으로 옮겨, 데이터 폴더가 달라도 직렬로 처리합니다.
4. **작은 것들** — 긴 제목 때문에 잘리던 '되돌리기' 명령 안내, 글자 방향을 바꾸는 보이지 않는 글자 거절, 문구 정정, 네트워크 경로의 읽기 전용 열기.

## 확인한 것
- 독립 재검증(구현자와 다른 AI 가 새 복사본에서): **'병합 가능'**(높음 0·중간 0·낮음 7건). 3차 검증이 짚은 낮음 10건 중 7건은 고쳐졌고 3건은 이번 범위 밖(사이트·가져온 코드)입니다.
- 시험: 서비스 672개·그 밖 990개 모두 통과, 새 시험 80개. 일부러 코드를 망가뜨려 보는 점검(변이) 구현자 118곳 중 116곳·검증자 90곳 중 83곳을 시험이 잡았습니다(못 잡은 것은 결과가 같은 변경 2곳과 시험 공백 5곳 — 실제 코드는 정상).
- 서비스 층 위에서 검증했습니다. 바뀐 곳: 파일 25개(추가 약 1,600줄). `vendor`·`.github`·`publish`·`render`·`security` 는 바뀌지 않았습니다.
- **병합 전에 꼭 볼 것:** 이 브랜치의 자동 검사 4칸(Windows·Ubuntu × 파이썬 3.10·3.12)이 모두 초록인지 확인해 주세요. 새 시험 일부(진짜 프로그램 여러 개를 동시에 돌리는 것)가 시간이 걸려서 **검사 시간이 20분 한도 안에 끝나는지**도 이번에 처음 확인합니다. 빨간 칸(시간 초과 포함)이 있으면 병합하지 말고 아래 '안 될 때'를 따라 주세요.

## 솔직한 한계 (병합을 막지 않음, 후속으로 고침)
- 죽은 프로그램이 남긴 낡은 잠금을 세네 개 앱이 **동시에** 넘겨받으면 아주 드물게(약 1~2%) 순간적으로 둘이 잠금을 쥘 수 있습니다(이번 변경 이전부터 있던 한계).
- 블로그 저장소에서 가져온 코드 한 곳이 전각 공백이 아주 많을 때 느립니다 — 블로그 저장소에서 고쳐 다시 가져와야 해서 후속으로 합니다.
- 기록 없이 남은 오래된 '올리기 직전' 글의 안내, 앞뒤 버전 앱을 섞어 쓸 때의 잠금은 문서에 적은 한계 그대로입니다.
- 사이트 `index.html` 의 제목 따옴표 처리는 이번 병합과 별개이고 결정 요청으로 따로 드립니다.

## 위험과 대비
- **블로그·네이버·발행은 바뀌지 않습니다.** 병합해도 이 저장소에서는 검사(시험)만 돕니다. 되돌려야 하면 병합 한 건을 되돌리는 요청을 드립니다.
- 병합 뒤 제가 직접 확인합니다(병합 상태·내용 일치·main 검사). 병합하신 시각을 알려 주실 필요는 없습니다.
- **결정하실 것은 없습니다.**
