# R-005 · 구글 "앱 게시" 버튼이 안 눌릴 때 (이슈 #61)

## 먼저 알려 드릴 것
- 이슈 #61 의 내용은 읽었습니다. 다만 접수기가 요청 번호를 소문자(`r-002`)로 쓰신 것을 "양식 모양이 달라 처리하지 못했습니다"로 답했습니다. 사용자님이 틀리신 것이 아니라 접수기가 대소문자를 구분해서입니다. **번호는 대문자 `R-005` 처럼 써 주세요.** 소문자도 받도록 제가 고치겠습니다(병합을 부탁드릴 때까지는 대문자만 받습니다).
- 접수가 어려우면 채팅으로 알려 주셔도 됩니다.

## 왜 버튼이 안 눌리나 (추정 — 공식 문서에는 조건이 없고 구글 커뮤니티 보고입니다)
Google Auth Platform 의 **대상(Audience)** 화면에 있는 **앱 게시(Publish app)** 버튼은, **브랜딩(Branding)** 화면의 이 항목이 비어 있으면 회색으로 막힙니다: 앱 이름 · 사용자 지원 이메일 · **앱 홈페이지 주소** · **개인정보처리방침 주소**(이 둘을 넣으면 **승인된 도메인**도 필수가 됩니다). 브랜딩 화면에서는 홈페이지·방침 주소가 '선택'처럼 보여서 비워 두기 쉽습니다. 앱 이름·이메일은 이미 채우셨다고 하셨으니 아래 세 칸이 남았을 가능성이 큽니다.

## 해 볼 것 (순서대로, 휴대폰도 가능)
1. 구글 클라우드 콘솔 → **Google Auth Platform** → **대상(Audience)** 화면에서 회색 **앱 게시** 버튼에 **마우스를 올립니다**(휴대폰은 길게 누르기). 부족한 항목을 알려 주는 문구가 나옵니다.
2. 왼쪽 메뉴의 **브랜딩(Branding)** 으로 갑니다.
3. 다음 세 칸을 채웁니다(우리 사이트 주소이고 실제로 열립니다).

   | 칸 | 넣을 값 |
   |---|---|
   | 앱 홈페이지 | `https://shine88pc.github.io/chanceblog/` |
   | 앱 개인정보처리방침 링크 | `https://shine88pc.github.io/chanceblog/privacy/` |
   | 승인된 도메인 (Authorized domains) | `shine88pc.github.io` |

   승인된 도메인 칸에는 `https://` 와 뒤의 경로를 빼고 도메인만 씁니다.
4. 맨 아래 **저장(Save)** 을 누릅니다.
5. **대상(Audience)** 화면으로 돌아가 **앱 게시(Publish app)** → 확인창에서 계속합니다. 상태가 **In production(프로덕션)** 으로 바뀌면 성공입니다.
6. 새 프로젝트·새 OAuth 클라이언트를 만드셨다면, 게시가 끝난 **뒤에** 토큰을 받고 `BLOGGER_CLIENT_ID`·`BLOGGER_CLIENT_SECRET`·`BLOGGER_REFRESH_TOKEN` **세 개를 새 값으로 함께 덮어씁니다**(R-002 와 `.github/editorial/BLOGGER_API_SETUP.md` §2·§2-B). 이전 프로젝트의 클라이언트 값과 섞지 마세요.

## 그래도 안 되면 (추정)
- 회색 버튼의 **마우스 올림 문구**를 그대로 알려 주세요(비밀 값이 아니라 안내 문구입니다).
- 화면의 **사용자 유형이 '내부(Internal)'** 이면 게시 버튼이 없고 조직 구성원만 쓸 수 있어 이 용도에 맞지 않습니다. **외부(External)** 여야 합니다.
- 프로젝트에서 사용자님 권한이 보기 전용이면 버튼이 막힐 수 있습니다. 소유자·편집자 권한인지 확인해 주세요.

## 게시한 뒤 보일 것
- 토큰을 받을 때 "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (앱 이름)(으)로 이동**을 눌러 계속합니다. 개인용으로 한 계정만 쓰는 앱이라 정상입니다(`BLOGGER_API_SETUP.md` §1-4).
- 프로덕션이 되면 토큰이 7일 만에 만료되지 않습니다(공식 문서: 테스트 상태의 토큰만 7일 만료).

## 알려 주기
- 성공하셨으면 알리지 않으셔도 됩니다. R-002 대로 토큰을 새로 받아 시크릿을 덮어쓰고 `인증 점검만 실행`을 돌리시면 AI 가 결과를 읽습니다.
- 막히면 `[답변]` 양식에서 요청 번호 **R-005**(대문자), 답 "문제", 메모에 화면의 문구를 적어 주세요(값·비밀 제외).
