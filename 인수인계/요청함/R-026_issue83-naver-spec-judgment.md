# R-026 · 이슈 #83 판단 — 첨부 명세서의 '자동 임시저장'을 티스토리에도 쓸 수 있나

## 한 줄 답
**기술적으로는 티스토리에도 됩니다. 하지만 하지 않기를 권합니다.** 지난번(R-025) 조사에서 같은 방식(프로그램이 로그인해 에디터에 글을 채우고 임시저장)을 티스토리·네이버 모두 검토했고 같은 결론이었습니다. 이번 명세서가 내세우는 좋은 점('사람이 마지막에 발행', '경험 지어내기 차단')은 **이미 지금 방식에 들어 있습니다.** 하실 일은 없습니다. (이 이슈는 '논의·준비까지만'이라 코드·설정은 바꾸지 않았습니다.)

## 명세서가 하자는 것
5단계입니다: 글감·키워드 수집 → 제휴 상품 정보 수집 → AI 본문 작성 → **프로그램이 네이버에 로그인해 스마트에디터에 제목·본문·태그를 채우고 [임시저장] 클릭** → 사람이 검수하고 발행. 만들 것은 수집 모듈·글 생성 모듈·브라우저 자동화 모듈(Playwright)이고, 마지막 장에 Claude Code 에게 줄 개발 지시문이 있습니다. 안전 규칙은 두 가지입니다: ① 제휴 링크가 있으면 '대가성 문구'를 자동으로 넣는다 ② **네이버의 봇 탐지를 피하려고 사람처럼 보이는 행동(타이핑 지연·마우스 클릭)과 탐지 회피 드라이버(undetected-chromedriver)를 쓴다.**

## 티스토리에 적용할 수 있나 — 항목별 판단
| 항목 | 판단 | 이유 |
|---|---|---|
| 기술 | 가능(회색 지대) | 티스토리의 공식 글쓰기 API 는 2024-02 에 끝났고, 남은 길은 브라우저를 움직이는 방법뿐입니다. 임시저장까지 해 주는 개인 오픈소스 사례가 있습니다(참고 수준) |
| 우리 규칙 | **불가** | 승인하신 D4·G-S7: 블로그 계정의 로그인·쿠키·세션을 자동화하거나 계정 정보를 보관하지 않습니다. 이 방식은 로그인과 쿠키가 있어야 돌아갑니다 |
| 약관 | 티스토리 불명확 / 네이버 위험 높음 | 티스토리: 자동화를 콕 집어 금지하는 조항은 못 찾았지만 포괄 조항이 있고, 우리 규칙은 '불명확하면 하지 않는다'입니다. 네이버: 자동화 수단(매크로·로봇) 금지 문구가 있다는 보도가 있습니다(약관 원문은 접근이 막혀 못 읽음). **임시저장만 한다고 위험이 줄지 않습니다** — 약관은 '어떻게 접근했는가'를 보기 때문입니다(해석) |
| 봇 탐지 회피 | **만들지 않음** | 명세서 규칙 2 와 undetected-chromedriver 는 서비스의 봇 차단을 속이는 것입니다(이 도구의 저장소 설명이 스스로 '모든 봇 차단 시스템 통과'라고 적고 있음을 이번에 확인). 제가 만들지 않는 종류입니다 |
| 로그인 보안 | 막힐 수 있음 | 카카오(티스토리)는 의심스러운 접속이면 비밀번호·추가 본인확인을 요구한다고 운영정책에 적혀 있고, 네이버도 2단계 인증·CAPTCHA 가 뜬다는 사례가 있습니다. 자동 로그인은 사람이 풀어야 하는 지점에서 멈춥니다 |
| 실행 장소 | 문제 | GitHub 서버(해외 주소)에서 개인 계정에 로그인하면 보안 확인에 걸릴 수 있습니다. 명세서는 '사내 PC 의 Claude Code 로 만들라'고 하는데, 개인 블로그 계정에 자동 로그인하는 프로그램을 회사 PC·회사망에서 돌리는 것은 회사 보안 규정과 부딪힐 수 있습니다(저는 규정을 볼 수 없으니 운영자 판단) |
| 계정 위험 | 운영자 부담 | 제재는 글 삭제·이용 제한·계약 해지까지 있고, 카카오계정으로 묶이면 다른 서비스까지 번질 수 있습니다 |
| 이득 | 작음(추정) | 자동으로 줄어드는 것은 복사·붙여넣기 몇 번(글당 1~2분)입니다. 계정 제재·탐지 위험에 견주면 이득이 작습니다 |

## 명세서에서 이미 하는 것 / 가져올 만한 것 / 가져오지 않는 것
- **이미 하는 것**: ① 사람이 마지막에 발행(AI 는 초안 이슈까지) ② **경험 지어내기 차단** — 두 초안 프롬프트의 4번 규칙이 '써 봤더니·직접 해 본 결과' 같은 개인 경험·후기·수치를 쓰지 않게 하고, 프로필의 금지 패턴('써 봤더니', '저는·제가' 등)이 실제로 걸러 냅니다. 명세서의 '메모가 없으면 경험형 금지'보다 더 강합니다(항상 금지) ③ AI 활용 고지문 자동 삽입.
- **가져올 만한 것(선택, 지금은 하지 않음)**: ① 제휴 링크(쿠팡 파트너스 등)를 쓰게 되면 대가성 문구를 자동으로 넣는 규칙 — 제휴는 수익 모델 변경이라 T3 승인 사항입니다 ② 키워드 조사는 공식 API(네이버 데이터랩 등)만 — 인증 키를 저장소에 등록해야 해서 T3 입니다 ③ 마크다운을 네이버 붙여넣기 서식으로 바꿔 주는 것(참조된 md-to-naver-blog)은 R-025 조사의 대안 A2('서식 그대로 복사')와 같은 방향의 '붙여넣기 편의'입니다.
- **가져오지 않는 것**: 로그인·세션 자동화, 탐지 회피, 설치형 자동 발행 앱·확장 프로그램.

## 대신 하는 것 (기본값 — 답이 없으면 이대로)
1. **지금 방식 유지**(진행 중): 초안 이슈 → 복사·붙여넣기 → 발행. R-025 를 병합하시면 첫 초안이 생깁니다. 처음 1~2건을 붙여넣어 보시고 **깨진 서식만** 알려 주세요. 제가 이슈 모양을 고칩니다.
2. **보류**: 고객센터에 '내 계정에서 내가 직접 실행하는 입력 보조(발행은 내가 누름)가 약관상 허용되는가'를 서면으로 묻는 일. 허용이라는 답이 와야 북마클릿 같은 보조를 검토할 수 있습니다. 문안이 필요하시면 `[요청]` 으로 알려 주세요(발송은 운영자 몫).
