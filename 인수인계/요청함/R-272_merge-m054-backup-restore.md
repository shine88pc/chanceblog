# [M054] 병합 부탁 — 전체 백업·복원 (BACKUPUI)

> **검사는 이미 끝났습니다 — PR 을 열어서 병합하셔도 됩니다.** 가지를 올린 때 데스크톱 저장소의 검사(Windows·Ubuntu × 파이썬 3.10·3.12 시험)가 돌아 초록으로 끝났습니다. **이 병합 부탁은 데스크톱 프로그램 저장소 `chanceblog-desktop` 의 것입니다**(블로그 저장소가 아닙니다).

- 병합 화면 맨 위의 저장소 이름이 **`chanceblog-desktop`** 이고 변경된 파일이 **65개**(+8,545/−17줄)인지 봅니다. 새 소스 몇 개(백업·복원 서비스와 화면 카드)와 많은 시험·문서·화면 사진입니다. `.github`·`vendor`·의존성 파일·블로그 저장소는 **없습니다.** 다른 노란 배너는 무시하셔도 됩니다.

## 이번 묶음이 하는 일
운영자 개인 PC 필수 시험('Backup·Restore')의 핵심이고 개인 PC 제한 사용 Package 의 Gate 항목(Backup Secret 0·복원 가능)을 닫습니다.
- **백업**: 설정 화면에 '백업·복원' 카드가 생깁니다 — `지금 백업`(진행 표시), 백업 목록(날짜·크기·담긴 것·'Credential 제외됨'·상태). 백업 폴더마다 `MANIFEST.json`(파일 목록·크기·SHA-256·앱 버전·만든 시각·항목 수·**`credential_excluded: true`**·담지 않은 것과 이유)이 들어가고 **키(자격 증명 관리자의 값)는 백업에 들어가지 않습니다.** 폴더 열기 단추는 없고(새 외부 호출 금지) '다른 곳(USB·다른 PC)에 직접 복사' 안내만 있습니다.
- **백업 전 비밀 모양 검사**: 앞서 병합한 보안 수정(M052)의 스캐너(Google API Key·GitHub Token·Bearer·OAuth·AWS 키·PEM 개인 키 여섯 종류)로 보관함·JSON·설정의 모든 칸을 훑고, 키 모양이 있으면 **어떤 사본도 쓰지 않고** 위치(표·칸)와 유형만 알립니다(자동 삭제·'무시하고 저장' 없음). 보관함 사본은 디스크에 닿기 전에 메모리에서 훑어, 거절된 백업에 비밀이 임시 파일로 남지 않습니다.
- **복원**: 매니페스트 변조(바이트 변경·파일 삭제·추가·해시까지 맞춘 위조)와 경로 조작(`..`·절대 경로·드라이브 문자)을 거절하고, 지금 데이터를 바꾸기 직전에 안전 사본을 만들고, 원자적으로 교체합니다. 복원이 중간에 멈추면 표지와 쉬운 안내가 남고 '안전 사본으로 되돌리기'(확인창 뒤에만 — 자동 아님)로 되돌립니다. 백업은 10개를 유지하며 정리가 방금 만든 백업·복원 중인 폴더·안전 사본을 지우지 않습니다(컴퓨터 시계가 거꾸로 가도).
- **앱 안의 로컬 동작만**입니다. 새 외부 호출·키·네트워크·AI·글 올리기는 없습니다(소스와 시험으로 확인).

## 눈에 보이는 변화
- **운영자 PC 의 블로그·자동 실행은 그대로입니다.** 이 변경은 데스크톱 앱 안의 동작이라 개인 PC 로 옮길 시험용 Package 에 들어가야 보입니다. 보이게 되는 것: 설정 화면 아래쪽(문체 참고값 카드 위)의 '백업·복원' 카드.

## 솔직한 한계 (문서에 적음)
- **백업은 암호화되지 않은 평문 폴더**입니다(같은 PC·같은 계정의 보호에 기댐 — 그래서 키는 아예 넣지 않고 키 모양 글이 있으면 백업을 거절합니다). 실제 Windows 전원 차단·백신의 파일 잠금은 시험에서 모의까지만 했습니다.
- 독립 검증이 남긴 **낮은 지적 셋**은 병합 뒤 후속으로 고칩니다: ① 복원이 끝났는데 표지를 못 지우면 거짓 '멈춘 복원' 안내가 남고, 되돌리기를 누르면 끝난 복원이 취소됩니다(안전 사본으로 돌아감 — 데이터가 사라지지는 않음). ② 정리 중 임시 사본을 메모리에 두는 줄이 구조 시험으로만 지켜집니다. ③ Windows 접합(junction)을 링크로 보지 못해 정리가 바깥 파일을 지울 수 있습니다(옛 설계의 정리에도 있던 길). 정보 수준 여덟 가지는 보고서에 있습니다.
- 설정 화면의 기존 불안정 시험(`test_ui_qt_blogs_topic` 의 간헐 충돌)은 이 변경과 무관하게 기준에서도 재현됩니다. 이전에 임시로 둔 `gc.collect()` 완화 줄은 지웠고 `test_ui_qt_seeds` 는 세 번 모두 통과했습니다.
