# 확인 요청 036 — 앱 v1.0 범위 네 가지 (결정은 한 가지)

> 이 글은 **질문**입니다. 이슈 양식 '[답변] AI 확인 요청에 답하기' 에 **대상번호 036**(`36` 처럼 써도 됩니다)과 고른 보기(1·2)를 적어 주세요(2 를 고르시면 내용 칸에 바꿀 항목 번호와 내용). **답이 없으면 1(추천대로)** 입니다. 범위를 정하는 질문일 뿐 새 외부 접속·쓰기를 여는 승인이 아닙니다 — 그것은 갈래마다 따로 여쭙습니다.

## 지금까지(확인 035 ③ 이후)
- 앱 v1.0(정식 설치 파일 포함)까지의 격차를 조사했습니다. 완료 기준 열두 항목 중 **완료 3**(유료 호출 불가·티스토리 제외·로그에 키 없음)·**일부 8**·**시작 안 함 1**(Blogger 초안 저장)입니다.
- 남은 일은 **큰 일**입니다: AI 쪽만 5–8일(병렬), 운영자님 답과 실기 시험까지 합쳐 **전체 1.5–3주** 추정입니다. 가장 큰 막힘 셋: ① 설치·자동 업데이트·릴리스가 코드 0줄 ② 외부 쓰기·접속이 소스 상수로 완전히 막혀 있어 Pages 올리기·Blogger 초안·업데이트 확인을 새로 열어야 함(설계·독립 검증·승인 뒤) ③ 설치되는 앱은 화면 전용인데 글 흐름이 아직 명령줄에만 있음.
- **승인 없이 되는 갈래 다섯을 시작했습니다**(외부 접속·쓰기 0 — 안전 규칙 그대로): 화면에서 글 흐름 1단계(가져오기·미리보기·검토·승인)와 D-18 시험표, 새 PC 시작 안내·결정 색인 문서, 릴리스 점검 스크립트, 설계서 둘(네트워크 공통 틀·Pages 올리기·Blogger 초안 / 설치 도구 시험·업데이트·릴리스 워크플로·CI 화면 시험 칸). 두 단계 독립 검증은 그대로 유지합니다.
- 앞으로 **하나씩** 여쭐 것(설계서가 나오는 대로, 한꺼번에 보내지 않습니다): 설치 도구 시험용 수동 워크플로와 도구 내려받기 허락 / 외부 접속·쓰기를 어디까지 열지 / 라이선스·제품 이름·태그 규칙 등 결정.

## 이 요청이 묻는 네 가지 (추천 — 지금 갈래들이 이 값으로 진행합니다)
1. **화면 범위 — 최소 화면**: 설치된 앱에서 글 흐름을 화면으로 쓸 수 있게 합니다 — 가져오기 → 미리보기 → 검토 → 승인 → 네이버 A·B 복사 패키지와 상태·발행 주소 기록 → 발행 기록 목록. Pages·Blogger 내보내기 화면은 '이 버전에서는 꺼짐' 안내와 자리만 둡니다(켜기는 별도 승인). 더 많은 화면(통계·예약 현황 등)은 v1.0 에 넣지 않습니다.
2. **시험 글 방식(완료 기준 5·6번)**: 실제 외부에 올리는 시험은 **가짜 원격(컴퓨터 안의 빈 저장소)으로 자동 시험을 충분히 하고**, 실제 연결은 운영자님 PC 에서 시험 글 한 건(제목에 '시험' 표시, 가지로 올려 병합·확인한 뒤 삭제를 요청)만 합니다. 공개 글이 되는 일이라 그때 따로 승인을 받습니다.
3. **D-18 의 '예약 작업'·'배포 성공·실패 감지'**: 앱이 백그라운드에서 상시 돌거나 예약을 만들지 않습니다(앱 규칙 — 몰래 하지 않기). 그 기능은 **앱 밖(GitHub Actions)이 이미 하고 있다고 읽고**, 앱은 읽기 전용 상태 표시만 합니다.
4. **사진 속 글자 읽기는 v1.0 에서 제외**: 꺼진 채로 둡니다. 켜는 것은 지금까지처럼 별도 '켜기' 요청과 확인 4가지 뒤입니다.

## 1 을 추천하는 이유
- 모두 이미 정한 안전 규칙(앱은 몰래 하지 않는다·사진은 PC 를 떠나지 않는다·외부 쓰기는 승인 뒤)과 맞고, v1.0 을 가장 짧은 길로 끝낼 수 있습니다. 2 로 바꾸셔도 이미 시작한 갈래는 계속 진행하고 바뀐 범위만 다시 맞춥니다.
- 이 알림에는 운영자님 사진의 이름이나 읽은 글을 쓰지 않았습니다.
