# 확인 요청 004 — C-Type 2단계(새 틀·홈·설정 재구성) 시작 전 보고

운영자 승인(2026-11-06)에 따라 **2단계를 시작하기 전에 7가지를 먼저 보고**합니다. 자세한 표와 근거는 이 PC 의 KCY 폴더 `C-Type_2단계_시작전_보고.md`(저장소에는 올리지 않음)에 있고, 채팅에도 요약을 올렸습니다. 1단계(색·글자 토큰과 점수 링 등 부품)는 **병합 부탁 M006** 으로 따로 드립니다(검사 초록 뒤).

## 답이 필요한 것 4가지 (답이 없으면 기본값으로 시작)
| # | 질문 | 기본값 |
|---|---|---|
| 1 | 사이드바에 **완성된 화면만** 보여도 되나요? 지금은 홈·설정 2줄이고 나머지 5개(주제 후보·초안 작성·발행 기록·Seed 관리·블로그 관리)는 화면이 완성될 때 한 줄씩 늘며 '준비 중' 표시는 없습니다 | 예 |

## 7가지 한 줄 요약
1. **상단바**: 높이 60·한 줄 소개를 이름 옆으로·날짜와 시간(1분마다 갱신)·설정 아이콘 제거. 알림 종·검색·날씨·사용자·창 조절은 만들지 않습니다(기능 없음).
2. **사이드바 최종 메뉴**: 3묶음(핵심 작업 / 데이터·관리 / 시스템) 규칙, **완성된 화면만 보이고 준비 중 표시는 없음**. 숨기는 화면으로 가던 홈의 이동 단추도 같이 정리합니다.
3. **홈**: 제목·요약 카드 유지, 추천 목록은 Naver A/B 두 구역(점수 링 + 구간 라벨)으로 분리, 작성 중 초안·최근 발행·연결 상태를 새로 읽기 전용으로 보임. 활용 팁·빠른 작업·'주제 분석 시작' 단추는 해당 화면이 생길 때까지 뺍니다.
4. **설정**: 아코디언 구조 유지(지금 실제 묶음 5개), '정보' 묶음 추가, 한도 줄은 사용량 막대로, 키 입력(P4f)은 오른쪽 서랍으로 계획.
5. **1366×768 상세 창**: 서랍은 홈 전용으로 두고 고정 열↔서랍 자동 전환은 주제 후보 화면과 함께 만듭니다. 최소 창은 지금(900×560) 유지.
6. **1920×1080·125% 결과(1단계 점검)**: 1920×1080(100·125·150%)·1366×768(100·125%) 다섯 환경에서 글자 잘림 0·36px 미만 누르는 칸 0·가로 스크롤 없음(독립 검증이 다시 돌려 확인, 125·150% 는 환경 변수 흉내라 실제 윈도 125% 는 운영자 PC 확인으로 남음).
7. **ViewModel·시험**: 서비스·저장 변경은 필요 없음(읽기 연결만). UI 시험 약 100개를 고치거나 교체하고 약 60~90개를 새로 더할 것으로 추정.

## 2단계 쪼개기(제안)
UI-C1a 틀 → UI-C1b 설정 → UI-C1c 홈 데이터(읽기 연결, 화면은 그대로) → UI-C1d 홈 모양. 각각 독립 검증을 거치고 병합 부탁은 한 건씩 드립니다.

## 위험
사이드바가 처음엔 비어 보일 수 있음 · 새 홈이 실제 PC 에서 비어 보일 수 있음(엔진 후보가 아직 없으면) · 좁은 창·125% 에서 상단바가 겹칠 수 있음(소개부터 숨기는 규칙).
