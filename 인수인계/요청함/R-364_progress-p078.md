# 진행 현황 P078 — 이슈 #212 답 (본문 — 폰에는 싣지 않고 요청 열기로 읽습니다)

## 1. 접수한 내용과 제가 이렇게 이해했습니다
- **로컬 분석 후보 확정**: 1순위 PaddleOCR(한국어 v5 모바일 인식 모델 등 경량 세트), 비교용 RapidOCR(ONNX — 윈도 CPU 의 oneDNN 오류와 메모리 폭증을 피하려는 비교군). **Florence-2 와 Docling 은 제외**합니다(영어 출력·한글 글자 인식 불가·번역 부담 / 너무 무겁고 사진 근거 부족).
- **장면·상황은 AI 캡션 없이** 사용자가 사진마다 부가설명(대상·메모)을 직접 적습니다(예: '반찬 5개 사진').
- **사진 Manifest 결합**: 사진마다 ① OCR 로 읽고 **사용자가 확정한** 글자(visible_text) ② 사용자가 적은 종류·대상·메모(photo_type·user_subject·user_note)를 초안 작성 쪽에 넘기고, 본문에는 `{{사진 1}}` 같은 자리표시자를 둡니다. 사용자가 적지 않은 맛·가격·사실은 지어내지 않습니다.
- 이 이슈는 '접수'입니다. 내려받기·설치의 승인은 번호 있는 확인 요청(019)에 대한 답으로만 받습니다.

## 2. 진행 계획
1. **확인 019(시제품 내려받기 목록)**: Florence-2·Docling 을 뺀 **PaddleOCR 한국어 v5 + RapidOCR 두 세트만**으로 만듭니다. 패키지 이름·버전·파일 크기·SHA-256·출처 주소를 근거 있게 뽑는 읽기 전용 조사를 지금 돌리고 있고(내려받기 없음), 끝나는 대로 번호 있는 요청으로 보냅니다. 승인 전에는 아무것도 내려받거나 설치하지 않습니다.
2. **시제품 시험 항목에 반영**: 윈도 CPU 안정성(PaddleOCR `enable_mkldnn` 끄기 또는 오류가 보고되지 않은 PaddlePaddle 버전 고정, RapidOCR 의 ONNX 구동 비교)과 큰 사진 메모리 안전장치(긴 변 960px 상한 — 휴대폰 원본 크기 사진에서 메모리가 폭증하지 않는지)를 측정 항목에 넣습니다. 시제품은 이 PC 에서 다른 시험이 쉴 때 한 번에 하나씩 돌립니다(RAM 16GB).
3. **시험 사진**: '접근 가능한 사진을 직접 정해서 진행' 하라고 하신 것을 이렇게 읽었습니다 — 외부 작성자의 사진은 쓰지 않는 조건이 그대로이므로 **직접 만든 이미지**(한글 메뉴판·간판·영수증·안내문·제품 라벨을 글꼴로 그린 뒤 기울임·흐림·잡음·밝기 얼룩·JPEG 압축을 더한 것)와 **이 앱의 화면 캡처**를 씁니다. 정답 글자를 알고 있어 글자 오류율을 정확히 잴 수 있지만, 실제 사진보다 쉬워 점수가 후하게 나올 수 있으니 결과에 그 한계를 적겠습니다. 이 PC 의 사진 폴더는 열어 보지 않습니다. 실제 사진으로 최종 확인하고 싶으실 때만 몇 장을 골라 폴더 경로로 알려 주세요(선택).
4. **사진 부가설명 입력·Manifest·초안 자리표시자 구현(T1·T2, AI 없이)**: 보관함 병합 부탁이 나간 뒤 시작합니다. 첫 묶음 = 사진 첨부 화면에서 사진마다 종류·대상·메모 칸이 잘 드러나게 + 순서 + Manifest 규칙(확정한 것만 초안에 전달) + 초안의 `{{사진 N}}` 자리표시자. OCR 읽기 연결은 시제품 결과가 나온 뒤 별도 묶음(본체와 분리된 선택 플러그인)입니다.

## 3. 알려 드릴 점 — 초안 생성 프롬프트
- 지금 앱에는 **글을 AI 로 쓰는 호출이 없습니다.** 'AI 보조(선택)' 는 Gemini 키를 넣는 칸만 있고(기본 꺼짐), 초안은 규칙 기반으로 AI 없이 만들어집니다.
- 말씀하신 [확정 글자 + 사용자 부가설명 + 레퍼런스 스타일] 세 가지를 결합하는 방식은 **같은 세 입력을 규칙 기반 초안이 쓰도록** 먼저 설계·구현하겠습니다(지어내지 않기 규칙은 그대로 시험으로 고정). 프롬프트(글자로 된 지시문) 형태의 설계도 함께 문서로 남깁니다.
- 그 프롬프트로 **Google 의 AI 에 글자를 실제로 보내는 일**은 새 외부 연결·키 사용이라 이번 지시와 확인 018 의 범위 밖입니다. 하고 싶으시면 사진은 보내지 않고 글자(확정 글자·부가설명·스타일 요약)만 보내는 조건으로 번호 있는 확인 요청을 따로 보내겠습니다.
