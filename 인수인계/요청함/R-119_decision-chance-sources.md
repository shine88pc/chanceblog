# [R-119] Chance 글감 소스 추가 후보 — 추천과 결정 5가지

> **지금 하실 일은 없습니다.** R-116 에서 승인하신 '소스 후보 조사(목록만 제안)'의 결과이고, 소스를 실제로 추가하는 것은 아래 결정 뒤에 구현·독립 검증·병합 부탁(병합이 곧 승인)으로 따로 합니다. 결정 5가지는 모두 기본값이 있어 답이 없으면 기본값으로 진행합니다.
> 답하는 방법: 텔레그램의 **[답하기]** → 요청 번호 `r119` → 답변 **승인** → **선택** 칸에 `A=1 B=0 C=1 D=0 E=0` 처럼 적기(안 적은 항목은 기본값). 채팅으로 말씀해 주셔도 됩니다.

## 한눈에 (쉬운 설명)
1. **어떻게 조사했나**: 약관·저작권 안내와 `robots.txt`(자동 접속 허용 여부)를 먼저 읽고, 허용되는 곳의 공개 RSS 피드만 한 번씩 읽었습니다. 70개 사이트, 요청 181건(사이트당 5건 이하, 요청 사이 8초 이상). 막힌 곳은 우회하지 않았습니다.
2. **가장 중요한 사실**: 공식 기관 피드는 **느리고 얇습니다.** 새로 본 약 30개 중 하루 1건을 넘는 것은 4곳뿐이고 글감이 되는 것은 한국 국가데이터처(구 통계청) 하나였습니다. 그래서 **전부 붙여도 분야당 하루 1건 안팎**이 한계이고, 하루 두 편(한영 쌍)을 안정적으로 받치려면 R-116 의 '다음 분야로 계속' 고침과 함께 써야 합니다. 기술·미래는 공식 기관만으로는 가장 약합니다(합쳐 하루 약 0.6건).
3. **많이 막혀 있습니다**: UNICEF·세계은행·영국 NAO 는 약관(허가 필요), 미 EIA·한국소비자원은 `robots.txt` 가 막음, 미 GAO·뉴질랜드 RNZ 는 AI 접근을 명시적으로 막음, 미 NIH·CBO·호주 AIHW·OECD 등은 접속 거부, 정책브리핑은 RSS 서비스 중단(2026-07-01), 질병관리청은 인증서 오류였습니다.
4. **날짜 형식 함정**: 미 FTC 소비자 경고·국가데이터처 피드는 날짜 형식을 지금 생성기가 읽지 못해, 그대로 붙이면 날짜 없는 글감으로 보고 '오래된 소식 거르기'를 건너뛰어 **묵은 글감이 새 글처럼 통과**합니다. 그래서 이 둘은 날짜 읽기 한 줄을 고치는 작업이 먼저 필요합니다.

## 결정해 주세요 (기본값 있음)
- **A 1차 6곳 추가**: `1` **승인**(기본 — 구현 → 다른 AI 의 독립 검증 → 병합 부탁) / `0` 하지 않음
- **B 건강·소비자 안전 소스(ECDC·미 FDA·FTC 소비자 경고)로 '일상·마음' 채우기**: `0` **지금은 하지 않음**(기본 — 의료 조언·소송 주장 같은 위험을 막는 지침을 먼저 정해야 합니다) / `1` 지침을 함께 만들어 추가(FTC 소비자 경고는 날짜 읽기 고침 포함)
- **C 한국 국가데이터처 보도자료**(공급이 가장 큼: 하루 약 1.4건·요약 중앙 562자, 경제·사회·일상 세 분야를 받침): `1` **먼저 공공누리 유형을 AI 가 확인하고 결과로 다시 여쭙기**(기본) / `0` 하지 않음 — 한국어 소스라 날짜 형식·출처 문구·신뢰 도메인 고침이 따르고, 항목마다 공공누리 유형(1유형이어야 요약·번역 가능, 3·4유형은 변경 금지)을 확인해야 합니다.
- **D 미 노동부(DOL) 보도자료**(요약이 풍부하지만 행정부 홍보 톤이라 이전에 영국 재무·DWP 피드를 뺀 것과 같은 정치 중립 문제): `0` **제외**(기본) / `1` 정치 톤 필터와 함께 추가
- **E 공식 기관 밖(예: arXiv 논문 메타데이터)까지 허용**: `0` **하지 않음**(기본, 기술·미래는 얇은 채로 둠) / `1` 허용
