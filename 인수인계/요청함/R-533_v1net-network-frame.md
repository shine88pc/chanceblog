# 병합 요청 M129 — 앱 네트워크 공통 틀 (앱, T3 급 안전 점검)

> **병합 방식**: 지금은 AI 병합 기능이 **꺼져 있어** 운영자께서 직접 병합해 주세요. (`M129 승인` 이라고 답하셔도 아직 AI 가 병합하지 않습니다.) 이 요청은 앱 저장소 `chanceblog-desktop` 의 것이고, PR 제목 맨 앞이 `[M129]` 인 것 하나만 병합합니다. 검사는 이미 끝나 초록입니다. 급하지 않습니다(보통).

## 1. 무엇을 바꾸는지
앱 v1.0 이 나중에 바깥과 이야기할 때(공개 사이트 확인·갱신 확인·Blogger 초안 올리기와 연결) 쓸 **공통 틀**만 만듭니다. **여덟 개 스위치가 모두 꺼져 있어(출하 표가 비어 있음) 이 병합 뒤에도 앱은 바깥에 아무것도 보내지 않습니다.** `.github/`·`vendor/`·의존성·`service/external.py`·`ui/` 는 0줄입니다.
① **새 패키지 `src/chanceblog_desktop/net/`(7파일)**: 요청 한 건의 상태 기계·고정 호스트 표·엄격한 응답 파서·오류 변환·쿨다운과 접속 기록(메모리 50건)·공개 사이트 확인용 `fetcher`. TLS 는 인증서 검증을 켠 직접 만든 컨텍스트(최소 TLS 1.2)이고, 환경 변수로 믿는 인증서를 바꾸거나 세션 비밀 로그를 남기게 할 수 없습니다. 받는 바이트 상한·총 시간 마감·머리글 한도·응답 모양 검사가 있습니다.
② **`capabilities.py`**: 새 스위치 다섯과 기존 셋, 모두 `False`. 용도별 관문 `require_net(용도, 작업)` — 글자 그대로 `True` 만 열리고 모르는 용도는 거절합니다. 소스 훑기 허용 목록은 정확히 6곳이고 앱 기본 모듈은 `ssl`·`http.client`·`socket` 을 불러오지 않습니다.
③ `service/wiring.py`(어댑터 등록은 이 파일의 스위치 `if` 안뿐)·공개 사이트 확인 네 곳이 접속 틀 관문을 거치게 정리·`service/doctor.py` 의 '인터넷 접속' 줄(읽기만).
④ 묶음 자가 점검에 `tls` 한 항목(총 13개)을 더했고, 이미 병합된 릴리스 점검 스크립트(`scripts/release_check.py`)의 이름 표도 13개로 맞췄습니다.
⑤ 시험 새 모듈 여섯과 강화한 기존 시험 — 가짜 소켓과 루프백 TLS 서버만 써서 **외부 접속 0** 입니다.
⑥ 문서: 결정 D-720–D-739·`docs/SECURITY.md`('켜기 전 필수 조건' 표)·PACKAGE·ARCHITECTURE·CHANGELOG 문장·결정 색인(다시 만든 생성물).

## 2. 왜 필요한지
갱신 확인·공개 사이트 확인·Blogger 연결을 켜기 전에 '바깥으로 나가는 길은 한 곳뿐이고, 그 길이 엄격하며, 꺼져 있으면 어떤 길도 열리지 않는다' 는 것을 시험으로 못박아 두려는 것입니다. 뒤 갈래(공개 확인·갱신·Blogger)는 이 틀 위에서 스위치를 하나씩 켭니다.

## 3. 사용자가 체감하는 변화
**없습니다.** 켜는 스위치가 없어 앱의 동작과 화면은 그대로입니다.

## 4. 위험과 알려 둔 한계
- 이 병합은 길을 만들 뿐 **열지 않습니다.** 스위치를 켜는 변경은 따로 번호 있는 부탁으로 여쭙습니다.
- 환경 변수 `SSL_CERT_FILE`·`SSL_CERT_DIR` 가 설정된 PC 에서는 접속하지 않습니다(믿는 인증서를 바꿀 수 있어서 — 안내 문구 `NET_TLS_FAILED`).
- 파이썬 3.13 부터 표준 기본 환경이 더하는 두 검증 깃발(부분 사슬·엄격 검사)은 이 틀이 따르지 않습니다 — 출하 파이썬(3.12·3.10)에서는 표준과 같고, 파이썬 판을 올릴 때 따를지 정해야 합니다.
- git 하위 프로세스(`pages_branch`)의 환경 변수 정리는 공개 확인 갈래가 켜기 전에 해야 할 일로 `docs/SECURITY.md` 표에 적었습니다(지금은 해당 스위치가 꺼져 git 하위 프로세스가 뜨지 않습니다).
- `update_check` 용도는 자리표시자(호스트 하나·이동 0·내려받기 표 없음)입니다 — 갱신 갈래가 채웁니다.
- 묶음 정보 카드의 '열린 스위치 이름' 칸은 이번에 넣지 않았습니다(몰래 열린 채로는 빌드가 안 만들어집니다) — 다음 갈래가 맡습니다.
- 처음에 앱 검사의 우분투 칸에서만 빨갛던 시험 둘(최신 파이썬 패치의 `http.client` 가 홍수를 더 일찍 끊어 이유 낱말이 달라짐)과 환경 변수에 흔들리던 시험 80개를 고쳤습니다.
- **운영자께 여쭐 것(급하지 않음, 이번 병합과 별개)**: ① 묶음 정보 카드의 열린 스위치 표시를 이번에 뺀 것에 동의하시는지 — **추천: 다음 갈래가 맡는 안 그대로** ② 세션 비밀 로그 환경 변수(`SSLKEYLOGFILE`)는 '접속은 허용하되 열쇠 파일만 끈다' 로 정했습니다 — **추천: 그대로**.
