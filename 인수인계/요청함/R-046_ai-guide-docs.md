## 요청하신 것 (데스크톱 이전 관련) — 결과
조사를 제가 쓰지 않은 AI 에게 맡겨 공급사 공식 문서·약관·가격 페이지를 오늘 직접 읽게 했습니다. 문서는 **`docs/AI_MODEL_GUIDE.md`**(읽기 쉬운 안내)와 **`docs/analysis/2026-11-02_free-ai-code-editing.md`**(원문·출처 주소·확인 못 한 것)입니다.

**1. 무료 AI 로 코드 수정이 되는가** — 되는 길이 **일부 있지만 올해 많이 닫혔고, 품질은 아무도(저도) 측정하지 못했습니다.**
- 지금 $0 으로 "여러 파일 수정"이 문서에 적힌 것: **Google Jules**(하루 15건, 브랜치로 올려 줌), **Google Antigravity**(주간 한도), **GitHub Copilot Free**(VS Code 에이전트 모드), **Amazon Q/Kiro**(월 50), **Mistral Vibe Free**.
- 끝난 것: Gemini CLI 개인 무료(6월), Qwen Code 무료 로그인(4월), Roo Code(5월). 한도·약관이 몇 달마다 바뀌어 **월 1회 다시 확인**하는 절차를 넣었습니다.
- 개인 PC(16GB)에 설치하는 무료 모델은 코드 수정에는 권하지 않습니다(알림·요약 실험용만).
- 무료 입력은 대부분 **학습·열람에 쓰일 수 있어** 공개 저장소 코드만, 비밀 없이 보냅니다.

**2. 코드 수정 가능 / 불가를 나눈 안내** — 표로 정리했습니다. 코드 수정은 T0(문서·시험)·T1(모듈 하나)만 무료 AI 가 직접, T2(워크플로·발행 핵심)는 초안까지만, T3 는 금지이며 항상 브랜치→PR→자동 검사→운영자 병합입니다. 알림·한 줄 요약·오류 설명·주간 요약·글 초안은 **문장 틀이 기본**이고 Gemini 무료 키(지금 쓰는 것)를 보조로 씁니다(저장소가 쓰는 모델 이름 3개는 접근 제한 영향이 없는 것을 확인했습니다).

**3. DeepSeek-Coder** — 참고하라고 하신 대로 판단했습니다: PC 에 받아 쓰는 DeepSeek-Coder-V2 는 2024년 모델이라 **비추천**, 지금의 DeepSeek 은 공식 API(`deepseek-flash`·`deepseek-v4-pro`)로 **무료가 아니라 선불 소액**(경량 사용 월 약 $1~10, 조사자의 계산)이며 서버가 중국입니다. **조건부 사용**: T0·T1 만, 공개 저장소 코드만(비밀·로그 원문 금지), 공식 API + 선불 $5 안팎, 브랜치+PR+검사 유지.

**4. 무료만으로 가능한가** — 작은 수정(T0·T1)은 가능성이 있고, **데스크톱 프로그램을 새로 만드는 일**은 무료 한도로 모자랄 가능성이 큽니다(추정). 그때 가장 덜 나쁜 길이 DeepSeek API 선불 소액입니다(0~3단계 추천 순서는 문서 §3-3).

## 운영자가 정할 것 3가지 (답하지 않으면 모두 '하지 않음')
