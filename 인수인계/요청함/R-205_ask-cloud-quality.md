# 확인 요청 005 — 글쓰기 품질 향상이 기존 Pages·Blogger 글쓰기에도 적용되나요? (이슈 #151 답)

운영자가 이슈 #151(진행 범위 '논의·준비까지만')로 물으셨습니다: **데스크톱 프로그램의 글쓰기 품질 향상 프로세스를 올리고 있는데, 기존에 운영 중인 Pages·Blogger 글쓰기도 함께 향상시키는 안으로 진행되고 있는 것이 맞는지.**

## 짧은 답: 아직은 아닙니다 (의도적으로 나눠 두었습니다)
- 데스크톱 쪽에서 올리고 있는 품질 체계 — **주제 엔진**(채널별 점수·같은 주제 묶음 2개 제한·중복 판정)·**건강·협찬 안전 판정**·**규칙 기반 초안 본문**(지어낸 사실을 세 겹으로 막음 — 독립 검증 중)·**위험 표현 검사** — 는 **네이버 A/B 초안·복사 흐름 전용**이고 데스크톱 앱 안에서만 돕니다.
- Pages(Chance)와 Blogger 영문·한글의 **자동 글쓰기는 블로그 저장소의 GitHub Actions 가 지금 코드 그대로** 합니다. 데스크톱 작업이 그쪽을 바꾼 것은 없습니다 — 전략 원칙(기존 GitHub Pages·Blogger 운영에는 직접 변경하지 않는다)을 지킨 결과이고, 오늘도 Chance·Blogger 영문·한글 모두 정상 게시됐습니다.
- 다만 **그쪽에도 자체 품질 장치는 이미 있습니다**: 생성물 게이트(HTML 정화·정책·중복·유사도 — 걸리면 게시하지 않음)와 주제 선정(시드 + AI 확장·쿨다운·블로그 간 중복 방지·계절 맞춤). 데스크톱의 새 체계(건강·협찬 판정·주제 묶음 제한·지어내지 않기)와 **같은 기준이 클라우드 쪽에 그대로 들어 있는지는 아직 확인하지 않았습니다** — 그래서 아래 1번(읽기 전용 점검)이 첫 단계입니다.
- 설계는 5채널로 넓힐 수 있게 되어 있습니다(주제 엔진에 Pages·Blogger 채널 칸이 이미 있고 후보 생성만 '기본 꺼짐'). 지금은 네이버 A/B 를 먼저 완성하는 순서입니다.

## 선택지 (기본값 1)
1. **읽기 전용 점검부터(권장, 운영 변경 0)**: 이미 발행된 Pages·Blogger 글을 데스크톱의 같은 검사 기준(위험 표현·단정·중복·유사도)으로 훑어 **리포트만** 만듭니다. 글쓰기·워크플로·발행·설정은 건드리지 않습니다. 리포트를 보고 어디를 개선할지는 **다음 확인 요청**으로 범위를 정합니다.
2. **지금 방침 유지**: 데스크톱은 네이버 전용으로 완성하고 클라우드는 그대로 둡니다(네이버·화면 묶음이 끝난 뒤 다시 논의).
3. **클라우드 개선 계획서까지만 먼저**(논의·준비까지만): 점검 없이 개선안(검사 기준 공유·주제 선정 규칙 맞춤 등)을 문서로 정리합니다. 실제 변경은 별도 승인입니다.
4. **다른 의견**: 내용에 적어 주세요.

## 하지 않는 것
이 확인 요청의 어떤 선택도 Pages·Blogger 의 실제 글쓰기·예약 실행·발행 설정을 바꾸지 않습니다. 바꾸는 단계는 광고·발행에 닿을 수 있어 **운영자 승인이 필요한 별도 요청**으로만 합니다.

## 답하는 방법
이슈 양식 `AI 확인 요청에 답하기(대상번호)` 에서 대상번호에 **005** 를 쓰고 선택(1~4)과 내용을 적어 주세요. 답이 없으면 기본값(1)으로 점검 설계를 준비하고 결과는 진행 현황에 한 줄로 알립니다(운영 글쓰기는 그대로 둡니다).
