# 확인 요청(할 일) — 개인 PC 에서 시험용 Package 만들어 시험하기

> 이 글은 **부탁**입니다. 텔레그램에서 번호에 맞춰 `대상번호/1/` 처럼 답해 주세요. 답이 없으면 기본값(2번, 나중에)으로 두고 아무것도 바꾸지 않습니다. **이 일은 회사 PC 가 아니라 개인 PC 에서 합니다**(회사 PC 는 관리자 권한이라 '일반 사용자' 시험이 되지 않습니다).

**한눈에**
- 개인 PC 로 앱을 가져가 제한적으로 써 볼 준비가 **코드 쪽은 모두 끝났습니다.** 보안 수정(비밀 가리기·키 표시 제거·외부 게시 완전 차단·비밀 모양 저장 중지), 초안 저장, 백업·복원, 만드는 도구, 빌드 워크플로가 모두 병합됐고 각각 독립 검증을 거쳤습니다.
- 남은 것은 **개인 PC 에서만 확인할 수 있는 시험**(표준 사용자 계정에서 실행, 다른 일반 계정에서 데이터·키에 못 닿는지, 키 등록·삭제)과 그 전에 **Package 를 만드는 단추 한 번**입니다. 제가 대신 누를 수 없는 일입니다.
- 이 Package 는 **서명이 없는 개인 PC 제한 시험용**이고 어떤 서비스에도 접속하지 않으며 글을 어디에도 올리지 못합니다(이번 버전은 소스에서 아예 꺼져 있습니다). 키 칸에는 **가짜 글자**만 넣습니다.

## 하실 일 (3단계)

**1. Package 만들기 — GitHub 에서 단추 한 번**
- 개인 PC 브라우저로 GitHub 의 데스크톱 저장소(`chanceblog-desktop`)를 엽니다.
- 위쪽 `Actions` 탭 → 왼쪽 목록에서 **'Package — 개인 PC 제한 시험용 빌드(수동)'** 를 고릅니다.
- 오른쪽의 `Run workflow` 단추 → 나오는 창의 초록색 `Run workflow` 를 누릅니다(입력칸은 없습니다). 아래 'main' 이 선택돼 있는지만 봅니다.
- 몇 분 뒤(보통 5–20분) 실행 줄이 초록 체크가 되면 성공입니다. 빨간 ×가 되면 **실패한 단계의 이름만** 알려 주세요(아래 3번 답).

**2. 내려받기**
- 성공한 실행을 누르고 맨 아래 `Artifacts` 의 **`ChanceBlogDesktop-preview`** 를 내려받습니다(14일 안에, GitHub 에 로그인된 상태여야 합니다). 풀면 파일 네 개(압축 파일·`SHA256SUMS`·`PACKAGE_INFO.md`·`PACKAGE_INFO.json`)가 나옵니다.
- 실행 로그의 'SHA-256 보기' 단계에도 같은 값이 찍혀 있어 이중으로 대조할 수 있습니다.

**3. 시험지대로 시험하기(약 한 시간)**
- 시험지는 저장소의 `docs` 폴더 **`PERSONAL_PC_TEST.md`** 입니다(개인 PC 브라우저로 GitHub 에서 열어 보시면 됩니다). 0단계(압축 파일 확인·SHA-256 대조)부터 8단계(지우기)까지 한 칸씩 `[ ]` 를 하며 갑니다.
- 결과는 시험지 7단계 표처럼 **통과/실패와 실패한 단계 번호**만 이 질문에 답으로 보내 주세요(길면 몇 번에 나눠도 됩니다).

## 알아 두실 점 (솔직하게)

- **첫 실행이 실패할 수 있습니다.** GitHub 의 Windows 컴퓨터 환경이 제 PC 와 달라서입니다. 실패해도 비밀·쓰기가 없어 해가 없고, 실패한 단계 이름을 알려 주시면 고쳐서 다시 부탁드립니다.
- **서명이 없어** SmartScreen('Windows의 PC 보호') 경고나 '스마트 앱 컨트롤' 차단이 뜰 수 있습니다. SmartScreen 은 `추가 정보 → 실행` 이고, **스마트 앱 컨트롤이 막으면 설정을 바꾸지 말고** 그 사실만 알려 주세요(시험지 맨 아래 '막혔을 때'). 시험하다 설정 변경이나 설치를 요구하는 창이 뜨면 누르지 말고 창 이름만 적어 주세요.
- 이 PC 의 Windows Defender 서비스가 꺼져 있어 **악성코드 검사는 못 했습니다**(정보 카드에 '검사 안 함'으로 적힘). 개인 PC 에서 시험지 0-2 대로 압축 파일을 검사해 주세요.
- 이 시험은 **블로그 자동 실행·재개와 무관**합니다(블로그는 일시정지 그대로, 재개는 따로 승인 요청 예정).
- 서명·스마트 앱 컨트롤 설정 변경·릴리스 게시는 이번 승인 범위가 아닙니다.
