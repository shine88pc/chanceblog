# 확인 요청 029 — 공개 사진 가지를 지울까요 (결정은 한 가지)

> 이 글은 **질문**입니다. 이슈 양식 '[답변] AI 확인 요청에 답하기' 에 **대상번호 029**(`29` 처럼 써도 됩니다)와 고른 보기(1·2·3)를 적어 주세요. **답이 없으면 1(그대로 둠)** 입니다.

## 무엇을 지우는 것인가
- 앱 저장소 `chanceblog-desktop` 의 임시 가지 `ai/claude/NO-MERGE-ocr-eval-photos` **하나**입니다. 들어 있는 것: 올려 주신 사진 17장(`photos` 폴더)·판정용 결과 페이지(`results` 폴더 — 사진과 읽은 줄을 나란히 둔 글)·안내 글(`README.md`). 앱 코드와 이어지지 않는 빈 가지라 **지워도 앱·블로그에는 영향이 없습니다.**
- 이 저장소는 **공개**라서 지금도 누구나 사진과 읽은 글을 볼 수 있습니다. 가지를 지우면 목록과 파일 보기에서 사라지지만, 이미 내려받았거나 캡처한 사람·검색 서비스의 보관본·GitHub 가 한동안 쥐고 있는 기록(커밋 주소를 정확히 아는 경우)까지는 **제가 없앨 수 없습니다.**
- AI 가 이 PC 안에 둔 **복사본**(`photolab/eval_op/clone`)은 PC 밖으로 나간 적이 없고 이 결정과 별개입니다. 필요 없으시면 따로 지워 달라고 알려 주세요.

## 선택지
1. **그대로 둠(기본)** — 공개 가지를 남깁니다. 나중에 같은 사진으로 다시 판정받고 싶을 때 편하지만 사진이 계속 공개됩니다. 직접 지우시려면 GitHub 의 가지 목록에서 지울 수 있습니다.
2. **지움(추천)** — 평가가 끝났고 AI 는 PC 안의 복사본으로 숫자 시험을 마쳤으며 앞으로 이 사진을 올릴 곳이 필요 없습니다. 공개 노출을 줄이는 쪽이 안전합니다. 다시 판정이 필요해지면 그때 새로 올려 주시면 됩니다.
3. **시험판 평가 때까지 두었다가 그때 지움** — 글자 읽기 b 단계 시험판이 나온 뒤 같은 사진으로 다시 판정받을 가능성을 열어 둡니다. 그때까지 공개가 이어지고, 시험판 평가 뒤 다시 지울지 여쭙습니다.

## 2 를 추천하는 이유
- 사진은 처음부터 '공개돼도 괜찮은 것' 으로 올려 주셨지만, 공개 기간이 짧을수록 좋고 더 필요한 일이 없습니다.
- 운영자님이 직접 해 보실 실제 사진 시험(켜기 전)은 앱을 만든 뒤 **본인 PC 에서 본인 사진으로** 하게 되어 이 가지가 필요하지 않습니다.
- 2 를 고르셔도 글자 읽기의 나머지(확인 026·028 의 조건)는 그대로입니다.

## 알려 드릴 점
- 지우는 일은 승인이 필요한 일이라 번호 있는 확인 요청으로 여쭙습니다. 2 가 아니면 지우지 않습니다.
- 알림에는 사진 파일 이름이나 읽은 글을 쓰지 않았습니다.
