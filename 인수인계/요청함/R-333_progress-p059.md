## 정기 알림 문구를 이렇게 고쳤습니다(이 PC 의 알림 프롬프트·템플릿, 저장소 사본은 도구 정비 때 맞춤)
1. **병합은 `[M###] 병합 부탁` 알림이 나간 PR 하나만** 하라고 씁니다. 진행 현황 알림은 병합을 시키는 글이 아니므로 `waiting`·`next`·`now`·본문 어디에도 병합 행동을 암시하는 앞날 문장('병합하시면 됩니다'·'부탁이 오면 병합'·'곧 올 수 있습니다')을 쓰지 않습니다.
2. **모든 진행 현황 알림에 '열린 PR' 줄**을 필수로 넣습니다 — 쓰는 시각의 실제 값으로 `열린 PR: 없음` / `#N [M###] — 병합 부탁 알림 나감(병합해도 됨)` / `#N [M###] — 병합 부탁 알림 전(아직 병합하지 마세요)` 셋 중 하나.
3. `waiting` 칸에는 **운영자가 지금 해야 하는 것만** 적습니다(병합 대기는 부탁 알림이 나간 것만, 없으면 '없음(알림 없는 열린 PR 은 병합하지 마세요)').
4. 부탁 알림 없이 병합된 일이 있으면 다음 알림에 **사실만**(시각·변경·직접 확인 결과·되돌릴 것 유무) 적고, '부탁 없이' 같은 탓하는 표현은 쓰지 않으며, 직전 알림 문구가 신호였는지 먼저 점검합니다.
5. 본문 맨 끝에 항상 한 줄: '병합은 `[M###] 병합 부탁` 알림이 나간 PR 하나만 하세요. 알림이 없는 열린 PR 은 아직 병합하지 마세요.'
6. 이미 나간 알림은 고치지 않고(요청 가지는 덧붙이기만) 잘못이 있으면 이렇게 **새 알림으로 정정**합니다.
