# [R-168] 결정 부탁(승인 필요) — P4 화면 시작 전 보고

> **지금 하실 일**: 아래 변경안을 보시고 **승인 또는 보류**를 알려 주세요. 11-05 에 주신 지시('7가지를 현재 데이터 모델·실제 연결 상태에 맞춘 변경안으로 먼저 보고한 뒤 시작')에 따라 **승인 전에는 화면(UI) 코드를 한 줄도 바꾸지 않습니다.** 질문 9개는 모두 **기본값**(가장 보수적인 쪽)이 있어 "승인"만 하셔도 기본값으로 시작합니다.
> **답하는 방법(지금은 옛 양식)**: 텔레그램의 [답하기] → 요청 번호 `r168` → 답변 **승인**(또는 보류) → **선택** 칸에 바꾸고 싶은 것만 `Q2=② Q7=②` 처럼 적기. 채팅으로 말씀해 주셔도 됩니다.

## 먼저 알려 드릴 사실 3가지 (코드를 읽어 확인 — 프로그램을 실행해 본 것은 아닙니다)
1. **지금 화면은 홈 한 장뿐**입니다. 메뉴 6개 중 홈만 만들어져 있고 주제 후보·초안 작성·발행 기록·블로그 관리·설정은 모두 "이 화면은 아직 만들고 있어요" 자리표시입니다. 그래서 7가지 중 #3~#6 은 '고치기'가 아니라 '새로 만들기'입니다.
2. 화면은 **연결 상태·한도·주제 엔진·초안 서비스를 아직 한 번도 부르지 않습니다.** 연결 용도 7개는 모두 실제 호출 코드가 없어 '연결됨'이 나올 수 없습니다 — 그래서 설정 화면은 '준비 중'을 정직하게 보여 줍니다.
3. 후보 화면이 실제 데이터를 보이려면 P3(주제 엔진 저장·서비스) 병합이 먼저입니다(지금 독립 검증 지적을 고치는 중, R-167). **설정(P4a)·프로필·색(P4b)은 P3 와 독립**이라 먼저 시작할 수 있습니다.

## 7가지 — 지금 모습과 변경안

## P4 쪼개기 (한 번에 한 묶음씩, 묶음마다 병합 부탁 — 화면 사진 몇 장과 결정 몇 개)

합계 약 30~40시간(AI 작업 시간) → 2~3일. 화면은 AI 가 직접 눈으로 못 보므로 **자동 점검**(화면 없는 렌더링으로 접근 이름·누르는 칸 크기·Tab 이동·글자 잘림 확인)과 **화면 사진 확인**을 묶음마다 합니다. 운영자 PC 의 윈도 125·150% 배율·한글 입력기·화면 읽기는 AI 가 확인하지 못하는 부분입니다.

## 승인하시면 / 답이 없으면
**승인**하시면 기본값(답하신 Q 는 그대로 반영)으로 **P4a(설정 화면)** 부터 구현→독립 검증→병합 부탁 순서로 시작합니다. P4a·P4b 는 P3 와 독립이라 P3 병합을 기다리지 않고, P3 병합 뒤 P3b→P4c→P4d→P4e 순으로 잇습니다. **보류**하시거나 **답이 없으면 화면 코드는 시작하지 않고** 기다립니다(그동안 P3 마무리·병합과 알림 표준화 같은 화면 밖 작업은 계속). 어떤 경우에도 키 값은 화면·로그·저장소에 쓰지 않습니다.

## 확인하지 못한 것(솔직히)
- 프로그램을 **실행해 보지 않고** 코드와 저장소의 홈 화면 사진 1장으로 확인했습니다(실제 픽셀·윈도 배율·한글 입력기·화면 읽기는 확인 못 함).
- 두 프로필 이미지의 색 원본을 이 PC 에서 찾지 못해 7번 색 값은 이름(크림·코랄·민트 / 네이비·블루·청록) 기준의 **임시 제안**입니다.
- P3 가 수정 중이라 후보 화면이 부를 서비스 함수의 이름·모양이 조금 바뀔 수 있습니다.
- 옛 '추세'(상승·보합·하락, 사람이 넣은 값)를 실제로 쓰고 계신지 모릅니다 — 새 관심도의 '상승·보통·하락'과 낱말이 같아 후보 화면에서 이름을 구분해 둘 예정입니다.
