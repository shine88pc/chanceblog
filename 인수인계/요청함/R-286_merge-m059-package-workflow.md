## 이 워크플로가 하는 일
- GitHub 의 Windows 컴퓨터(러너)에서 **개인 PC 제한 시험용 Package(미서명)를 만듭니다.** 앞서 병합한 M058(만드는 도구)을 실행하는 것뿐입니다.
- **사람이 Actions 화면에서 `Run workflow` 를 누를 때만** 돕니다(푸시·PR·예약 실행 아님, 입력칸 없음 — 입력받은 글을 명령에 넣는 길이 없습니다).
- **읽기 권한 하나만** 쓰고 비밀 값·토큰·서명 단계가 없습니다. 올리는 것은 압축 파일·`SHA256SUMS`·`PACKAGE_INFO.md`·`PACKAGE_INFO.json` **네 개뿐**이고 14일 보관하며, 빌드 로그·작업 폴더·데이터는 올리지 않습니다.
- 빌드는 작업 트리가 깨끗하지 않거나 설치된 도구 버전이 잠금 파일과 다르거나 묶음 자체 점검·외부 쓰기 관문 값이 틀리면 실패합니다. 시험 빌드 옵션은 쓰지 않으므로 이 워크플로가 만드는 것은 조건을 모두 통과한 '정식' 빌드뿐입니다. 실행 로그에 SHA-256 이 찍혀 개인 PC 에서 대조할 수 있습니다.
- 쓰는 액션 셋(`actions/checkout`·`actions/setup-python`·`actions/upload-artifact`)은 **전체 커밋 번호로 고정**했고, 세 번호 모두 오늘 공식 저장소의 릴리스 태그(v4.4.0·v5.6.0·v4.6.2)와 직접 대조해 일치함을 확인했습니다.
