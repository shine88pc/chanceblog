# 확인 요청 035 — '프로그램 완성'의 뜻 (결정은 한 가지)

> 이 글은 **질문**입니다. 이슈 양식 '[답변] AI 확인 요청에 답하기' 에 **대상번호 035**(`35` 처럼 써도 됩니다)와 고른 보기(1–4)를 적어 주세요. **답이 없으면 4(정하지 않음)** 입니다 — 지금처럼 안전 → 시험 두 단계 독립 검증을 유지하고 절감 모드는 시작하지 않습니다. 급하지 않습니다(보통).

## 왜 묻는지
- 11-23 13:19 에 '지금은 프로그램 완성이 우선이니, **완료된 시점부터** 에이전트 쪽 변경(절감 모드)을 진행하라' 고 정하셨습니다. 그런데 **무엇이 '완료'이고 누가 어떻게 판정하는지**는 문서(AGENT_RUNBOOK 8-3 '미정')에 비어 있어, 제가 스스로 '완료'라고 판단해 절감 모드를 시작하지 않으려고 묻습니다.
- 절감 모드 6가지: ① 감시기 하나로 합치기(이미 적용) ② 감시기 시작·만료 알림 없애기(이미 적용) ③ AI 는 일이 있을 때만 켜서 짧게 일하고 닫기 ④ 검증 에이전트는 갈래당 1명(안전+시험 겸임) ⑤ 문서만 바뀌는 묶음은 에이전트 없이 검사(CI)와 자동 점검만 ⑥ 진행 현황(P)은 이벤트가 있을 때만. 시작 전인 것은 ③–⑥ 입니다.

## 보기와 지금 거리
1. **개발 동결(추천)** — 진행 중인 갈래가 모두 병합되고 검사(CI) 시간 문제가 정리된 상태. 지금 남은 것: 의존성 고정(AP7) 구현 병합 · 시험 시간 줄이기 병합 · 검사 속도 보고서와 별도 변경안(승인 대기) · 2차 독립 감사 지적 처리. 이 기준을 채우면 제가 알리고, 운영자님이 '선언' 이라고 답하시면 절감 모드를 시작합니다.
2. **운영 개시까지** — 1 에 더해 발행 정지 해제 경로가 끝나는 것: 발행 안전 병합(끝남) → 그림자 실행 3회차 결과 평가(운영자님 올려 주신 첨부 확인 대기) → 증거 한 장·설정 3건 확인 → `PIPELINE_PAUSE` 해제(운영자님만) → 초안 PR 3개 시험.
3. **앱 v1.0 까지** — 2 에 더해 정식 설치 파일과 v1.0(지금은 개발 실행과 시험용 Package 뿐, 글자 읽기 켜기 전 운영자님 몫 셋이 남음). 가장 멉니다.
4. **정하지 않음(기본)** — 아무것도 안 바꾸고 지금처럼.

## 1 을 추천하는 이유
- 제 일의 끝(더 만들 갈래가 없음)을 가장 정확히 가리키고, 2·3 은 운영자님 몫(그림자 3회차·변수 해제·설치 파일 확인)에 달려 시점이 제 손 밖입니다. 1 로 정해도 발행 해제·앱 일은 그대로 계속 진행하고, 절감 모드만 일찍 시작합니다.
- 어느 보기든 **T3 변경(워크플로·권한·시크릿·광고 등)은 선언 뒤에도 두 단계 검증을 유지**하고, 병합은 운영자님만 합니다. 안전 규칙은 하나도 느슨해지지 않습니다.

이 알림에는 운영자님 사진의 이름이나 읽은 글을 쓰지 않았습니다.
