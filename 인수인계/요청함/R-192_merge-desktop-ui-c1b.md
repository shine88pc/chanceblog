## 이번 묶음이 하는 일 (확인 요청 004 에 주신 결정 7 '설정'의 구현)
1. **사용량 막대**: 설정 카드의 한도 줄이 **기간마다 막대 한 줄**이 됩니다 — 높이 8, 표시한 퍼센트로 **0~79% 파랑·80~89% 노랑·90% 이상 빨강**, 한도를 넘으면 `한도 넘음`, **기간·쓴 수·한도·퍼센트가 함께** 보이고(`이번 달 340 / 27,000회` + 오른쪽 `1%`) 예시 값에는 `예시` 꼬리표가 붙습니다. 콘솔 한도(월 30,000회)는 지금처럼 작은 글로 따로 있습니다.
2. **모르는 값은 막대 없이 글**: 사용량을 못 읽으면 `확인할 수 없어요` 글만 보이고 빈 막대는 그리지 않습니다(1단계 독립 검증이 찾은 결함 M1 — 실제 0회는 빈 길과 `0%` 로 구별됩니다).
3. **묶음 이름과 '정보' 묶음**: 접이식을 데이터 Provider·이미지·AI 보조·발행·연결·**정보** 다섯 묶음으로 맞추고, 옛 '고급 > 진단 정보' 를 마지막 '정보' 묶음(버전 + 진단 정보, 접어 둠)으로 옮겼습니다. 기준 문서의 다른 묶음(일반·블로그 프로필·주제·Seed·백업·보안)은 해당 화면이 없어 보이지 않습니다.
4. **카드 글 줄이기**: 카드의 긴 안내 문장 7개를 줄였습니다(309→276자). 뜻과 안전 안내(비밀 값은 표시하지 않음·키를 화면에서 넣는 기능은 아직 없음 등)는 그대로이고, 키 입력·키 관리 단추는 만들지 않았습니다(다음 묶음 몫).
5. 점검 사진 16장(바뀐 14·새 2)을 새로 찍었습니다.
