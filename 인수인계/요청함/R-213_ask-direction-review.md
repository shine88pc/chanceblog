# 확인 요청 006 — 감사 결과에 따른 방향 검토 12가지 (요청서 6)

요청서 6 은 현재 합의된 방향에서 크게 벗어나는 항목을 **수행하지 말고 목록으로 한 번에** 올리라고 했습니다. 감사(R-211)와 보완·재개 계획서(R-212)를 바탕으로 항목마다 (무엇이 왜 벗어나는지 / 영향 / 선택지와 추천)을 적었습니다. 추천은 ★ 표시입니다. **어느 선택도 곧바로 글·설정·광고를 바꾸지 않습니다.** 실제 변경은 배치마다(또는 구체 변경안마다) 채팅 승인을 따로 받습니다. 확인 요청 005 는 요청서 6 으로 답이 와서 '선택 1 확장'으로 처리했습니다.

## 1. 언어·글 수 전략 (방향 검토 ②·⑥)
- **왜 벗어나나**: 지금은 모든 이야기를 한·영 쌍으로 공개하는 것이 기본인데, 감사에서 22쌍이 번역 복제 구조였고 '사이트당 소수의 완성도 높은 글'이 목표입니다.
- **선택지**: A★ 쌍 단위 정리 — 비공개·통합 5개 이야기를 내리고 21개를 재작성, 통과 못 한 쪽은 임시 비공개, 최종 15–20개 이야기 예상(30–40편) / B 국문 우선 — 영문은 통과한 각색만 공개 / C 이야기 15개 이내로 강한 축소(15–30편).
- **영향**: A 는 작업량이 큽니다(약 2–3주). B 는 영문 글이 일시적으로 크게 줄고, C 는 글 수와 주제 폭이 크게 줄어 공공 자료 주제 정체성이 약해집니다.

## 2. 응급 정정 배치 1(10편) 준비 시작
- **내용**: 사실 오류·지어낸 문장이 확인된 10편(S25 한·영, S17 한·영, S10 국문, S11 국문, S13 영문, S08 영문, S15 영문, S16 국문)의 정정안.
- **선택지**: A★ 예 — 근거 표와 전후 비교·URL 영향을 만들어 **적용 승인을 따로 요청** / B 아니오 — 계획 승인까지만.
- **영향**: 준비는 작업 폴더에서만 하고 공개 글은 승인 전에 바뀌지 않습니다.

## 3. 비공개 대상 이야기 5개의 시점 (S03·S09·S12·S20·S22 — 비공개 전환은 T3)
- **선택지**: A★ S12(멘토링)·S20(11-05 종료된 행사)는 W0 와 함께 비공개 승인을 요청하고 S03·S09·S22 는 W1 에서 / B 5개 모두 W1 / C 비공개하지 않고 재작성으로 살림.
- **영향**: 삭제가 아니라 `published: false` 입니다. 주소는 404 가 되고 사이트맵·피드에서 빠집니다(되돌릴 수 있음).

## 4. Pew 글과 열람 규칙 (S07·S08·S09·S22)
- **왜 벗어나나**: Pew 약관 §3 은 무허가 자동 수집을 막습니다. 생성기는 RSS 요약만 쓰고 11-04 표본은 페이지를 읽었으며 이번 감사는 열지 않아 기준이 셋입니다. 표 재게재 범위도 불명확합니다.
- **선택지**: A★ Pew 에 허가 문의(운영자 이메일로 보낼 문안은 제가 작성) + 답이 올 때까지 열람 규칙을 'RSS 요약만'으로 통일, S09·S22 는 비공개 후보, S07·S08 은 정정만 / B 허가 문의 없이 사람이 직접 원문을 읽고 재작성 / C 현행 유지(비추천).
- **영향**: Pew 글 8편(4쌍)의 처리와 앞으로의 생성 규칙이 정해집니다.

## 5. 한국 출처 이용 조건 불명확 (식약처 S06, NST S04, 같은 계열 S03)
- **왜 벗어나나**: 해당 페이지에는 'All rights reserved'만 있고 공공누리 유형 표시가 없습니다. 프로젝트 정책은 '불명확은 유예 + 허가 문의'입니다.
- **선택지**: A★ 정책대로 해당 이야기를 임시 비공개하고 허가 문의 / B 문의하며 공개 유지(정책 예외 승인 필요) / C 이용 조건이 확인된 공식 자료로 대체 재작성.
- **영향**: S06 국문은 감사에서 가장 잘 쓴 글 중 하나(A)라, A 를 고르면 좋은 글을 잠시 내리게 됩니다. 그 글만 B 나 C 로 고를 수도 있습니다.

## 6. 루트 랜딩과 광고 코드 (방향 검토 ③·⑤, 별도 저장소·T3)
- **왜 벗어나나**: 루트 주소는 본문 약 610자·광고 로더·자체 소개/개인정보 없음입니다. AdSense 가 도메인 첫 화면으로 보는 곳일 가능성이 있습니다(확정 아님).
- **선택지(루트)**: A★ 정식 홈으로 보강(편집 원칙·분야·최근 글이 JS 없이 보이게 + 소개·개인정보 링크) / B 블로그 홈으로 이동 / C 현상 유지.
- **선택지(광고 코드·표시)**: A★ 콘텐츠 정비가 끝날 때까지 변경 없음 / B 루트의 로더 제거.
- **영향**: 어느 쪽이든 구체 변경안(바뀌는 파일·전후)을 보고 따로 승인을 받습니다. `ads.txt` 는 승인 뒤 할 일로 두고 지금은 하지 않습니다.

## 7. 고정 페이지 문구와 운영자 노출 수준 (방향 검토 ④)
- **왜 벗어나나**: 소개·개인정보는 광고 표면에 닿는 페이지입니다. 소개에는 운영 주체·편집 책임·검수 절차·정정 이력이 없고, 개인정보 문구('광고 미게시')는 광고 로더 존재와 어긋날 수 있습니다.
- **선택지**: A★ 편집부(필명) 표기 + 편집 책임·검수 절차·정정 이력 보강 + 개인정보 '광고 미게시' 문구를 사실에 맞게 갱신 / B 운영자 실명 소개 / C 현상 유지.
- **영향**: 실제로 하는 검수만 적습니다(하지 않는 검수는 쓰지 않음). 가짜 인물·AI 를 사람처럼 표기하지 않습니다.

## 8. Blogger 영문(AdSense 검토 중) 처리 — 검토 중 수정 허용 범위
- **왜 벗어나나**: 검토가 끝나기 전에는 대규모 수정·비공개·구조 변경을 하지 않기로 했습니다. 다만 안전 의심 4편(천식 식품·내장지방·단백질 비교·간 질환 징후)은 R-210 에서 보고했습니다.
- **선택지(안전 4편)**: A★ 지금 초안으로 되돌림(삭제 아님, 복구 가능) / B 검토 결과가 나온 뒤로 미룸.
- **선택지(소개·문의·개인정보 페이지)**: A★ 지금 추가(새 페이지만 더하고 기존 글은 바꾸지 않음) / B 검토 결과가 나온 뒤.
- **영향**: 검토 중 수정이 심사에 미치는 영향은 확인하지 못했습니다(미확인). 되돌리면 홈 '인기 글'에서 건강 글이 빠집니다.

## 9. 재개 순서와 목표 시점 (방향 검토 ⑦ — 사람 승인 흐름을 상시 모델로)
- **내용**: R-212 §7 의 R0–R6 — 전제 확인 → 알림 중복 방지 같은 AI 후속 → 생성 기준 보강 → 승인 흐름 전환(T3, 정지 유지) → 하루 상한 낮춤 → 해제 → 첫 초안 PR 을 사람이 읽고 병합 또는 닫기.
- **선택지**: A★ 이 순서 승인(해제는 W0·W1 과 R2·R3 첫 단계가 끝난 뒤, 목표 약 1–2주), 사람 승인 흐름을 먼저 켜고 상시 여부는 첫 달 뒤 다시 논의 / B 승인 흐름 없이 재개(비추천) / C 재개 시점 미정(AdSense 검토 결과 뒤 다시 의논).
- **영향**: 해제 전까지 새 글이 없습니다. 오래 멈추면 운영 중단으로 보일 수 있다는 11-04 점검표의 지적을 감안한 시점입니다.

## 10. 생성기 개선(11-04 트랙 G) 시작
- **내용**: 입력 보강(피드 본문 사용) → 그림자 모드(보고만, 게시에 영향 없음) → 보류 승격 → 분야별 지침. 새 글이 감사에서 나온 문제를 다시 만들지 않게 하는 일입니다.
- **선택지**: A★ 그림자 모드부터 시작(T2, 독립 검증) / B 보류.
- **영향**: 정지 중이라 새 약한 글이 개선을 상쇄할 위험이 없습니다. 생성기·검사 모듈을 건드리므로 방향 검토 대상에 올립니다.

## 11. 도구·계산기, 커스텀 도메인 (방향 검토 ①·⑤)
- **선택지**: A★ 둘 다 보류(글 정비가 끝난 뒤 별도 제안) / B 통계 해설 페이지·계산기 설계 시작 / C 도메인 비용·절차 조사(읽기 전용)만 시작.
- **영향**: 도구와 도메인은 글 품질 문제를 먼저 풀지 않으면 효과가 불분명하고 비용·약관·유지관리 부담이 늘 수 있습니다.

## 12. 주제 적합성 기준 (방향 검토 ⑧)
- **왜 벗어나나**: Chance 주제는 '공공 자료로 읽는 세계'인데 회사 발표 정리(S01 OpenAI·S03 원프레딕트)·행사 안내(S04·S20)·한 줄 인용을 늘린 글(S12)이 섞여 있습니다.
- **선택지**: A★ 공공기관·연구기관 1차 자료를 근거로 한 글은 유지하고, 회사 발표 중심·행사 안내·한 줄 인용 확장 글은 비공개 또는 통합 후보로 / B 현행 유지(분야 제한 없음).
- **영향**: 3번 항목과 이어집니다(S12·S20·S03 이 이 기준으로도 비공개 후보).

## 하지 않는 것
이 확인 요청의 어떤 선택도 공개 글·고정 페이지·광고 코드·`ads.txt`·발행 설정·정지 변수·Blogger 글을 바꾸지 않고 AdSense 재검토를 요청하지 않습니다(재검토는 운영자만). 바꾸는 단계는 배치 또는 구체 변경안마다 채팅 승인으로만 합니다.

## 답하는 방법
이슈 양식 `AI 확인 요청에 답하기(대상번호)` 에서 대상번호에 **006** 을 쓰고 선택(1–4)을 고르세요. 항목별로 다르게 고르려면 선택에 2 를 쓰고 내용에 '번호=선택'을 적어 주세요(예: `1=B 5=C`, 적지 않은 항목은 ★ 추천). 답이 없으면 기본값(4)으로 아무것도 바꾸지 않고 정지·읽기 전용을 유지하며, 응급 정정 배치 1 의 정정안은 작업 폴더에서 미리 준비해 적용 승인 요청만 올립니다.
