## 이번 묶음이 하는 일 (개선 발굴 첫 묶음 — 문서·시험·주석만)
1. **개발 PC 의 가짜 빨강 해소**: 시험 하나(`test_service_lock`)가 이 PC 의 파이썬 가상환경에서만 늘 한 건 빨갛게 나오던 것을, 자식 프로세스가 자기 번호를 직접 알려 주는 방식으로 고쳤습니다(단언은 오히려 강해짐). 앞으로 전체 시험 결과가 깨끗하게 나옵니다.
2. **비밀 모양 검사를 넓힘**: 저장소 훑기 시험이 자체 여섯 모양뿐이라 새 구글 키 모양 등을 놓쳤습니다. 정본 패턴 14종으로 파일을 훑고 읽는 확장자도 넓혔습니다(현재 저장소에서 새로 걸리는 것은 0건).
3. **공개 저장소의 이 PC 식별 값 제거**: 시험·주석·결정 기록 한 줄에 남아 있던 계정 짧은 이름과 다른 프로그램의 폴더 이름을 합성·중립 값으로 바꿨습니다. **공개 이력의 과거분은 못 지우고**, 문서 사진 한 장에 작업 폴더 경로가 찍힌 것은 다시 찍기로 남깁니다.
4. **입구 문서와 시험지 바로잡기**: README 상태 줄을 사실('미리보기 단계 — 개인 PC 제한 시험용 Package 만 있고 설치 파일·자동 업데이트는 아직 없음')로 고치고, 시험지에 **0-0 '압축 파일 받기'**(Actions 수동 실행·압축 속 압축 주의·SHA-256 확인 전에는 안쪽 압축을 풀지 않기·빨간 실행이면 어느 줄을 복사해 알릴지)를 더했으며, 실제 화면(1440×900·900×560 창을 찍어 확인)과 달랐던 위치 설명(블로그 카드·'이 주제로 만들기' 단추·설정 화면의 카드 순서)을 바로잡았습니다. PACKAGE·RELEASE·ARCHITECTURE 의 낡은 문장도 병합된 사실로 고쳤습니다.
