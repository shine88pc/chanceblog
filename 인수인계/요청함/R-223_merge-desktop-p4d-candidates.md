## 이번 묶음이 하는 일
1. 사이드바 '핵심 작업'에 **`주제 후보`** 메뉴가 생깁니다(실제 메뉴 4→5, '다음 단계' 3→2). 지금까지는 이름만 있고 열 수 없던 메뉴입니다.
2. 화면: 머리의 `후보 만들기` 단추·거르기(채널·작업 상태·글 검색, `더 거르기` 뒤에 점수 구간·주제 묶음)·**후보 카드 격자**(24장씩, 점수 링·배지)·**상세**(창 논리 폭 1366 이상은 오른쪽 고정 창, 미만은 서랍). 후보는 주제 엔진 보관함에서 **읽기만** 합니다.
3. **쓰기는 한 길뿐**: `후보 만들기` → 미리 보기(읽기뿐) → **확인창의 `만들기`**(처음 포커스는 `취소`) → 서비스가 후보를 한 번 만들어 `topic_engine/topic_engine.db` 하나에 씁니다. 열기·거르기·찾기·고르기·상세·창 크기 바꾸기·취소는 파일도 폴더도 만들지 않습니다(임시 폴더 전체 바이트 비교로 시험).
4. 명령줄 `gui --help` 설명 문장 하나가 바뀝니다(이 화면이 확인창 뒤에만 쓴다는 것). 나머지 명령 출력은 기준과 한 글자도 같습니다(12개 비교).

## 눈에 보이는 변화
- 앱을 열면 사이드바에 `주제 후보` 가 보이고 누르면 위 화면이 열립니다. 후보가 아직 없으면 준비 안내 카드가 나오고(승인한 Seed 가 있으면 `후보 만들기` 로 첫 후보를 만들 수 있습니다), 홈·설정·블로그 관리·Seed 관리 화면은 그대로입니다(본문이 같고 사이드바 메뉴 하나만 다름 — 72장면·위젯 7,713개 비교).
