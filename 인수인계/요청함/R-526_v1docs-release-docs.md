# 병합 요청 M127 — v1.0 안내 문서 묶음 (앱, T0–T1)

> **병합 방식**: 지금은 AI 병합 기능이 **꺼져 있어** 운영자께서 직접 병합해 주세요. (`M127 승인` 이라고 답하셔도 아직 AI 가 병합하지 않습니다.) 이 요청은 앱 저장소 `chanceblog-desktop` 의 것이고, PR 제목 맨 앞이 `[M127]` 인 것 하나만 병합합니다. 검사는 이미 끝나 초록입니다. 급하지 않습니다(보통).

## 1. 무엇을 바꾸는지
앱 v1.0 으로 가는 길의 **문서 갈래**입니다. **제품 코드·`.github/`·`vendor/`·의존성·`capabilities.py` 스위치·`service/external.py`·VERSION 은 0줄입니다.**
① **새 문서**: `docs/V1_RELEASE_CHECKLIST.md`(v1.0 선언 전에 고칠 낡은 문장 목록과 열 가지 점검)·`docs/PERSONAL_PC_TEST_V1_DRAFT.md`(**운영자 시험지 초안 13단계 — 초안**)·`docs/MIGRATION_NOTES_TEMPLATE.md`(이관 노트 틀)·`docs/DECISIONS_INDEX.md`(결정 색인 — 도구로 만든 생성물).
② **끝에 덧붙인 문서**: `docs/MIGRATION.md` §6(새 PC 에서 빈 폴더로 이어받는 시작 안내와 도구 표)·`docs/RELEASE.md`(릴리스 노트 규칙 — **설계만**, 외부 도구 사실은 모두 '확인 필요')·`README.md`(새 PC 안내)·`AGENTS.md` §0 의 한 줄·`CHANGELOG.md`·`docs/DECISIONS.md` 의 결정 D-660–D-669.
③ **`scripts/gen_decision_index.py`**(표준 라이브러리만, 읽기 전용): 결정 문서(1.4MB 넘는 큰 표)에서 번호·날짜·변경 등급·한 줄 요약 색인을 만듭니다. `--check` 는 색인이 낡았는지 보기만 하고, 정본을 덮어쓰지 않는 방어(같은 파일·링크·하드 링크 거절)가 들어 있습니다.
④ 시험 새 모듈 둘(`test_decision_index`·`test_v1_docs`, 95개).

## 2. 왜 필요한지
PC 를 바꾸거나 새 세션이 이어받을 때 읽을 순서를 한곳에 두고, v1.0 선언 전에 낡은 문장·점검 항목을 빠짐없이 정리하며, 커진 결정 문서를 한눈에 찾게 하려는 것입니다.

## 3. 사용자가 체감하는 변화
**없습니다.** 앱 화면·기능은 그대로이고 문서와 개발 도구만 늘어납니다.

## 4. 위험과 알려 둔 한계
- **새 PC 에서 처음부터 따라 해 본 기록은 아직 없습니다**(운영자 실기 1회 필요). 릴리스 노트 규칙·시험지는 **설계·초안**이고 외부 도구(릴리스 서비스·설치 도구)의 사실은 전부 '확인 필요' 입니다(태그 규칙·채널 수·산출물 이름은 확인 C 의 추천값을 가정).
- 결정 색인의 한 줄 요약은 자동으로 자르므로(547행 중 64개가 잘림, 가장 긴 109자) 정확한 내용은 정본 결정 문서를 보셔야 합니다.
- **병합 때마다 색인을 다시 만들어야 합니다**(다른 갈래가 결정 행을 더하면 `test_decision_index` 가 빨개짐 — 그래서 이 갈래는 맨 뒤에 병합합니다). 이번 병합 가지에서는 앞선 병합의 결정 행(D-670–D-696)을 넣은 뒤 색인을 다시 만들었습니다.
- 기존 현상(이 갈래가 만든 것 아님): `test_l8_docs`·`test_l8b_docs` 는 단독 실행하면 경로 문제로 불러오기에 실패합니다(전체·조각 실행은 통과).
- 점검표가 찾은 **이미 낡은 문장**(README 의 '초안을 쓰는 일은 아직 없습니다'·'초안 문장은 아직 만들지 않습니다' 등)은 점검표에 적었고 v1.0 선언 전에 정리 대상입니다.
- **운영자께 여쭐 것(급하지 않음, 이번 병합과 별개)**: ① 시험지 초안 13단계를 한 번 읽고 빠진 단계·틀린 순서를 알려 주세요 — **추천: 앱 v1.0 갈래가 끝나는 시점에 한 번에 실기** ② 확인 C(라이선스·제품 이름·패키지 ID `ChanceBlogDesktopApp` 등)의 추천값을 문서가 가정하고 있으니 바꾸실 곳이 있으면 알려 주세요 — **추천: 추천값 그대로**.
