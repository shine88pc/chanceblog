# [R-108] 새 요청 접수(이슈 #121) — 범용·주제별 가이드로 분류·표본 개선·실행안 (2026-11-04 12:35 기준)

> 12:19 에 올리신 요청(이슈 #121 — 첨부 두 문서 '범용 블로그 콘텐츠 품질 및 작성 가이드라인'·'주제별 블로그 콘텐츠 작성 가이드', 진행 범위 '구현·시험까지(T1·T2)')에 대한 접수와 진행 계획입니다.

## 1. 제가 이해한 것
- 두 문서를 **블로그 콘텐츠의 공통 기준**으로 검토합니다 — 범용 기준은 모든 글에, 주제별 가이드는 글의 분야를 판단한 뒤 추가로 적용합니다. **모든 글에 같은 목차를 강제하지 않고**, 사실성·독창성·정보 가치·출처 검증 기준은 일관되게 두되 구성은 글의 주제와 독자의 검색 의도에 맞게 조정합니다. 두 문서의 내용은 구체적이고 쓸 만해서 거의 그대로 '공통 기준'으로 쓰고, 우리가 더하는 것(예: 출처를 실제로 열어 대조하는 절차)은 구별해 표시하겠습니다.
- 순서: ① 현재 게시글을 주제별로 분류 → ② **표본 게시글에 적용한 개선 전후**를 보여 드리고 검토 → ③ 검토 뒤 전체 게시글과 향후 AI 자동 생성 글에 적용할 구체적인 실행안. 승인 없이 광고 코드·발행 설정은 바꾸지 않습니다.
- 진행 범위가 '구현·시험까지(T1·T2)' 이므로 **글 본문의 정정·보강(T1)** 과 생성 코드 변경(T2 — 독립 검증 필요)은 진행할 수 있지만, 광고·정책 페이지·자동 발행 설정·글 비공개 전환·삭제(T3)는 따로 번호 있는 요청으로 여쭙습니다.

## 2. 어떻게 진행하나
- **#114 준비와 합쳐서** 진행합니다(조사자 4명). ① 이미 끝난 전체 진단표에 **'주제별 분류'**(핵심 독자 질문·검색 의도·주 분야·적용할 가이드 항목)를 더하는 중 ② 허블 글 표준 사례와 **표준 템플릿을 두 문서 기준으로 다시 설계**(고정 목차 대신 고를 수 있는 구성·판정 3단계) ③ 자동 생성 개선안에 **AI 보조 작성 규칙·발행 보류 기준·분야 판정 단계** 반영 ④ **표본 두 편**을 별도 조사자가 작성 ⑤ 전체·자동 생성 **실행안** 추가.
- **표본 3편**(제가 고른 것이고 바꾸고 싶으시면 알려 주세요 — 분야와 진단 분류가 서로 다릅니다): ⓐ 허블 우주망원경 RFI 글(과학·기술·우주 — '대폭 수정') ⓑ Pew 데이터센터 정치 광고 글(정책·경제·산업 — '대폭 수정') ⓒ 유통기한·소비기한 글(생활정보 — '유지', 잘 쓴 글을 최소로만 손보는 예시).
- **결과 시각(제 추정)**: 표본 3편의 개선 전후(근거 표 포함)는 **오늘 14:30경**, 전체·자동 생성 실행안은 **오늘 17시경**입니다.
