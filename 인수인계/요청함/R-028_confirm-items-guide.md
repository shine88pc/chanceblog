## 확인사항 1 — 네이버 블로그 B 추가 (결정 2)
**언제**: 두 번째 네이버 블로그를 쓰기로 정하셨을 때. 새 블로그라서 **승인이 필요한 일**입니다.
**준비물**(채팅이나 이슈 양식 `[요청]`에 아래 칸만 채워 주세요):
```text
네이버 블로그 B 추가
- 블로그 주소: https://blog.naver.com/아이디
- 주제(한 줄):
- 대상 독자:
- 말투: (예: 친절한 존댓말)
- 하루 몇 편: 1
- 블로그 A(계절·명절·여행 준비와 생활 관리)와 다른 점:
```
**추천**: 티스토리에 쓰려던 'IT 생활 팁(스마트폰·PC·앱 사용법과 오류 해결)'을 네이버 B 의 주제로 옮기면, 이미 만들어 둔 주제 36개·글 규칙·프롬프트를 거의 그대로 쓸 수 있어 가장 빠릅니다. 다른 주제를 원하시면 그 주제로 새로 만듭니다.
**그다음**: 정보를 받으면 제가 번호 있는 **승인 요청**을 한 번 보냅니다(블로그 주소·주제·켜기 확인). 승인하시면 구현하고 병합 부탁을 보냅니다(네이버 A 때와 같은 절차, 하루 안팎). 글을 복사해 발행하는 일은 운영자께서 하시고, **AI 는 블로그에 로그인하지 않으니 비밀번호·쿠키는 절대 보내지 마세요.**
**기본값**: 정보가 올 때까지 보류.

## 확인사항 2 — 무료 AI 키 (결정 7)
**언제**: 데스크톱 프로그램이 나온 뒤(지금은 프로그램이 없어 하실 일이 없습니다).
1. **앱용 Gemini 키를 따로 만들기**(무료, 5분): 구글 AI Studio(주소는 `aistudio.google.com`, 바뀌었으면 '구글 AI Studio API 키'로 검색)에 구글 계정으로 로그인 → **API 키 받기(Get API key) → 키 만들기** → 프로젝트는 **새 프로젝트**(예: `blog-publisher-desktop`)로 고릅니다. 새 프로젝트의 키를 써야 자동 발행(Actions 의 기존 키)과 하루 무료 한도를 나눠 쓰지 않습니다.
2. 만든 키는 **채팅·이슈·텔레그램·문서 어디에도 붙여 넣지 마세요**(저장소가 공개입니다). 프로그램이 나오면 설정 화면의 키 입력칸에만 붙여 넣습니다(Windows 자격 증명 관리자에 저장됩니다).
3. **결제수단(카드)을 등록하거나 결제 계정을 연결하지 마세요**(무료 등급 유지). 자동 발행에 쓰는 기존 키(GitHub 시크릿 `GEMINI_API_KEY`)는 건드리지 않습니다.
4. **Groq·OpenRouter 는 가입하지 않습니다.** 자동 발행이 Gemini 한도 때문에 자주 건너뛸 때만 따로 번호 있는 요청으로 여쭙겠습니다(그때도 결제수단 등록은 하지 않습니다).
**기본값**: 키가 없어도 프로그램은 '직접 쓰기·복사' 수동 모드로 돌아갑니다.

## 확인사항 3 — 앱의 Blogger 연동 (결정 8)
**언제**: 프로그램 1차 버전(복사 패키지·GitHub Pages)이 안정된 뒤. 지금은 하지 않습니다.
**나중에 하실 일**(제가 '이제 필요합니다'라고 요청드릴 때): 영문 Blogger 와 한글 Blogger 는 구글 계정이 달라 **각각** 합니다.
1. 구글 Cloud 콘솔(`console.cloud.google.com`)에서 그 Blogger 에 쓰는 프로젝트를 엽니다.
2. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID → 애플리케이션 유형 '데스크톱 앱'** 으로 만듭니다.
3. 나온 클라이언트 ID·보안 비밀은 채팅에 붙이지 말고 프로그램 설정 화면에 직접 입력합니다(지금 Actions 에 들어 있는 로그인 정보는 프로그램이 쓸 수 없습니다).
4. OAuth 동의 화면이 **'프로덕션(게시)' 상태**인지 확인합니다(테스트 상태면 로그인이 7일 뒤 풀립니다).
5. 프로그램에서 'Blogger 연결'을 누르고 브라우저에서 로그인합니다. 경고 화면이 나오면 사진을 찍어 알려 주세요.
**기본값**: 1차 버전에서는 Blogger 연동 없이 시작합니다.
