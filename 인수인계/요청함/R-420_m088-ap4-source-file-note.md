# 병합 요청 M088 — 계산 글 출처 목록에 '원자료 파일' 안내 한 줄을 더합니다(확인 015 의 AP4 F106)

> **병합 방식**: 지금은 AI 병합 기능이 **꺼져 있어** 운영자께서 직접 병합해 주세요. (`M088 승인` 이라고 답하셔도 아직 AI 가 병합하지 않습니다.) 이 요청은 블로그 저장소 `chanceblog` 의 것이고, PR 제목 맨 앞이 `[M088]` 인 것 하나만 병합합니다. 검사는 이미 끝나 초록입니다. 급하지 않습니다(보통).

## 1. 무엇을 바꾸는지
계산 글의 `## 출처` 절은 제공처 자료 주소를 링크로 걸어 둡니다. 그 주소가 사람이 읽는 화면이 아니라 제공처가 내려 주는 **원자료 파일(`.json`)** 일 때만, 링크 줄 바로 아래(이용 조건 줄 앞)에 '위 링크는 읽을 수 있는 화면이 아니라 제공처가 내려 주는 원자료 파일입니다.' 한 줄을 더합니다. 코드는 `pipeline/recipes.py`(안내 문구와 `.json` 판정 함수)와 `pipeline/fact_assembler.py`(출처 목록 조립에 조건부 한 줄) 열두 줄 안팎이고, 나머지는 새 시험과 문서입니다. 주소가 `.json` 이 아니면 안내를 붙이지 않아 거짓이 되지 않습니다.

## 2. 왜 필요한지
운영자님이 확인 015(2026-11-13, 이슈 #195)에서 추천대로 승인하신 열두 가지 중 하나입니다. 지금 계산 글의 출처는 NOAA 제품 여섯 개로 모두 `.json` 파일이라, 독자가 링크를 누르면 글이 아니라 데이터 파일이 열립니다. 미리 알려 두면 놀라지 않습니다.

## 3. 사용자가 체감하는 변화
**지금은 없습니다** — 공개된 계산 글이 아직 없습니다(발행 정지, PIPELINE_PAUSE). 발행을 다시 켠 뒤 첫 글부터 출처 목록에 안내 한 줄이 보입니다. 글 모양 점검 규칙·품질 Gate·얇음 측정에는 영향이 없습니다(전후 글자 수·측정값 같음).

## 4. 위험과 기존 기능에 미치는 영향
- **기존 기능**: 골든 9편(출처 주소가 `example.invalid` 꼴이라 확장자 없음)은 바이트 그대로입니다. `.github`·레지스트리·광고 표면·기존 시험은 한 줄도 안 바뀌었습니다.
- **알려 둔 한계**: ① 본문 첫 소개 문단의 `[공식 자료](주소)` 링크와 `.json` 밖의 확장자(`.csv`·`.txt`·`.xml`)는 승인 범위 밖이라 안 바꿨습니다(필요해지면 접미사 한 줄). ② 호스트가 `.json` 으로 끝나는 경로 없는 주소는 참으로 판정되지만 품질 Gate 가 그런 주소를 보류해 실제 글에서는 나오지 않습니다(결함 기록 D-387).
- **운영자께 알려 둘 점**: 저장소의 AI 병합 분류기(지금 꺼져 있음)가 이 PR 을 `ai_ok` 로 읽습니다. 이 변경은 공개 글 문구가 든 모듈이라, AI 병합을 켜기 전에 이런 모듈을 운영자 전용으로 둘지 정해야 합니다(지금은 운영자 직접 병합이라 영향 없음).
