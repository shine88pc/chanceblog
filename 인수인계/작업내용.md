2. **GitHub 설정 확인**: 비밀값 유출 자동 탐지(Secret scanning·Push protection) 켜짐, main 보호 규칙은 "삭제·force push 차단"만(PR 필수·승인 필수는 켜지 않음 — 봇이 main에 직접 올립니다).
3. **Google Search Console·Bing Webmaster** 등록 확인(사이트맵 제출), 열린 이슈 **#1~#3**(6~7일째 미처리 옛 요청) 확인 후 닫기.
4. **Chance의 AdSense 계정과 macat0722의 구글 계정이 같은지** 알려 주기(같으면 Blogger 자동 글의 정책 위반이 광고 계정에 영향을 줍니다).
5. **Blogger 시크릿·OAuth는 초안 업로드 기능 병합 뒤에만**: OAuth 동의 화면을 "프로덕션"으로 전환 → 토큰 발급 → `BLOGGER_*` 4종을 GitHub Secrets에 직접 등록(값은 채팅·저장소에 쓰지 않음). 지금 등록하면 글이 검수 없이 공개될 수 있습니다.
6. **새 블로그 정보**: 신규 한글 Blogger(다른 구글 계정)의 URL·ID, 네이버 운영 방식 결정.
7. **UN News 알림·서면 확인**(PR #27 병합 뒤 적용): 운영자 메일로 unnews@un.org에 사이트 주소와 이용 방식(광고가 붙는 사이트, AI 도구로 새 글을 쓰고 UN News를 출처로 링크, 피드를 자동으로 읽음)을 알리고 이대로 써도 되는지 서면 확인을 받아 알려 주세요. AI가 대신 보내지 않습니다.
8. 중복 이미지 2건 교체를 원하면 `Chance 기존 글 이미지 교체(수동)`을 연습 끄고 실행.
